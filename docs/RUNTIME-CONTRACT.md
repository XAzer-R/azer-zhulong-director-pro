# 公开版运行合同

本合同约束当前项目的所有角色与技能；创作方法用于完成已授权任务，不得越过本合同的状态和权限边界。

## 入口与上下文

- Claude Code 从项目根的 `CLAUDE.md` 加载指令，再读取 `.claude/CLAUDE.md`。自然语言中的 `~start`、`/开始` 等是本项目约定，不是宿主注册的命令；如宿主拦截斜杠输入，使用自然语言表述。
- 一次只处理一个作品、一个集或一个段。主控派发任务时必须传递项目根、目标单元、输入文件、允许输出位置和当前版本。子 Agent 不得仅依赖父对话中未传递的信息。
- 方法路径始终相对系统根；作品输入输出相对当前选定作品根。禁止把系统规则目录当作品输出目录，也不把真实素材写进 Skill 的 source 子目录。
- 宿主没有子 Agent 能力或无法加载角色时，报告不支持，不伪称已完成独立审查。自审与独立审查分别记录。
- 模型由用户和宿主选择。平台能力文档只作提示词方法参考，不保证时长、分辨率、接口或计费现状。

## 状态与修订

- 文件存在不等于阶段通过。只有当前输入与产物版本匹配、审核为 PASS 且无阻断项时才能进入下一阶段。
- 自动修订最多两轮；仍失败就保留 FAILED / NEEDS_USER_DECISION，列出剩余问题。不得把失败改名为通过，也不得因预算或轮数耗尽继续后续阶段。
- 输入剧本、摄影约定、身份素材或关键帧变化后，依赖旧版本的审核失效。记录受影响单元并要求重新核对；不得悄悄沿用旧素材和旧通过状态。
- 修改已完成结果前显示范围与差异，保留可恢复的旧版本。一次只由一个责任角色写一个文件。
- production 的内容归导演；服化道与分镜师返回素材编号和回填建议。只有主控核验后更新 production 的上传清单与素材对应表，不改变导演的镜头、对白和驱动模式。
- 上传清单尚无真实参考图时标为待素材；提示词设计完成不等于图片、视频或成片已生成。

## 空项目与可选输入

- 没有作品时进入首次配置，不凭空创建现成故事；作品类型、视觉方向或创意范围由用户提供。
- 空模板和 `status: unconfigured` 均表示未配置，不能因为文件存在就跳过引导。
- 可选范例库、图片示例或上集不存在时，明确标记缺失并走无范例路径；缺少当前剧本或必需输入时停止该阶段，不伪造内容补齐。
- 本包所有示例路径都是用户将来创建的路径，除明确提供的空模板外，没有预置作品文件。

## 权限与费用

- 默认只进行当前项目内文本创作、审核与文件维护。付费 API、图像/音视频生成、上传、公开发布和破坏性操作按用户明确授权执行。
- 不扫描本机凭据，不安装 Hook，不读取其他作品私有资料，不在失败后自动切换供应商或重发收费请求。
- 用户说暂停或收工时停止业务执行，报告准确停点。

## 机械复核入口

导演入口派发前执行 `python -B tools/workflow_guard.py unit EP01-S01`（替换为实际单元）。审核后按 `docs/REVIEW-RECEIPTS.md` 保存回执，进入下游前运行 `tools/workflow_guard.py review`；退出码非零不得继续。执行工具的工作目录为系统根，`--root` 指向当前作品根。
