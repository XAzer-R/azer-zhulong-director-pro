# 运行机制检查与修复

版本：0.1.0；检查日期：2026-09-10。

## 已关闭的发现

| 触发条件 | 原风险 | 本版处理 |
|---|---|---|
| 两轮修改后仍失败 | 失败被转换为带警告通过 | 保持 FAILED / NEEDS_USER_DECISION，停止下游 |
| 专业版关键帧回填 | 分镜师直接写与禁止写 production 同时存在 | 分镜师返回建议，主控唯一回填，导演持有内容 |
| 干净剧本项目首次启动 | 读取不存在的根状态 | 零项目进入新建，坏状态报告且不覆盖 |
| 空摄影圣经 | 按文件存在误判已配置 | unconfigured 明确进入配置 |
| 示例和审稿模板未分发 | 强制读取失效路径 | 提供空白模板，可选范例缺失明确降级 |
| 改动上游后继续处理 | 旧通过状态仍被使用 | 运行合同与 SHA-256 回执检查拒绝旧版本 |
| 子 Agent 上下文隔离 | 方法路径与作品路径混淆 | 派发显式携带两个根、范围和输入版本 |
| 剧本 Skill 大量预加载 | 与按需加载原则矛盾 | Agent 仅预载基础方法，其余按需读取 |

首次检查还发现校验器错误要求嵌套格式包名字等于目录名；已改为仅对一级可发现 Skill 应用该规则，保留嵌套方法原有名字。

## 验证

- `python -B tools/validate.py`：检查角色集合、技能字段、技能引用、明确文件引用、JSON、敏感模式及装配哈希。
- `python -B -m unittest discover -s tests`：13 项，通过真实临时文件验证单元参数、路径边界、输入变化、产物变化、缺失产物、失败/阻断、缺失版本绑定和修订轮数。
- 文件存在与艺术质量不由哈希等同；回执没有防篡改签名。主控仍须真实执行审核并调用检查入口。
- 项目无外部 Python 依赖；未安装 Hook，未调用付费模型或生成服务。

已进行规则文本审查和离线代码回归，没有进行真实 Claude Code 子 Agent 创作、真实模型或媒体生成 E2E。不是“保证无 bug”的证明。需要用自己的授权测试材料在宿主中验证角色调度与完整流程。
