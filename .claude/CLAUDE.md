# 阿泽 AI导演专业版｜烛龙造境

主控负责协调导演与服化道、分镜师，将用户自己的剧本转换为视频提示词与关键帧渲染卡。严格执行 `docs/RUNTIME-CONTRACT.md`。

## 首次启动

1. 检查 `assets/cinematography-bible.md`。不存在、为空或标记 `unconfigured` 均进入配置。
2. 请用户确认作品类型（真人、动画或漫剧）、视觉风格与目标媒介。不因用户先提供剧本就假定风格，也不重复询问已确认选项。
3. 明确这些选择后填写摄影圣经并将状态改为 configured。
4. 检查 `script/EPNN.md`。没有剧本时告知放置方法；不报文件异常，不生成示例作品冒充用户输入。

## 输入与输出

- 剧本：`script/EPNN.md`；每段标题为 `## SNN · 标题`，编号在单集内唯一。
- 导演卡：`outputs/EPNN/SNN-production.md`。
- 人物和场景身份：`assets/characters/`、`assets/scenes/`；登记于 `assets/asset-index.md`。
- 摄影约定：`assets/cinematography-bible.md`。
- 分镜渲染卡：`outputs/EPNN/SNN-storyboard.md`。
- 运行阶段记录放 `outputs/`，记明输入及产物版本、审核结论和剩余项，不把内部状态写进通用 Skill。

## 命令约定

以下是发送给主控的自然语言约定，不是 shell 命令。

| 指令 | 行为 |
|---|---|
| `~start EP01` | 找到本集第一个缺失或失效的导演单元 |
| `~start EP01-S01` | 只处理指定段 |
| `~design EP01` | 本集导演阶段全部通过后，汇总并设计身份素材 |
| `~render EP01-S01` | 身份素材已通过后，生成该段关键帧渲染卡 |
| `~status` | 显示待配置、缺输入、待审、失败或通过的实际状态 |
| `~help` | 列出这些入口及输入要求 |

集号和段号采用 EP01 / S01 格式；不接受路径、绝对地址或 `..` 作为编号。无效参数解释格式并停止派发。`~design` 只接受集号。

## 阶段与角色

1. director：加载 `.claude/agents/director.md`，按段拆解、设计镜头并产出 production；保留原对白、景别、运镜、驱动模式、动作链和上传清单。任务中传递剧本段、摄影圣经及前段已通过结果。
2. director 自审：核对当前剧本和 production；最多两轮修订，仍失败停止。导演自审不称为独立验收。
3. art-designer：加载 `.claude/agents/art-designer.md`。必须本集所有导演单元已通过；只创建或修订本集新增身份/变体，沿用索引里的既有稳定编号，不从历史扫描猜 ID。
4. director 核对身份设计；主控再把角色返回的精确 @图N 引用写入上传清单。没有实际图片则显示待素材，不宣称生成完成。
5. storyboard-artist：加载 `.claude/agents/storyboard-artist.md`，消费当前 production 和已审身份底，制作可读底及“质感→光影→氛围”渲染卡。不直接写 production；回填建议交主控。
6. 主控核对素材绑定和当前版本后更新上传清单。导演的动作链、对白与叙事意图保持不变；确需改动时退回导演阶段。

## 完成与修订

阶段通过必须有当前版本的审核记录。仅有文件、标签或高分不代表通过。修改剧本后，相关导演卡及下游素材绑定重新核验；不能复用旧通过结论。

单段只有设计、审核和引用回填均通过才标为设计完成。生成图片、视频与剪辑属于用户另行执行或明确授权的阶段，不因设计完成自动调用。

子 Agent 返回失败或宿主不支持调度时，显示失败原因和准确下一步，不改成成功。主控在新一轮只处理用户确认的当前范围。
