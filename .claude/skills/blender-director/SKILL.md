# Blender 建模与导演预演

Copyright (c) 2026 阿泽。MIT License。

先读系统根 `docs/RUNTIME-CONTRACT.md`。本技能按需启用；不要求所有镜头都经过 Blender，不替代原导演、服化道、分镜师主流程。

## 选择本次任务

| 模式 | 目标 | 完成依据 |
|---|---|---|
| 白模 / 灰模预演 | 空间比例、占位、视线、走位、动作意图、运镜和节奏 | 起／中／末相位回看及关系检查 |
| 基础建模 / 场景搭建 | 将主体拆成结构、部件、连接和尺寸，逐步建立可编辑模型 | 模型结构、比例、拓扑检查与多视角回看 |
| 机位 / 运动调整 | 使用现有授权场景调整摄影机或对象运动 | 相位位置、镜头取景、遮挡与运动轨迹回读 |

缺少模型目标、尺度、输出用途或需要修改的对象范围时先补齐。不要把“建模”默认解释为最终材质、动画绑定或自动出片。

## 能力检测

在系统根运行 `python -B tools/blender_preflight.py`。仅通过 PATH 或显式 `--binary` / BLENDER_BIN 定位程序，不扫描账号配置，不写全局设置。

检测只调用 Blender 的 `--version`，不建模、不启用插件、不检查真实 MCP 连通性；不能将 `BLENDER_FOUND` 当成渲染验收。

- headless：确认用户允许本次本地建模/预演后，在单独进程和新输出目录运行已复核的 bpy 脚本。使用 `--background --factory-startup --disable-autoexec --python-exit-code 1`，再传入脚本。不得装载来源不明的 blend 文件自动脚本。
- live：只有宿主已提供且文档已读的 Blender 工具可用时才操作。先只读查询场景、版本、当前文件与目标 Collection。不要假定固定端口、自动改端口或安装 MCP。
- 没有可用工具：可以交付建模方案和待执行脚本，明确“未执行”。不能用截图示意代替真实场景证据。

原生 bpy/API 版本差异先查当前 Blender 官方资料。旧笔记的 5.1.1 经验是历史起点，不是所有版本均兼容的保证。

## 从需求到操作

1. 建立对象清单：名称、尺寸、单位、坐标、朝向、父子关系、允许修改范围。拆分承重面、容器、遮挡面与可动部件。
2. 先做低复杂度块体。把比例、轮廓和机位确认后，再细化部件、修改器和材质；避免一开始就做高密度网格。
3. 每次只执行一小组有明确目的的操作，回读对象数量、名称、尺寸、变换与输出路径。生成 bpy 前审核其中的文件操作和场景修改范围。
4. 预览后目检；确认坐标或文件存在只证明操作发生，不证明造型、构图或空间关系正确。
5. 修正失败时遵守最多两轮自动修订合同。保留失败证据和剩余问题，不把失败标成完成。

白模预演时额外读取 `references/greybox-practice.md`；执行脚本或 live 操作前读取 `references/blender-operation.md`。这两个文件相对本 Skill 目录。

## 场景保护与输出

- 只修改用户选定对象或本次创建的专用 Collection，使用唯一任务前缀；不得遍历删除当前场景全部对象。
- live 模式不调用 factory reset，不改插件和偏好，不覆盖用户当前 blend 文件。需要删除已选对象也须在已授权范围内。
- headless 使用全新进程；输出统一落在系统根 `outputs/blender/<任务ID>/` 的新目录，计算绝对路径后传给 Blender，不把机器路径写进仓库。
- 不把动态生成脚本视为沙箱。执行前检查脚本；不能从 JSON 字段或参考文本直接 eval/exec Python。
- 模型、渲染、动捕、原件和实际脚本都属于作品产物，留在被忽略的 outputs 中。公共模板不带预置模型或剧本。

## 向专业导演流程交接

交回：目的、对象清单、输入版本、blend/预览路径、机位与时间说明、验证结果、已知近似。记录用户是否完成视觉确认。

Blender 角色不直接重写 production。主控在核验输入、覆盖范围和参考图/视频对应关系后，才回填素材清单；导演持有对白、镜头意图和叙事内容。

若用白模视频作为外部视频模型的参考，分别声明“运动/占位参考”与“角色外观参考”，说明覆盖哪些镜头或时间段。原始导演卡保留，另出适配候选，不直接删除运镜或台词。实际平台支持和效果单独验证。

## 模型与范围

可以由用户选择的 GPT、Claude 或其他能调用工具的模型理解需求；本仓不固定模型版本、不提供密钥，也不承诺某个模型必然能完成任意建模。复杂雕刻、面部绑定、精密工程尺寸和最终生产模型需要各自验收。
