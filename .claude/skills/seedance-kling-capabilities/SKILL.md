# 视频提示词写法手册（极速版 · 模型无关）

**定位**：本 skill 是导演产出 production 的**执行层**——定义"视频提示词具体怎么写、参考图怎么上传"。

**极速版说明**：当前主流视频模型（Seedance / 可灵 等）底层能力已趋于一致。**本手册不区分模型、不做模型选择、不写线稿**——提示词以统一写法产出，由用户在任意 i2v 平台生成。

> ⚠ **卡片最终格式以模板为准**：见 `director-skill/templates/director-analysis-template.md`——**分镜动作链**（`- [C01]…`·按事件顺序·**不写秒级时间戳**·台词内嵌）· **无 avoid** · 无风格前缀/模型/线稿。本手册提供平台能力/驱动模式/参考图策略等**方法论**（仍有效）；下方示例里出现的 `avoid …` 行**已作废**。**分镜用 `C01/C02/C03` 按事件顺序标识、不标秒**（官方：模型对精确时间如 0–3 秒支持不稳定、强行限时长可能致生成异常）。

**上游**：导演标注的"驱动模式"（首帧 / 首尾帧 / 续写 / 多元参考）。

## §1 平台能力基线（i2v 通用）

| 维度 | 基线 |
|---|---|
| 生成方式 | i2v（图生视频）——上传参考图 + 提示词驱动 |
| **最短时长** | **4 秒**（低于 4s 不支持） |
| 单条最长 | 约 10-15 秒（超长拆多条续写拼接） |
| 甜区 | 单条 4-12 秒，生成质量最稳定 |
| 参考图 | 多图分开上传（人物/场景/道具各自独立） |
| 画面风格 | **从输入参考图继承**（风格前缀块在生图阶段由服化道烧进参考图） |

> 因为画面风格从参考图继承，**视频提示词不写风格前缀**（不写 `Shot on ARRI…`），只写运动与表演。

## §2 参考图上传策略

**核心原则：参考图分开上传**。人物设定图、场景图、道具图各自独立上传，**不合成为一张图**（合成会同时降低场景和人物的 identity 精度）。

| 参考图类型 | 用途 | 上传方式 |
|-----------|------|---------|
| 角色设定图（三视图） | identity 锚·跨帧一致 | 用到角色的镜头必传·分开上传 |
| 场景图（主视角） | 空间环境锚定 | 分开上传 |
| 场景图（角度变体） | 首尾帧的起始/终止角度 | 分开上传·@图N-A / @图N-B |
| 道具参考图 | 特定物件外观 | 道具交互时传·分开上传 |

**与提示词的配合**：
- 参考图提供视觉锚定（角色外貌/场景空间/道具外形）+ **画面风格**
- 提示词提供动作指令 + 构图/运镜控制 + 必要的光影补充
- 提示词用 `{{@图N}}` 引用上传的参考图
- 提示词**不重复参考图已锁定的信息**（角色外貌/服装/发型已在设定图中）

## §3 四种驱动模式（导演标注）

### ① 首帧模式（start-only）
- **场景**：机位静止 / 角色静态 + 局部动作（嘴唇动、手指动）/ 无视角变化
- **必传**：场景图 @图N（主视角）+ 角色设定图 @图N（按需道具图）
- **提示词要点**：运动描述（动作链 + 表情并入）+ 运镜翻译 + 台词（如有）

### ② 首尾帧模式（start+end）
- **场景**：焦点切换 / 角色动作变化 / 镜头运动（推拉摇移）/ 视角明确改变
- **必传**：场景图·起始 @图N-A + 场景图·终止 @图N-B + 角色设定图 @图N
- **提示词要点**：描述起始→终止之间的"过渡过程"（不是终点状态·AI 通过终止图知道终点）；运镜翻译尤其重要

### ③ 延长续写模式
- **场景**：连贯动作的时间延长 / 伪一镜到底 / 同一机位持续
- **必传**：上一条生成视频（或尾帧截图）+ 角色设定图 @图N
- **提示词要点**：从"上一条视频尾"继续描述接下来发生什么，不重复已发生内容，光线/运镜连续

### ④ 多元参考模式（multimodal）
- **场景**：大场景建立镜头 / 无强构图要求 / 环境主导镜头
- **必传**：角色设定图 @图N + 场景设定图 @图N（+ 参考音频可选）·全部分开上传
- **提示词要点**：完整描述画面组成（多素材混合·AI 自由度高）

## §3.5 片段间动作衔接（无缝缝合技巧·剪起来不"怪"的关键）

> AI 视频剪在一起"怪怪的"，根因常在**衔接**不在模型。一段连续动作拆成两条 clip（续写/首尾帧）时，光靠首尾帧对齐还不够，按下面三招缝才看不出剪辑点。与 director-skill [剪辑原则] 原则 4「动作中切」、long-take-skill 跨片段缝合配套用。

- **① 保留重叠动作（动作叠合）**：相邻两条 clip **保留一段重叠的同一动作**——上一条结尾的动作和下一条开头的动作是**同一个动作的连续段**（上镜"举起咖啡杯到嘴边"，下镜从"杯在嘴边"继续"喝一口放下"）。靠重叠动作把两条焊在一起，而不是各演各的。
- **② 剪辑点放在动作中途（不在动作起止）**：真正剪开的那一帧选在**动作进行到一半**时（手抬到中途、转身转到一半），用运动本身遮掩剪辑痕迹；切在动作完全静止的起点/终点反而会"顿"一下、暴露接缝。
- **③ 利用视觉暂留（0.1–0.2s 重叠余量）**：人眼有约 0.1–0.2s 视觉暂留，剪辑时让两条在接缝处**重叠极短一截**（后期对齐时留 0.1–0.2s 余量），观众的眼睛会自动把它脑补成连续动作。
> 落地：拆条时在 production 标注衔接方式——上一条尾画面字段写清"动作进行到 X 中途"的状态，下一条首帧承接同一动作的后半段；最终接缝的 0.1–0.2s 重叠靠**后期剪辑**对齐（生成不保证精确到帧·见 §5.1bis 硬约束 #3/#8）。

## §4 提示词格式（统一·无风格前缀·无模型）

> ⚠️ **现行卡片格式＝分镜动作链**（`- [C0N·景别·运镜] 动作`·按事件顺序·不写秒级时间戳·见 `director-skill/templates/director-analysis-template.md`）。下方示例为**早期散文式**、仅示意"驱动模式/参考图怎么配"，**实际产出按模板的分镜格式**（官方：精确秒数支持不稳定，多镜头用 C01/C02/C03 按事件顺序）。

**基础格式**（首帧·场景图+角色图+动作描述）：
```
无BGM无字幕。[全局修饰（按需）]。角色为{{@图1}}。场景为{{@图2}}。
[运动描述·动作链与表情并入·物理化·污染词已替换]。[光影补充（按需）]。
```

**首尾帧格式**（起始+终止场景角度·运镜过渡）：
```
无BGM无字幕。角色为{{@图1}}。场景起始为{{@图2-A}}，场景终止为{{@图2-B}}。
[起始→终止之间的过渡过程描述·运镜翻译]。
```

**多 clip 格式**（一卡内运镜切换·复杂动作拆分）：
```
无BGM无字幕。[全局修饰]。角色为{{@图1}}。场景为{{@图2}}。
[C01: 运镜] 动作1。
[C02: 运镜] 动作2。
[C03: 运镜] 动作3。
```

> **不写风格前缀块**（`Shot on ARRI…` 归服化道参考图）。固定句 `无BGM无字幕。`。

### 全局修饰词
| 修饰词 | 效果 |
|--------|------|
| 手持模拟 | 手持摄影晃动感 |
| 延时摄影 | 时间加速·昼夜循环 |
| 一镜到底无切镜 | 连续无剪辑 |
| 主体追踪 | 镜头跟随主体运动 |

### 提示词 不写 / 写
| 不写 | 写 |
|------|------|
| **风格前缀块（归服化道）** | 运动描述（动作链+表情·物理化） |
| **模型字段（无模型概念）** | 运镜翻译（按运镜词汇） |
| **线稿（极速版无）** | 人物行动（情绪核心物理描写） |
| 角色外观/服装/发型（设定图已锁） | 台词（角色说话时写入） |
| 音效 / BGM | 光影补充（参考图不够时） |
| 运动速度具体数值（只写极缓/慢/中/快·不写"X m/s")· **秒级时间戳（`[0-3s]` 这类·官方称不稳定）** | **分镜动作链 `- [C0N·景别·运镜]`**（现行格式·按事件顺序·见 director 模板）/ 氛围粒子（按场景绑定） |
| 生图 avoid（text/HUD/手指·归服化道） | —（视频不写 avoid）|
| — | 全局修饰词 / 多 clip C01/C02 |

## §5 时长硬约束 + 演时换算法（**估时单一事实源**）

### §5.1 容器硬约束
- 单条 clip **4–15 秒连续可选**（**无固定档位**·<4s 不支持·>15s 拆多条续写拼接）。**按内容实际需要定时长，不迁就固定档、也不凑满 15s。**

### §5.1bis 硬约束清单（**单一事实源**·时长只是其一·重抽无效·必须结构方案）
> **核心区分（贯穿全系统）**：
> - **硬约束 = 物理/结构限制**：重抽一万次也突破不了（如时长上限），**必须靠结构性方案绕过**（拆条/参考图/首尾帧/后期/道具特写）。这才是该"特殊处理"的。
> - **软约束 = 抽卡/不稳定**：模型这次没做出来 ≠ 做不到，换种子/改措辞/重抽**可能就成**。**不预设"做不出"、不擅自降级替换**，把镜头照给用户、提示"多抽几次"，换不换由用户定。
>
> 下面是**硬约束**全清单——产出时一眼分清"哪些必须结构绕过、哪些只是抽卡"：

| # | 硬约束 | 为什么是硬的（重抽不解决） | 结构性解法 | 归属 skill |
|---|---|---|---|---|
| 1 | **单条时长上限 ~15s** | 模型容器就这么长 | 拆条 + 续写/首尾帧/转场缝合 | 本节 §5.1 + §5.2 演时换算 |
| 2 | **跨条一致性漂移** | 每条**独立生成**·无法跨条记住同一张脸/道具/场景 | 参考图锚定 + 首尾帧 handoff + seed 锁 + @引用 | consistency-skill |
| 3 | **跨片段帧对不齐** | 两条之间无逐帧无缝衔接 | 创意转场（遮挡/甩镜/入暗）缝合（"不可能穿越镜""精确 match-cut"本质都是这个） | long-take-skill |
| 4 | **精确文字渲染** | 指定招牌字/UI/书法/数字/品牌名 → 必乱码 | 后期叠字 / 留空 / 关键可读文字靠图层（字幕片名一律后期） | 后期·非生成 |
| 5 | **口型对白同步** | 嘴型对不上指定台词（中文尤甚） | 后期配音 + 提示词只写"开口说话"概略 + 侧脸/画外/不露正脸规避 | director（表演写法） |
| 6 | **精确数量 / 计数** | 指定"恰好三道痕/五个人"常给错数 | 关键计数物用**道具特写单独控制** / 叙事不死依赖精确数量 | director（道具特写锁） |
| 7 | **精确物理因果链** | 多米诺/精确碰撞/液体飞溅轨迹/绳索缠绕·物理控不准 | 简化动作 / 拆关键帧 / 不依赖精确物理 | director（动作设计） |
| 8 | **精确到帧的时长 & 卡点** | 要 4s 给 3.7s·动作命中点不落在指定帧 | **节奏卡点一律靠后期剪辑对齐**，不靠生成 | 后期（卡点）·sound-design |
| 9 | **画面外 / 不可见信息** | 声音、画外、心理活动无法直接生成 | 物理化暗示 + 后期声音 | director（抽象概念视觉化禁令） |
| 10 | **（半硬）精确运镜参数** | 精确速度/距离/角度数值控不了·只能"慢/快"概略 | 自然语言概略 + 多抽选接近 | storyboard / 轨B |

> 用法：导演/服化道产出时，命中 1–9 的**先想结构方案**（别指望重抽）；其余难度问题（复杂运镜如 dolly zoom/360/子弹时间等）属软约束 → 照给 + 多抽，**不预设做不出**。轨 B 招牌镜头库的 🔴 标记 = 命中本清单的真硬约束；⚠️ = 软难度。

### §5.2 演时换算法——把"一拍演几秒"从【猜】变成【算】
> 设计动机：AI / 主 Agent 对"表演时长"没有可靠内部时钟，凭感觉估会在同一段戏上反复横跳（14↔28↔48s）。本法把估时拆成**可数的离散单元 × 固定常数**，消除随意性：同一拍任何人算、每次算，结果一致；且可被你实拍校准。

**主公式**
> **一拍时长 ≈ Σ(开口前铺垫动作) ＋ max(台词朗读时长, 说话时并行的动作)**
> 算出 **<4s** → 补到 4s 或与邻拍合并｜**4–15s** → 一条·时长=算出值｜**>15s** → 在该拍内按"开口前 / 说话中 / 说话后"就近拆条（每条 4–15s·首尾帧承接·不切场景）

**表1 · 台词朗读时长（确定性·可复算）**
- 基准 **4 字/秒**（中文影视对白·含字间停顿·约 240 字/分）
- 标点加成：句末 `。！？` 各 **+0.4s** ｜逗号 **+0.2s** ｜破折号/省略号拖腔 **+0.6s**
- 公式：`台词秒 = 字数 ÷ 4 ＋ 标点加成`

**表2 · 动作 beat 时长（确定性）**
| 类型 | 例 | 秒/beat |
|---|---|---|
| 微动作 | 喉结滚、抿唇、眨眼、手指动、眼神移 | **1s** |
| 中动作 | 转头、抬手、递物、俯身、起身、走 1-2 步 | **2s** |
| 大动作/位移 | 扑、追两步、转身离去、蹲起、跌坐 | **3s** |

**表3 · 串行还是并行（横跳真凶）**
- 开口**前**为说话做铺垫的动作 = **串行**（计入）
- 说话**同时**进行的动作（手抖 / 走动 / 站立 / 落泪）= **并行**（取 max·不叠加）
- 说话**后**的反应动作 = **串行**（计入）

**演算范例（辩白拍·一看就会）**
> 老黄：喉结滚→扑身→抓豆→抓渣→举到脸前→（举着手抖）"我这作坊开了三代！一粒豆子都是挑过的！我往里掺这玩意儿干啥？"
> 铺垫 = 喉结1＋扑3＋抓豆2＋抓渣2＋举2 = **10s**（串行）
> 台词 = 28字÷4 ＋ `！！？`×0.4 = 7＋1.2 = **8.2s**（手抖 8.2s 并行·不另加）
> 一拍 = 10 ＋ max(8.2, 8.2) = **18.2s** → **>15s·拆 2 条**

**校准机制**：表 1/2 的常数为**工程经验初值**，**绝对真值靠实拍校准**——你实测后只改这里几个常数，全平台口径一起更新。本 §5.2 是估时**单一事实源**，调参在此处。

**派活铁律**：导演产出每一拍前，**必须对该拍套主公式算出秒数，并把"换算式"写进 production**（如 `10s铺垫 + 8.2s台词 = 18.2s → 拆2`）。**禁止采信剧本"约Ns"标注**（只算画面骨架、系统性低估对白与表演）。

## §6 avoid 负面约束（极速版：不写）

**极速版视频提示词不写 avoid 负面约束**——卡片只保留 卡片头 + 图片行（含"无字幕，无bgm"）+ 分镜动作链，整段直接复制粘贴。
（生图专属 avoid 如需要由服化道写进参考图提示词；视频提示词侧不写。）

## §7 提示词通用规范

### 铁律映射（详见本 skill 同目录的 seedance-prompt-methodology.md）
- 铁律 1（污染词）：禁用事件名/抽象概念 → 改具体动作
- 铁律 2（视觉元素替抽象）：背对/望向/注视 → 身体朝向+头部方向+眼睛焦点
- 铁律 3（前景营造）：按场景类型选择性使用（太空/闪回/多人需要·极简/情绪峰值不需要）
- 铁律 4（氛围粒子）：按场景绑定的粒子类型写入提示词

### token 预算
驱动词约 10-30 中文字。核心：一句话动作描述 + 全局修饰。精度靠图片数量提升，不靠文字长度。
