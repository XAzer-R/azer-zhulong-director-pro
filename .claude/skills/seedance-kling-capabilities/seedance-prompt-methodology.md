# 提示词组装方法论（极速版 · 导演执行层）

> 极速版分镜师已并入导演。本方法论是导演把镜头表组装成可用视频提示词的底层规则。
> **极速版要点**：视频提示词**不写风格前缀**（`Shot on ARRI…` 归服化道参考图）、**不写模型**（模型无关）、**不写线稿**、**不写 avoid**。
>
> ⚠ **卡片最终格式以模板为准**：见 `director-skill/templates/director-analysis-template.md`——**分镜动作链**（`- [C01]…`·按事件顺序·台词内嵌·可直接粘贴生视频）。本文件提供 AI 语义机制（污染词/视觉代偿）、三层前景等**方法论**（仍有效）；示例中的 `avoid …` 行**已作废**。
> ⚠ **不写精确秒数（2026-06-16 据 Seedance 官方文档校正）**：官方明确"模型对精确时间（如 0–3 秒）支持不稳定，强行限制时长可能导致生成结果异常"。**分镜用 `C01/C02/C03` 按事件发生顺序标识、不标秒**；总时长在生成时选档（4-15s）。注意名词分层：导演写的「镜头 S0N」= 一段戏剧表达 = 一次生成；其内的「分镜 C0N」= 官方所说的"镜头1/2/3"（一次生成内的硬切子镜头）。

[工作流总览]
    ```
    镜头表（景别/运镜/动作链/光影/台词已定义）
        ▼
    导演组装提示词卡片
        ├─ 上传清单（人物/场景/道具参考图·各自独立上传·不合成）
        ├─ 执行参数（驱动模式）
        ├─ 提示词正文（运动描述 + 运镜翻译）
        └─ 元数据（景别/运镜·意图追溯）
        ▼
    [用户手工流水线] i2v 平台跑视频 → 上传参考图（分开上传）→ 复制提示词 → 生成 → 剪辑
    ```
    **关键原则**：
    - 镜头表是提示词主体——组装时直接取用，不重写
    - 参考图各自独立上传（合成进 i2v 会被压缩，画面和人物都掉画质）
    - 提示词不重复参考图已锁定的信息（角色外观/服装/发型已在设定图中）

[第一性原则]
    - **导演意图优先**：提示词是技术翻译，不偏离画面意图、不自行添加未描述内容
    - **叙事描述式**：用完整段落描述，不关键词堆叠
    - **参考图已见原则**：i2v 模型能"看到"参考图——图片承担 90% 视觉信息，绝不重复参考图已有的静态内容；提示词只写运镜翻译 + 人物行动 + 台词；精度靠图片的**质量与精准对应**（官方建议 4-5 张最佳·**不堆满上限**），不靠文字长度
    - **一条提示词一段叙事**：一条对应一次生成；内可含多组连续镜头但叙事必须连续
    - **节拍密度（内部规划参考·不写进正文）**：每连续镜头内 1 拍 ≈ 2.5s，太密会糊/跳/不自然——用于判断一条放几个分镜，不把秒数写进提示词
    - **头尾安全区**：每次生成前 0.5s、后 0.5s 不放关键内容

[一个整体，不是一堆细节 — 提示词组织总纲]
    写每条提示词前，先一句话定这镜头的**整体感受**（他在忍 / 空荡的孤独 / 危险逼近 / 松了口气）。
    然后所有细节都**为这一个感受服务、往它靠**——宁可只写 2 个准的，别堆 5 个平的。
    - **选细节的标准**：观众感受这个整体时**余光会扫到**的那几个（喉结滚一下、指尖压白、呼吸停半拍），不是"他客观在做的所有动作"。
    - **自检**：读起来像清单（A、B、C、D 并列）= 错，模型会糊；读起来所有细节都在说**同一件事** = 对。
    - 这条统领下面的"一句一核心 / 不加噪声 / 情绪核心翻译"——它们都是这一条的具体做法。

[AI 语义理解机制 — 避开两大 bug]
    必读。无论镜头表多精准，不按本节翻译，i2v 会在两处反复失控。

    **机制 1 · 关键词污染陷阱**
    AI 看到某词就脑补整套刻板印象，**即使被否定也不例外**（写"不戴护士帽"仍把人放进医院；写"意识"违反物理生成大脑发光画面）。
    破解：**只描述具体动作/姿态/物体，不用事件名或抽象概念。**

    通用污染词黑名单 & 替代写法（按项目持续追加）：
    | ❌ 污染词 | AI 脑补陷阱 | ✅ 替代写法（具体视觉元素） |
    |---|---|---|
    | 意识 / 记忆 / 命运等抽象概念 | 生成大脑发光、神经元放电等抽象画面 | 描述具体物理表现（瞳孔收缩、手指无意识抽搐、监测屏波形变化） |
    | 望向 / 注视 / 凝视 / 看向 | 强行出正脸（眼睛必须可见） | 身体朝向 + 视线所及物体的具体描述（见机制 2） |
    | 背对 + 望向（叠加） | AI 妥协给侧身 | 拆成两条物理描述（见机制 2） |
    | 深空 / 太空 | 生成彩色星云壁纸风太空 | 漆黑背景，冷白针点恒星，无星云无彩色天体，纯粹黑暗 |
    | （题材专属事件名/生物名/设定名） | 生成好莱坞刻板造型 | 用具体物理特征描述（外形/材质/几何结构/光线），按项目在此追加 |
    使用规则：写提示词前对照黑名单自查命中即改；新发现污染词在段末"设计备注"记录，审核时决定是否追加。

    **机制 2 · 视觉代偿**
    AI 无世界模型，不理解抽象动作（背对/望向/注视/回眸/俯视），只画"对应的具体视觉元素"凑数；两个抽象动作叠加时画一个两者都能凑到的妥协姿态。
    黄金法则：**只描述画面能看到的视觉元素，不写抽象动作。**

    抽象动作 → 提示词翻译表：
    | 抽象动作 | 翻译（视觉元素描述） |
    |---|---|
    | 背对镜头望向某物 | 角色背对镜头站立；画面对应方向出现该物体的具体描述 |
    | 注视远处/凝视前方 | 身体朝某向，远景中呈现注视目标（具体物体） |
    | 俯视地面/低头看物 | 头顶、肩膀、颈部、地面透视占据画面 |
    | 回眸 | 侧身向右，头部左转，侧脸四分之三面向镜头 |
    | 跟着她/追上去 | 背影占据画面前景（后背+发丝+肩线），身后环境向前展开（跟拍） |
    | 望向窗外 | 角色朝窗户方向，窗外景物细节占据画面 |

    **用视觉元素密度控制景别/角度**（AI 对抽象景别词识别不稳，改用细节密度）：
    | 想要的效果 | ✅ 推荐写法（细节密度） |
    |---|---|
    | 特写面部 | 详细描述面部疤痕纹理/瞳孔/睫毛/皮肤毛孔 |
    | 中近景上半身 | 描述服装肩章/徽章/领口/颈部线条/锁骨 |
    | 全景 | 描述环境大尺度元素 + 人物作为小剪影 |
    | 俯拍 | 描述头顶/肩膀/背部/地面透视 |
    | 仰拍 | 描述下巴/颈部/服装下缘/天花板背景 |
    | 推进 | 逐分镜递增主体细节（轮廓→徽章→面部→瞳孔） |
    AI 按"哪里描述多"分配注意力——用这个机制控制景别。

[平台约束]
    - 单条生成：图片 ≤ 9 张（每张 <30MB）/ 视频 ≤ 3 个 / 音频 ≤ 3 个 / **总文件 ≤ 12**
    - 时长 4-15s；以上是每条生成限制，不是全文档；素材对应表 @图片 总数可超 9
    - **素材数量（官方建议）**：单条 4-5 个参考图最佳，**不建议用满上限**——素材过多反而降低一致性与可控性
    - **主体指代（官方建议）**：每次涉及主体都明确 @图 指代、不省略；多角色全程用统一标签（固定 @图N / 角色名），避免模型混淆
    - 不支持写实真人脸部素材（自动拦截）

[@ 引用语法]
    @图片1…（≤9）/ @视频1…（≤3）/ @音频1…（≤3）。务必明确每个引用作用（如"@图片1 作为首帧"、"场景参考 @图片3"、"参考 @视频1 的运镜"）。
    场景宫格每格独立编号为一个 @图片（不能整张宫格作为一个 @图片）。
    示例（4 人物 + 场景）：@图片1 人物·角色A / @图片2 人物·角色B / @图片3 人物·角色C / @图片5 场景·走廊（宫格格1）/ @图片7 场景·大厅（宫格格3）。

[三层前景结构 — 电影感核心铁律]
    i2v 默认画面是"真空感"（无前景遮挡/无氛围粒子，像塑料模型）。加"前景层"是告别塑料感的第一招。
    **硬规则**：除"极近特写"外，所有场景类型的提示词**必须有前景层描述**。
    写法：用自然语言描述三层，不用尖括号标签。
    ```
    前景（虚化）：[具体物体/粒子 + 失焦/虚化/严重散景 + 光线/位置]
    主体（实焦）：[核心人物/事件 + 焦点清晰/细节丰富]
    背景（柔焦）：[空间深度元素 + 柔焦/轻微虚化]
    ```
    关键词（必须出现否则不分层）：`失焦`、`虚化`、`严重散景`、`模糊`、`柔焦`、`完全失焦`。

    两类前景（按场景类型选，通用清单）：
    ① **物理遮挡型**：
    | 场景类型 | 前景元素候选 |
    |---|---|
    | 室内功能空间 | 设备边缘 / 面板框 / 管线 / 支架 / 栏杆 |
    | 太空舱内 | 控制台边缘 / 投影面板 / 终端支架 / 舷窗框 |
    | 太空外景 | 飞行器机身边缘 / 桅杆 / 散热鳍片 / 漂浮碎片 |
    | 室内生活空间 | 床铺边缘 / 屏幕反光 / 嵌入式小屏框 |
    | 室外/闪回 | 窗框 / 屏幕边缘 / 家具棱角 / 织物 |
    ② **氛围粒子型**（i2v 在粒子上有专项优化，用好效果拔群）：
    | 场景类型 | 氛围粒子候选 |
    |---|---|
    | 太空舱内 | 光束中尘埃 / 通风气流可见 / 投影微粒反光 |
    | 太空/星际 | 星尘颗粒 / 漂浮碎片 / 恒星眩光 |
    | 室内生活 | 阳光中微尘 / 屏幕反光散射 |
    | 闪回/回忆 | 暖色尘粒 / 低悬尘雾 / 光束中悬浮微粒 |
    反面警示：只写"前景有管线"→ 会和主体同样清晰、层次丢失；必须明写"失焦/严重散景"+ 具体材质/光线。
    组合：前景虚化 + 镜头缓掠前景 → "从遮挡后窥视"视角；前景实焦→拉焦→主体实焦 = 调焦叙事。

[提示词范式]
    **核心认知**：参考图承担 90% 视觉信息；提示词通过景别+运镜元数据追溯意图，正文写运动描述 + 运镜翻译 + 人物行动 + 台词。精度靠参考图数量质量，不靠文字长度。

    **提示词卡片结构**：
    ① 上传清单（参考图分开上传）② 执行参数（驱动模式）③ 提示词（元数据 景别/运镜 + 运动描述）④ 台词（独立标注供审核·同时写入提示词）

    **提示词格式**（极速版·无风格前缀·无模型·无线稿）：
    ```
    **景别**：[景别]
    **运镜**：[运镜方式] → [情绪映射]
    无BGM无字幕。[全局修饰]。角色为{{@图X}}。场景为{{@图Y}}。
    [动作链内容·直接取用·污染词已替换]。[运镜翻译（按 storyboard-skill 运镜翻译表）]。[台词（如有）]。
    ```
    **写作规则**：
    - 动作链直接取用仅做污染词替换；运镜按运镜翻译表翻译；人物行动提取情绪核心译为物理动作（见 storyboard-skill 情绪核心翻译原则）
    - 台词角色说话时写入提示词；static 运镜不写运镜只写人物行动
    - 不重复角色外观/场景/光影（参考图已锁）；不写情绪/氛围/音效（后期的事）
    - **不写风格前缀、不写模型、不写线稿**

    **三个精度层级**：L1 场景图+角色图+提示词（微动作/单一变化·首帧）· L2 场景图两角度+角色图（A→B 运镜/焦点·首尾帧）· L3 多张有序场景图（多阶段精确控制）。

    **多 clip 结构**（复杂动作必用）：大幅姿态切换 / 位移 >1/3 画幅 / 场景状态变化 / >2 离散动作 / 景别切换 → 拆 C01/C02/C03，每 clip 一句话一个核心动作。入画出画用方位词。

    **完整示例**（无风格前缀）：
    ```
    微动作（L1·static）：
    **景别**：近景  **运镜**：static → 冷静·客观
    无BGM无字幕。手持模拟。角色为{{@图1}}。场景为{{@图5}}。
    角色微微地抬了一下头。

    动作+运镜（L1·track）：
    **景别**：中景  **运镜**：track 侧跟 → 伴随·沉浸
    无BGM无字幕。角色为{{@图1}}。场景为{{@图3}}。
    镜头侧面跟随，角色A 面部毫无表情变化，脚步节奏均匀如节拍器，穿过走廊的明暗交替区域。

    多步动作（多 clip·handheld）：
    **景别**：中景  **运镜**：handheld 手持 → 真实·纪录片感
    无BGM无字幕。手持模拟。按照{{@图1}}严格保持角色一致性。场景为{{@图5}}。
    C01：角色走向操作终端，左手悬浮于触感界面上方。
    C02：角色手指轻触界面，全息投影展开数据。
    C03：角色收回手，侧头看向舷窗。

    含台词（L1·static）：
    **景别**：中近景  **运镜**：static → 冷静·客观
    无BGM无字幕。角色为{{@图1}}。场景为{{@图5}}。
    角色A 低头看着数据终端，微微抬头说"它在试图和我们交流，但不是用我们理解的方式"。
    **台词**：@角色A："它在试图和我们交流，但不是用我们理解的方式"

    推镜头（L2·首尾帧）：
    **景别**：中景 → 近景  **运镜**：slow dolly in → 聚焦·进入内心
    无BGM无字幕。角色为{{@图1}}。场景起始为{{@图5-A}}，场景终止为{{@图5-B}}。
    镜头缓慢向前推近，角色A 嘴唇抿紧，眼神从空洞变为聚焦。
    ```

    **驱动词精度控制**：
    - **强弱词配合**：每个运动元素一对强词（定义动作：下落/抬起/转头）+ 弱词（控制质感：极缓/轻微/稳定/克制）。缺强词→不知做什么；缺弱词→幅度失控。
    - **三层递进**：① 构图锁死（保持构图或描述运镜）② 背景氛围（强弱词对）③ 主体微动作（精确到每个可动部件）。
    - **减法控制**：肯定主句 + 排除清单明确什么不动（"主体身体保持静止，肩颈几乎不动"）。

    **台词规则**：写入提示词 + 独立"台词"字段标注；原剧本台词零丢失；补充台词 `[补]`；驱动 ≥8s 且无台词又无静默理由时检查是否应补。

[运镜/动作/速度词汇]
    运镜按 storyboard-skill `[运镜翻译表]` 翻译。景别（极致特写/面部特写/中近景/中景/全景/远景）、推拉/横纵摇/环绕/跟拍/升降/高级运镜（希区柯克变焦/鱼眼/仰拍/鸟瞰/主观视角/快速摇/机械臂跟随）/手持与固定。
    动作词：面部（睁眼/微笑/目光转移/咬唇）、头部（转头/点头/抬头）、身体（呼吸起伏/前倾/站起）、手部（举手/握紧/比划）、环境互动（发丝飘动/烟雾升起/尘埃飘浮）。
    速度修饰：缓慢/轻柔 · 平稳/自然 · 快速/突然。

[转化步骤]
    1. 上传清单：从镜头表角色/场景确定参考图（分开上传）；首尾帧确定两个场景角度
    2. 精度层级和驱动模式：微动作→L1 首帧 / A→B→L2 首尾帧 / 多阶段→L3
    3. 是否拆 clip：单一动作不拆 / 大幅姿态切换/多离散动作 → 拆
    4. 组装提示词：全局修饰→引用声明→动作链内容→光影补充→运镜翻译（动作链直接取用仅替换污染词，不重复参考图信息）
    5. 台词：写入提示词 + 独立字段；零丢失·补充 `[补]`

[禁忌规则]
    - 单独否定指令（"不要移动"→"保持静止"）；允许肯定主句+排除清单的减法控制
    - 不重复参考图已有静态内容 / 不合成参考图 / 不重写动作链（仅替换污染词）
    - 不用抽象概念（"体现自由"→具体动作）/ 一条提示词不塞不相关场景
    - @引用必须指定用途 / 不上传写实真人脸部素材
    - **不写风格前缀、不写模型、不写线稿**

[音频/BGM]
    **音频不写入视频提示词**——只管视觉运动。统一写 `无BGM无字幕`。音频/BGM 见 `sound-design-skill`（仅供导演叙事规划和后期剪辑参考）。
