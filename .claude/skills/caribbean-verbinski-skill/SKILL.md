    ## 轨 A · 画面 look（Wolski 摄影签名 · 四个光世界）
    《加勒比海盗》的画面不是一种光，是**四个截然不同的光世界**轮换——这是它"高级"的根：
    | 光世界 | 是什么 | 落地关键（写进参考图底 / @图N 渲染） |
    |---|---|---|
    | **加勒比白日** | 阳光晒透的热带：绿松石海水、白沙、过曝天空、暖肤色 | 高调暖光·turquoise 海 + warm skin·镜头光晕·海面波光 |
    | **烛光船舱** | 油灯/烛火的船舱：金色光池、深木色阴影、地图与酒 | 暖金低长调·practical 烛光火源·深棕阴影·木纹质感 |
    | **诅咒月光** | 超自然冷月光揭示骷髅/亡魂：去饱和银蓝、阴森 | 冷蓝月光·rim light 描边·去饱和·骨白与暗 |
    | **风暴海战** | 漩涡/海战/雨夜：蓝灰、海沫、闪电、火炮橙光 | 蓝灰高反差·雨幕海沫·闪电瞬亮·炮火暖橙刺破冷调 |
    > 共性签名：**2.39:1 scope 宽银幕（变形质感·椭圆焦外/横向光晕，作为画面观感词；该系列实为 Super 35 球面镜头裁切 scope，非真变形镜头拍摄） · 做旧质感（盐渍木/锈铁/湿绳/破帆/铜绿金币/旧皮革）· 实用火源（火把/烛/炮火）· 胶片颗粒 + 高光辉光 halation · 戏剧性天空（金色时刻/风暴云/逆光船剪影）**。

    ## 调性 · 维宾斯基三味（魂）
    **冒险浪漫**（磅礴、向往自由的海）＋ **痞气幽默**（杰克船长式的歪打正着、贫嘴、滑稽时机）＋ **鬼气奇观**（诅咒、骷髅、深海亡魂的哥特恐怖）。三味缺一不是加勒比。

[三 · ★情节类型战术手册（核心·导演按戏查表）]

    每类给：**主光世界（轨 A） · 运镜（轨 B） · 节奏 · production 落地（运镜意图 + 分镜动作链 [C0N]） · 适配提示**。
    ⚠️ i2v 视频**不含音频**——Zimmer 的"推进感"落地为两层：①**动作设计层**：把战斗/航行的关键 beat（开炮/中弹/桅杆折断/船倾覆/拔剑/命中）写成清晰节奏点，按事件顺序写进 production 动作链 [C0N]，由 i2v 生成动作运动；②**后期剪辑层**：写进 production「后期参考·节奏」（磅礴管弦·乐章式推进·关键转折落乐句重音），剪辑时把切点踩到音乐推进上。**production 只写画面与运动，不写音乐。**

    ## ① 海战 / 炮战 Sea Battle（磅礴 ●●●●）
    - **主光世界**：风暴海战（蓝灰高反差·雨幕海沫·闪电·炮火暖橙刺破冷调）。
    - **运镜**：大幅 crane/航拍掠过两船甲板与桅杆揭示战场、低水位贴海面看船身擦过、开炮瞬间急推炮口、中弹处木屑飞溅 snap、桅杆折断仰拍。
    - **节奏**：establishing 大调度松 → 接舷/开炮密；每记炮火/折桅/跳帮踩一个推进 beat；乐章式起伏不是机枪快剪。
    - **production/i2v 落地**：拆成一组 i2v 片段（船身擦过 / 开炮 / 中弹木屑 / 跳帮各成段奇观运动），每条动作链按事件顺序写战斗节拍（瞄准→开炮→命中木屑→船身震）；速度感靠低机位贴浪 + 海沫前景飞溅 + 火光照亮雨幕。
    - **适配提示**：没有两船对轰时，单船遇风暴 / 被炮击的逃逸也走本表，重点是"海与船的体量感"。

    ## ② 甲板剑斗 Sword Duel（冒险 ●●● × 痞气 ●●●）
    - **主光世界**：加勒比白日（高调暖光·海面波光）或烛光船舱（金调）。
    - **运镜**：贴身 steadicam/handheld 跟着剑来剑往在甲板/索具/桅杆间流动的一镜流，人物上下穿梭打斗；关键命中/缴械 snap 到中近景；杰克式歪打正着留一拍喜剧时机。
    - **节奏**：尽量用长镜展现连贯剑势（动作遮剪），仅关键交锋/缴械踩拍 snap；痞气段故意慢半拍"作"。
    - **物理**：剑刃碰撞有重量、有火星、有受力踉跄；荡绳索/翻桅杆借力真实。
    - **production/i2v 落地**：长连贯剑斗拆成一组 i2v 片段，每条动作链按事件顺序写招式节拍（格挡→反手→荡绳借力→缴械）；speed ramp 处慢放剑火星迸溅的奇观瞬间；穿梭索具走 crane 跟随 + 衣摆/海风飞扬。
    - **适配提示**：杰克船长式"打不过就跑/歪招取胜"＝痞气剑斗，取**滑稽机变 > 硬桥硬马**；正派对决取**优雅凌厉**。

    ## ③ 索具追逐 / 跑酷 Rigging Chase（冒险 ●●● × 痞气 ●●●）
    - **主光世界**：加勒比白日（阳光·过曝天空·逆光索具剪影）。
    - **运镜**：FPV 贴身跟攀爬、荡绳索侧跟、桅杆纵跃 crane up、落甲板低机位一沉、海面波光前景掠过的速度感。
    - **节奏**：每个荡绳/翻越/落点踩一个 beat；连贯攀爬用长镜，跨大跨度处 snap。
    - **物理**：荡绳的钟摆惯性、踩索的晃、落甲板的冲击——真实重量。
    - **production/i2v 落地**：连贯追逐拆成一组 i2v 片段，每条动作链按事件顺序写路径节点（抓绳→荡出→翻桅→落甲板）；速度靠 crane 跟随 + 海风衣摆 + 逆光索具前景飞掠。
    - **适配提示**：甲板间追逐、码头桶堆翻越同理；可叠痞气幽默（边逃边贫嘴/顺手偷东西）。

    ## ④ 风暴漩涡 Maelstrom / Storm（磅礴 ●●●● × 鬼气 ●●）
    - **主光世界**：风暴海战（蓝灰·雨幕·闪电瞬亮·海沫漫天）。
    - **运镜**：镜头随漩涡/船身倾覆螺旋翻转、荷兰角失衡、随浪起伏的失重感、揭示巨浪/敌船。
    - **节奏**：螺旋推进感拉满、混乱密；闪电劈下/巨浪砸甲板/船身倾覆各占一个重 beat。
    - **production/i2v 落地**：螺旋翻转拆成几段 i2v（绕船环绕 + dutch tilt），每条动作链写灾难节拍（浪起→船倾→人抓索→浪砸下）；失重靠 dutch 角 + 海沫飞溅 + 闪电频闪照亮。
    - **适配提示**：单条 i2v 难一气呵成的大漩涡 → 拆多条 + 创意转场（入浪黑场/海沫遮挡）缝合，见 `long-take-skill`。

    ## ⑤ 烛光船舱文戏 Cabin Drama（冒险 ●● × 痞气 ●●·杰克味）
    - **主光世界**：烛光船舱（暖金低长调·practical 烛火·深木阴影·地图/酒/罗盘道具）。
    - **运镜**：稳、缓、克制；中近景/特写承载微表情与道具（罗盘指针/酒瓶/地图）；少运镜给表演与痞气台词空间。
    - **节奏**：放慢、长镜、留白；杰克式贫嘴的喜剧停顿；情绪/笑点未到不切。
    - **production/i2v 落地**：微表情物理化（挑眉/晃酒瓶/罗盘指针乱转）；烛光在脸上跳动的暖光；不炫技、靠表演与光氛围。
    - **适配提示**：谈判/算计/暧昧/独白都是船舱文戏；痞气角色给喜剧节拍，正派给暖情。

    ## ⑥ 月光诅咒奇观 Cursed Reveal（鬼气 ●●●● 满）
    - **主光世界**：诅咒月光（冷银蓝月光·去饱和·rim 描边·骨白与暗）。
    - **运镜**：缓推到揭示瞬间（人走进月光→皮肉褪成骷髅）、恐怖反应反打、缓慢横移揭示暗处亡魂。
    - **节奏**：缓、悬、屏息；揭示那一下骤然清晰；静（潜伏）松、揭示（窗口）凝。
    - **物理/奇观**：月光区＝骷髅/腐烂揭示，暖光区＝正常皮肉——**用光的明暗边界讲诅咒**（核心奇观逻辑）。
    - **production/i2v 落地**：揭示拆成走入月光的运动 i2v（皮肉→骨的过渡靠月光边界）；rim 光描骷髅轮廓；恐怖靠缓推 + 月光冷调 + 去饱和。
    - **适配提示**：任何"超自然揭示"（亡魂/诅咒/变形）都套本表——关键是冷月光 vs 暖实光的二元对照。

    ## ⑦ 海盗登场亮相 Pirate Reveal（痞气 ●●●● 满）
    - **主光世界**：加勒比白日（逆光/暖光·港口/桅杆背景）。
    - **运镜**：低角度英雄仰拍显气场、缓推到亮相定格、痞气慢半拍的喜剧时机（船沉了还淡定踏上码头那种反差）、剪影定格。
    - **节奏**：登场留一拍让人物"作"出性格（叼酒/整帽/斜睨）；反差幽默 beat（狼狈中的从容）。
    - **production/i2v 落地**：低机位仰拍 i2v 显气场；登场定格用逆光轮廓光（见 cinematography-skill/styles/_风格方法论与库.md §C·逆光轮廓光 Rim Light）；痞气靠一个标志性小动作（晃罗盘/扶帽/咧嘴）。
    - **适配提示**：正派登场取"英雄仰拍磅礴"，反派/痞子取"痞气反差幽默"。

    ## ⑧ 海上 establishing / 磅礴大远景 Establishing（磅礴 ●●●●）
    - **主光世界**：加勒比白日（金色时刻）或风暴海战。
    - **运镜**：极缓 crane/航拍 establishing，帆船驶入金色海面或风暴，满构图铺海与天；镜头可微抬揭示天空体量。
    - **节奏**：极缓铺陈、留呼吸、史诗体量感；纯立世界、不接战（与①海战段开头的 establishing 大调度区别：这条只定调海的辽阔、不进入战斗）。
    - **production/i2v 落地**：单条缓推/缓 crane i2v，动作链按事件顺序写「船入画→满构图铺海与天→（可选）镜头微抬揭示天空」；体量感靠极缓机位 + 海天满幅 + 渺小船衬大海。
    - **适配提示**：开场/转场/章节起手用，定调海的辽阔与冒险召唤。

[五 · 落地到 production（导演怎么把它写进交付）]

    **0. 项目 setup（选定本风格时一次性做·关键）**：把 §四 四个光世界前缀块（① 加勒比白日 / ② 烛光船舱 / ③ 诅咒月光 / ④ 风暴海战，各含通用基底句）逐条转录进项目 `assets/cinematography-bible.md` 的风格前缀块章节。**因为服化道写底、分镜师渲染 @图N 都只读 bible、不读本 skill**——四光世界细节必须落进 bible 才到得了这两个轨 A 消费者，否则他们只拿得到风格库里的短条目。转录后 production 在「场景与光影」标 💡光世界，分镜师据此从 bible 取对应前缀渲染。

    2. **production「运镜」列**：写 §一轨 B 招牌运动名（如"甲板剑斗一镜流""海战横摇大调度（crane/航拍）""风暴漩涡螺旋（dutch tilt）""奇观揭示推（缓推）"）。
    3. **分镜动作链 [C0N]**：关键 beat 按事件顺序写清（开炮/中弹木屑/拔剑/缴械/走入月光揭示骷髅），不写秒级时间戳，给 i2v 明确运动锚。
    4. **变速标注**：剑火星/中弹/巨浪砸下处用 `[V0N]` 写"慢动作强调 X，随即恢复常速"。
    5. **「后期参考·节奏」薄章节**：写"磅礴管弦·乐章式推进·关键转折（开炮/揭示/登场）落乐句重音"——给后期剪辑师踩音乐推进，不是卡点快剪。
    6. **三味剂量自检**：每段问"这段冒险/痞气/鬼气各几颗●？"（查 §二剂量表）——海战拉满磅礴、登场拉满痞气、诅咒拉满鬼气。
    7. **production 只写画面与运动**：不写音乐、不写风格前缀块（轨 A look 归服化道底·i2v 从 @图N 继承）。
