# 导演统一审核技能（专业版 · 三阶段）

[技能说明]
    专业版 = 极速版 + 分镜师增强，共用同一条视频主干。审核为**三阶段**：
    - **阶段一 · production 审核**（§1）：导演自审自己一次成型产出的 production（剧情拆解 + 镜头设计 + **i2v 视频提示词卡片**：景别/运镜/**驱动模式** + **分镜动作链 [C0N]** + 台词内嵌 + 上传@图）。这是用户在用的视频出口。
    - **阶段二 · 服化道审核**（§2）：导演跨阶段审 art-designer 产出的**身份级底**（身份级风格进底·**大平光高可读·底干净不焊光影/氛围/质感**——那些留给分镜师三道洗）
    - **阶段三 · 分镜师渲染审核**（§3）：导演审 storyboard-artist 在服化道底上的渲染——**三道洗（质感→光影→氛围）→ 精修关键帧 `<段号>-storyboard.md`（@图N 渲染卡）**，identity 不漂、**可喂导演 production 的 i2v 当首帧**

    **审核执行者 = director**（自审同 agent 内生成+审核）。

    **加载策略**：按任务类型精读对应章节 + §0 通用原则（阶段一读 §0+§1，阶段二读 §0+§2，阶段三读 §0+§3）。

    **不产出独立审核文件**。自审作为内部质控流程，得分摘要在 director 返回消息中汇报给主 Agent。

---

## §0 通用审核原则

[审核立场] 你的任务是**找出问题**，而非确认通过。批判性逐行比对 / 脑内预演 / 逐项评分。

[流程] 1. 读上游+被审对象+依赖素材 → 2. 逐行比对（弱化/遗漏/偏离）→ 3. 脑内预演（想象生成效果）→ 4. 逐项评分 → 5. 特殊核对 → 6. 输出。

审核最多修订两轮；仍失败则保持 FAILED，交用户决策，禁止自动进入下一阶段。

[评分] 9-10 精准免改 · 7-8 基本到位有 1-2 处可改 · 5-6 明显问题需改 · 1-4 严重不足。

[输出规范]
    PASS：✅ **审核：PASS** + [评分表] + 整体评价（1-2 句）
    FAIL：❌ **审核：FAIL** + [评分表] + 业务问题（位置/当前问题/修改方向）+ 修改优先级（🔴 必须 / 🟡 建议）

## §1 阶段一 · production 审核（剧情拆解 + 镜头设计 + i2v 视频提示词卡片）

[审核对象]
    `outputs/<集号>/<段号>-production.md`（**i2v 视频提示词卡片**：景别/运镜/驱动模式 + 分镜动作链 [C0N] + 台词内嵌 + 上传@图 + 角色走位 + 节奏曲线 + 人物清单 + 场景清单 + 薄后期参考）。
    **这是用户在用的视频出口**——production 就是可直接喂图生视频工具（Seedance/可灵/即梦等）的 i2v 提示词。i2v（驱动模式 / 分镜动作链 [C0N]）是**正品**，缺了才是问题。

[审核前必读]
    - 对应剧本段（从 `script/EPNN.md` 提取本段内容，逐行比对基准）
    - `assets/cinematography-bible.md`（场景映射 / 负面约束 / 配色基调）
    - `assets/asset-index.md`（@引用核对·服化道未完成时占位可接受）

[结构瘦身核对]（违反为"必须修改"）
    □ production **不得**包含全剧恒量（摄影机基准/画幅规则/配色基调/风格前缀块）——这些在 cinematography-bible，由服化道写身份级底、分镜师渲染时取。
    □ 每个剧情点**必须**有"场景类型"标签（对应 director-skill 场景类型枚举；新场景标 `⚠ 新场景类型：XXX`）。
    □ **视频提示词不得写**：风格前缀块（`Shot on ARRI…` 归服化道身份级底）、模型字段、线稿、摄影机参数、avoid 负面约束、质感/光影/氛围的洗图执行（归分镜师三道洗·阶段三）。出现即"职责错位"，要求删除。
    □ **分镜动作链按事件顺序、不写秒级时间戳**：出现 `[0-3s]` 这类秒标即扣分（官方：模型对精确秒数支持不稳定）。镜头运动展开成分镜动作链 `[C0N]` 是**正品**，不是违规——别把 i2v 概念当残留删掉。

[A · 剧情拆解准确性]（每个剧情点评分 1-10）
    □ 逐行比对完整性 / 叙事完整性 / 合并拆分检查（剧情点 P01/P02 划分是否合理）
    □ 镜头覆盖率：每个剧情点的剧情是否都被卡片覆盖（常遗漏收尾镜）
    □ 省略检查：是否有应省略的无信息位移
    □ 出处反现编：人物/场景/世界观清单每条是否带〔出处:SNN PNN〕，从镜头/台词/场景派生，无现编

[B · 镜头设计合理性 + 卡片字段完整（i2v 视频提示词）]（每个剧情点评分 1-10）
    逐镜核对（违反扣分·系统性缺失=FAIL）：
    □ **卡片字段完整**：每镜含 景别/机位/运镜/**驱动模式（首帧/首尾帧/续写）**/焦点/叙事功能 + **分镜动作链 [C0N]** + **台词内嵌（有台词时）** + 表演走位 + **上传@图（分类分行）**，缺项扣分
    □ **主体优先组织**（见 director-skill「主体优先组织律」checklist）：每镜是否立住**唯一绝对主体 + 核心动作**？客体/背景/光影是否标"为主体服务·不抢镜"、弱化干扰项？**元素平铺、主体被环境/光影淹没、一眼锁不定该看谁 = 扣分**（AI 视频靠挑重点·干扰多就丢主体）
    □ **驱动模式必填**：每张卡片标驱动模式（首帧 / 首尾帧 / 续写）；缺失 = 卡片不可执行 = 扣分。驱动模式是 i2v **正品字段**，不是该删的视频概念
    □ **分镜动作链 [C0N]**：正文是否为 `- [C0N · 景别 · 运镜] 动作描述` 的分镜动作链？**按事件顺序、无秒级时间戳**（出现 `[0-3s]` 即扣分）？动作物理化、污染词已替换？这是 i2v 的运动表达**正品**，缺了即问题
    □ **景别规范**：景别 + 角度（正/侧/3-4/背），取值在枚举内（极近特写…OTS/鸟瞰/POV）
    □ **机位规范**：高度（平视/仰拍/俯拍）+ 必要角度说明
    □ **运镜元数据**：每张标景别 + 运镜（static/slow dolly in/pan/tilt/track/orbital/rack focus + 速度，或圣经指定的招牌镜头名）+ 情绪映射
    □ **焦点字段**：锁定对象 / rack focus 起点→终点 / 景深倾向是否标注
    □ **视觉代偿**：括号情绪注记 `（...）` 是否翻译为物理微动作（不允许抽象情绪直接入提示词）
    □ **叙事功能强制填写**：每镜有叙事功能（建立/揭示/对峙/冲击/静止/蒙太奇…）；写不出功能=不该拍
    □ **运镜多样性**：连续 2 个以上镜头不得使用相同运镜
    □ **30 度法则**：相邻镜头拍同一主体角度变化 > 30°
    □ **走位**：角色走位用自然语言相对位置（"院门口""坛阵那头"），不钉画面占比%/坐标
    □ 武打段落（仅）：动作四维度具体 + 关键打击"蓄力-爆发-落点"三拍

[C · 提示词合规]（违反扣分）
    □ **无风格前缀**：视频提示词不得以 `Shot on ARRI…` 风格前缀开头（归服化道身份级底）
    □ **无模型/无线稿**：卡片不含模型字段、不含线稿
    □ **无 avoid**：卡片不含 avoid 负面约束（视频提示词不写）
    □ **分镜动作链不写秒级时间戳**：按事件顺序，无 `[0-3s]` 这类秒标
    □ **上传@图齐全**：`@图N` 角色/场景是否齐全（服化道未完成时占位是否标注待回填）

[D · 台词零丢失]
    □ 逐条比对剧本台词 → 每句**内嵌进对应镜块**（`@角色："原文"`·原文照搬·零丢失，不单列台词字段）；遗漏=FAIL；补充创作台词标 `[补]`，原著台词不挂标签

[E · 节奏曲线]
    □ 有节奏曲线（≥3 镜段画曲线形态 + 各剧情点落点；单镜段一行说明）
    □ 镜头密度服从曲线：对照场景类型检查密度（动作密·对话中·沉思疏），用镜头数与切点密度表达，不钉死秒数
    □ 平行剪辑/对位结构命中时有「结构标注」+「剪辑装配表」（装配序按成片序交错）

[F · 人物/场景清单 + 后期参考]
    □ 人物清单：筛选合理性 / 外观可设计性 / 素材状态标注（复用/变体/新增）/ 带〔出处〕
    □ 场景清单：完整性 / 环境可设计性 / 光线色调 + 氛围关键词 / 素材状态 / 带〔出处〕
    □ 后期参考：环境音/音效/沉默/听觉记号薄留且**未混入视频提示词正文**

[G · 段尾衔接]（非最后一段必有）
    □ Handoff 级别（L1/L2/L3）+ 理由 / 尾帧状态（角色@图N方位姿态 + 环境持续状态）/ 跨段可复用素材；最后一镜标"→下一段/段结束"

[评分表]
    | 剧情点 | 剧情拆解 | 镜头设计 | 卡片字段 | 提示词合规 | 台词完整 | 节奏曲线 | 段尾衔接 | 均分 | 问题摘要 |
    |--------|---------|---------|---------|-----------|---------|---------|---------|------|---------|
    | P01    | 9       | 9       | 9       | 9         | 10      | 9       | 9       | 9.1  | 无 |
    人物清单：X/10 · 场景清单：X/10 · **剧情点平均分：X.X/10**

## §2 阶段二 · 服化道审核

[审核对象]
    `assets/character-prompts.md` 和 `assets/scene-prompts.md` 中本集新增内容

[审核前必读]
    - 本集各段 production（`<段号>-production.md`）的人物清单和场景清单
    - 既有素材（风格一致性参照）
    - `assets/cinematography-bible.md`（配色/光源规则 + 风格前缀块）+ `visual-style-presets.md`（风格前缀块）

[服化道定位]
    服化道出的是**身份级底**：身份级风格进底（机型/造型/材质 DNA·辨识度），**光影/氛围/质感不进底**——底要干净、大平光、高可读，给分镜师三道洗留干净基面。底焊死光影氛围 = 越界，分镜师没法洗。

[审核流程]
    1. 建立整体理解（人物/场景清单 + 待审产出）
    2. 逐项比对（每个人物/场景对照清单外观关键词，找遗漏/偏离/矛盾）
    3. 脑内预演（想象丢进文生图工具的生成效果）
    4. 逐项评分

[验收清单]
    人物造型提示词（每人评分 1-10）：与清单一致性 / 辨识度（身份级 DNA）/ 描述精确 / 细节完整 / 风格匹配 / 格式可执行
    □ **风格前缀块**：每张人物/场景提示词顶部是否带"风格前缀块"（身份级风格前缀 + 生图 avoid）？缺失 = FAIL
    □ **生图 avoid 正确**：是否含生图专属 avoid（text overlays/HUD/手指/水印）？是否**误把动态约束**（jitter/identity drift 等视频概念）写进生图？
    □ **身份级底干净**：人物/场景底只出**大平光高可读** + 结构清晰 + 身份级风格DNA，**不焊光影/氛围/质感效果**（那些留给分镜师三道洗）；出现戏剧布光/体积雾/情绪调色/PBR质感细节＝越界扣分（底焊死了分镜师没法洗）
    场景环境提示词（宫格整体 1-10）：逐格与清单一致性/空间/关键元素；整体覆盖完整/宫格规格/格间风格一致/格式可执行
    跨集一致性（EP02+·不评分）

[阶段二注意事项]
    文生图（Nano Banana 等）高频注意点：避免"神似某真人"的面部描述、避免具名品牌 logo、避免政治/敏感宗教符号。

## §3 阶段三 · 分镜师渲染审核（三道洗 → 精修关键帧 @图N · 喂导演 i2v 首帧）

[审核对象]
    `outputs/<集号>/<段号>-storyboard.md`（每镜一张**精修关键帧 @图N 渲染卡**：在服化道身份级底上 → 三道洗[质感→光影→氛围] → 精修关键帧 + 上传@图 + avoid + 运镜旁注）。
    **关键帧定位**：@图N 是**喂导演 production 的 i2v 当首帧**用的精修帧——不是给 CG/动画团队的静帧终产物。审核要确认它渲染到位、identity 不漂、可直接当 i2v 首帧。

[审核前必读]
    - 对应段 production（`<段号>-production.md`·production 是关键帧的主体，逐镜比对基准）
    - `assets/character-prompts.md` 和 `scene-prompts.md`（本集服化道身份级底·@图N 核对）
    - `assets/cinematography-bible.md`（风格前缀块基准·必读）
    - `assets/asset-index.md`（@引用核对）

[结构核对]（违反为"必须修改"）
    □ **不混入 i2v 卡片字段**：分镜师关键帧渲染卡是出**精修帧**的（图层渲染），**不重写** production 的驱动模式/分镜动作链 `[C0N]`/时长——那些是导演 production 的事，分镜师只把镜头运动以**运镜旁注**形式带住、出静态首帧。注意：i2v 本身是正品（在 production 里），这里只是分工边界——关键帧渲染卡不是不许有 i2v，而是 i2v 的运动参数归 production、关键帧只出首帧画面。
    □ **风格前缀已写（生图硬规则）**：每张关键帧卡是否带风格前缀（取自 bible/服化道身份级底统一登记的同一条）？缺失 = FAIL（关键帧是生图，必写）。服化道未配置时用占位 `[风格前缀·待 bible 回填]` 并在文末诊断标注，可接受。

[A · 镜头全覆盖]（评分 1-10）
    □ **镜头覆盖率**：production 每一镜是否都有对应关键帧（常遗漏最后 1-2 镜）= 系统性缺失为 FAIL
    □ 不重写导演意图：景别/机位/运镜/焦点/叙事/画面瞬间/构图直接取用 production，分镜师只出图渲染 + 三道洗，无擅自改写

[B · 画面瞬间贴合叙事 + 三道洗到位]（每张卡片评分 1-10）
    逐张核对：
    □ **画面瞬间选取**：是否把导演镜头的动作过程**定格成最具叙事性的一帧**（写此刻姿态/表情/走位/手部的静态截面，作 i2v 首帧用，不写"他走过去然后……"）？
    □ **台词镜定格**：台词镜是否定格在台词最有张力那一刻的口型/神态？
    □ **视觉代偿（抽象→物理）**：括注情绪 `（...）`、抽象动作（望向/凝视/背对）是否翻译为身体朝向 + 头部方向 + 视线所及物体的具体物理描述？污染词是否已替换？
    □ **一句一核心**：每张关键帧只画一个情绪核心，承载情绪重量的姿态/微表情放句首；无添加 production 未描述的动作/元素（噪声）
    □ **构图完整**：占比 + 位置 + 朝向 + 前中远景分层（除极近特写外三层到位·缺层=画面扁平）
    □ **三道洗顺序到位（质感→光影→氛围）**：① 质感（material-pbr·菲涅尔/粗糙度差异/AO·非空词）② 光影（主光方向·色温 + 对比 + 边缘光·承接导演影调意图）③ 氛围（雾/粒子/调色·点到为止）；三道按序、在服化道干净底上洗；同段/跨段同场景光线一致

[C · identity 不漂 + 风格前缀正确]（评分 1-10）
    □ **identity 不漂**：三道洗后角色身份级特征（面部/造型/材质 DNA）是否仍与服化道身份级底一致（洗光影氛围不该改身份）？漂了 = 回信息版/底图重出，不在洗图层硬修
    □ 风格前缀**原样引用** bible/服化道统一登记的同一条（不自由发挥、不每镜各写一套）
    □ 风格前缀块只覆盖**身份级**视觉 DNA（机型/材质身份/胶片/画幅/颗粒），保证关键帧身份级风格统一；调色/色温/对比/大气/戏剧光影属分镜师三道洗·**不在前缀**（身份级↔光影氛围分界·见 art-design-skill）

[D · 上传素材 · 参考图分开上传]（评分 1-10）
    □ **分开上传**：场景图、人物图、道具图各自独立上传（合成=FAIL·合成会压缩画质和 identity）
