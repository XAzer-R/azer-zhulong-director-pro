# 大友启史 × 埃德加·赖特 · 融合风格方法论（时尚动作怪盗 DNA）

[技能定位]
    这是一套**导演执行层（运动 / 剪辑 / 节奏）**方法论，不是画面生图前缀（画面 look＝轨 A·见 cinematography-skill/styles §B·归服化道生图；本 skill 管轨 B·运镜剪辑——两轨分工不混）。
    融合两位导演的核武器，专治"时尚怪盗 / 都市动作轻喜"题材（Cat's Eye 现代真人版那一挂）：
    - **大友启史**（《浪客剑心》真人版）＝ 动作的**华丽真实流畅** + **人物温情内核**
    - **埃德加·赖特**（《极盗车神》Baby Driver / 《僵尸肖恩》）＝ **节奏剪辑卡点** + **时髦幽默韵律**
    合成一句话：**「有重量感的华丽动作，踩着节拍剪出来，时髦幽默又走心。」**

[一 · 两位导演核武器拆解（先认武器，才会融合）]

    ## 大友启史 · Keishi Otomo（动作骨架 + 温情内核）
    | 武器 | 是什么 | 落地关键 |
    |---|---|---|
    | **长回し动作流** | 一镜到底 / 长镜头贴身跟拍展现完整招式与空间，不靠快切堆 | 连贯处用长镜·贴身 steadicam/handheld 随动 |
    | **重量感 / 真实物理** | 硬桥硬马，每一击有重量、有受力、有后果，不飘不花架子 | 动作链写清受力反馈（踉跄/格挡/被压制） |
    | **Speed Ramp 变速** | 慢-快-慢，在拔刀/命中/腾跃瞬间变速强调 | 提示词写"慢动作强调…随即恢复常速" |
    | **凌厉但看得懂** | 高速凌厉，但招式落点清晰，观众跟得上 | 关键命中 snap 到中近景/特写交代落点 |
    | **敏捷优雅·身法如水** | 流畅、无多余动作、零代价（贴猫系夜行） | "流畅如水·无声着地·无多余动作" |
    | **温情内核·人物深挖** | 动作之外深挖关系、内心，留白克制 | 文戏放慢、微表情、潜台词、Mamet 短句 |
    | **双重时空驾驭** | 夜战凌厉 vs 日常温情，冷暖自由切换 | 配合双重身份视觉法则（冷夜/暖日） |

    ## 埃德加·赖特 · Edgar Wright（节奏剪辑 + 时髦幽默）
    | 武器 | 是什么 | 落地关键 |
    |---|---|---|
    | **Everything on the beat** | 动作/剪辑/转场/声效全部踩在节拍上 | 关键动作 beat 设计成可卡点·标节奏锚 |
    | **音乐驱动剪辑** | 先有节奏/歌，画面踩着它走（Baby Driver） | 后期参考标 BPM 区间 + 卡点位置 |
    | **Whip Pan / Snap Zoom** | 快速横摇、急推急拉做转场与强调 | 转场/强调点用 whip/snap·不滥用 |
    | **对称构图·居中海报感** | 风格化、整齐、有平面设计感 | 登场/换装/物件用对称居中 |
    | **Quick Cuts / Reaction 快切** | 信息高密度，reaction（手/眼/脚）踩点快切 | 反应镜头短·踩拍·递进 |
    | **视觉笑点·韵律幽默** | 动作里藏幽默节拍，时髦轻盈不端着 | 贫嘴搭档/反差/意外做幽默 beat |
    | **章节 / 标题卡** | 风格化分段、出字 | 后期叠字·非生成 |

[二 · 融合公式（谁给骨、谁给皮、谁给魂）]

    - **动作骨架 ＝ 大友**（真实重量 + 连贯流畅 + 招式清晰）——这是地基，先立住"看得懂、有分量、够漂亮"。
    - **节奏剪辑 ＝ 赖特**（卡点 + 音乐驱动 + whip/snap + reaction 快切）——把大友拍好的动作"剪出韵律"。
    - **情绪内核 ＝ 大友**（温情 + 人物 + 留白）——动作再炫，落点是人。
    - **整体调性 ＝ 赖特**（时髦 + 幽默 + 轻盈）——怪盗是来"潇洒"的，不是来苦大仇深的。

    ### ★ 黄金法则：赖特剂量按情节配（这套 skill 的真正智慧）
    赖特的"卡节拍 / 音乐驱动"很强、很风格化，**全程拉满会发腻、显 MV**。按场景给剂量：

    | 情节 | 赖特剂量 | 大友剂量 | 主导 |
    |---|---|---|---|
    | 飙车 | ●●●● 满 | ●● | 赖特 |
    | 时尚换装/登场 | ●●●● 满 | ●● | 赖特 |
    | 盗窃潜入（盲区卡点） | ●●● 高 | ●●● | 合 |
    | 跑酷 | ●● 中 | ●●●● | 大友 |
    | 打斗/制服 | ● 低（仅命中卡点） | ●●●● 满 | 大友 |
    | 文戏/温情/暧昧 | ○ 撤掉 | ●●●● 满 | 大友（+文戏调味） |

    ### ★ 文戏调味（暧昧/暗恋线·第三味·只调不主）
    大友×赖特 是"动作+节奏"引擎；**暧昧惆怅 / 暗恋张力**（如"猎人即情人"）两位都不是最强项。文戏段可借**一层**调味（**不是第三个完整风格**，只在文戏段加一点）：
    - **王家卫味**：霓虹暧昧、框中框、欲言又止的都市惆怅 → 用于暗恋/夜里独处/未说出口。
    - **是枝裕和味**：生活质感、温润日常、克制的暖 → 用于茶馆温情/家人感/不煽。
    用法：文戏段在「场景与光影/表演」里点一句"借王家卫暧昧 / 是枝温情"，运镜放慢、留白，赖特节拍撤掉。

[三 · ★情节类型战术手册（核心·导演按戏查表）]

    每类给：**主导 · 运镜词汇 · 剪辑节奏 · 声画卡点（后期） · production 落地（运镜意图 + 分镜动作链 [C0N]） · 适配提示**。
    ⚠️ i2v 视频**不含音频**——"卡节拍"落地为两层：①**动作设计层**：把关键动作 beat 设计成清晰节奏点（拔刀/落地/漂移/命中各占一个明确 [C0N] beat·按事件顺序写进 production 动作链），由 i2v 生成动作运动；②**后期剪辑层**：写进 production「后期参考·节奏卡点」（BPM 区间 + 卡点位置 + 音乐类型），剪辑时把切点/命中踩到拍子上。**production 只写画面与运动，不写音乐。**

    ## ① 飙车戏 Car Chase（赖特主导 ●●●●）
    - **运镜**：车内 POV / 方向盘+档把特写、贴车侧跟 low-angle、引擎盖机位、后视镜 reaction、whip pan 切对向车流、漂移甩镜。
    - **剪辑节奏**：每个换挡/漂移/擦身踩**重拍**；reaction（手紧握/脚踩油门/眼神）快切踩拍；**直道松、弯道险情密**。
    - **声画卡点（后期）**：引擎轰鸣/轮胎尖啸/转向灯"嗒嗒"＝节奏元素；选一首明确 4/4 拍的曲子，漂移落在重拍。BPM 建议 120–140。
    - **production/i2v 落地**：拆成一组 i2v 片段（漂移/换挡/擦身各成段奇观运动），命中点 beat 在 production 标节奏锚（卡点位置）；用具体物理（甩尾/擦护栏/钻车缝/急刹）；速度感靠**运动模糊 + 低机位 + 前景飞掠**。
    - **适配提示**：没有真追车时，接应/逃逸的车内戏 + 搭档贫嘴卡点也是天然赖特段。

    ## ② 打斗/制服戏 Fight（大友主导 ●●●●·赖特仅命中卡点 ●）
    - **运镜**：长镜头一镜流贴身跟拍、手持随动、speed ramp 慢-快、招式落点中近景、关键命中 snap 到特写。
    - **剪辑节奏**：**尽量少切**、用长镜展现连贯；切点放动作中间（动作遮剪）；仅关键命中/拔刀踩拍 snap。
    - **物理**：硬桥硬马有重量，每击有后果（踉跄/格挡/受力）；不飘不花架子。
    - **production/i2v 落地**：长连贯动作拆成一组 i2v 片段，每条动作链按事件顺序写一个招式节拍（格挡→反手→压制）；speed ramp 处慢放动量凝固的奇观瞬间；猫系敏捷＝流畅如水无多余动作。
    - **适配提示**：零暴力侠盗题材，"打斗"＝制服/擒拿/闪避（抢先按死控制台、躲摄像头、擒住手腕），不血腥；取大友的**优雅敏捷 > 暴力**。

    ## ③ 跑酷戏 Parkour（大友身法 ●●●● × 赖特落点卡拍 ●●）
    - **运镜**：FPV 贴身跟、wall-run 侧跟、纵跃 crane up、落地膝盖一沉的低机位、城市夜霓虹掠过的速度前景。
    - **剪辑节奏**：每个落点/翻越/蹬墙踩一个 beat；连贯处用长镜，跨大障碍处 snap。
    - **物理**：猫系——无声着地、零代价、流畅如水。
    - **production/i2v 落地**：连贯跑酷拆成一组 i2v 片段，每条动作链按事件顺序写路径节点（蹬墙→借力→翻越→落定）；速度靠 crane 跟随 + 前景飞掠 + 衣摆翻飞。
    - **适配提示**：序场贴墙上滑、屋顶纵跃落对面楼顶即跑酷戏，可按本表升级节奏卡点（潜入盲区读秒"三二一"做卡拍锚）。

    ## ④ 盗窃潜入戏 Heist / Stealth（赖特倒计时卡点 ●●● × 大友静-动张力 ●●●）
    - **运镜**：多搭档视角 whip 切（望风/黑客/潜入三视角）、静止悬置长镜 vs 突发 snap、手部精密动作特写。
    - **剪辑节奏**：**盲区倒计时做节奏锚**（读秒"三二一"踩拍）；静（潜伏）松、动（窗口期）密；搭档贫嘴做幽默 beat 缓冲。
    - **声画卡点（后期）**：心跳/秒针/低频脉冲作"盲区"听觉签名，倒计时归零落重拍。
    - **production/i2v 落地**：多空间切各自卡；倒计时压力靠交叉剪辑（后期）+ 读秒台词；精密动作（压窗缝/解锁/避摄像头）走特写。
    - **适配提示**：盲区倒计时（如六秒/九秒）＝天生赖特卡点结构——把读秒、冻摄像头、潜行动作剪在同一节奏骨架上。

    ## ⑤ 文戏 / 温情 / 暧昧戏 Drama（大友主导 ●●●●·赖特撤掉 ○·加文戏调味）
    - **运镜**：稳定、缓、克制；中近景/特写承载微表情；少运镜，给表演空间。
    - **剪辑节奏**：放慢、长镜、留白；**情绪不切**（积累未到峰值不切、关键反应未完成不切）。
    - **内核**：关系深挖、潜台词、Mamet 短句；**借王家卫暧昧 / 是枝温情**调味。
    - **production/i2v 落地**：微表情物理化（垂眼/停手/喉结滚/水线稳）；不炫技、不卡点。
    - **适配提示**：对白戏、不煽的温情戏、一件小道具承载情绪——都是大友温情戏；暗恋/猎与被猎的张力那条可借王家卫的欲言又止。

    ## ⑥ 时尚换装 / 登场戏 Transformation / Reveal（赖特主导 ●●●●·风格化）
    - **运镜**：快切换装蒙太奇（每件装备一个**对称特写**）、snap zoom 强调、踩拍、登场逆光定格。
    - **剪辑节奏**：换装每件踩一拍（手套→靴→面罩→收拳），节奏递进到登场定格。
    - **声画卡点（后期）**：每件装备一记金属/皮革质感音踩拍，收拳落重拍。
    - **production/i2v 落地**：每件装备一条短特写 i2v（由细节运动到锋利）；登场用**逆光轮廓光**（见 cinematography §C）定格气场。
    - **适配提示**：换装蒙太奇"快切·每格一物件由下往上"＝正是赖特换装蒙太奇，可在序场/出手前插一段，配登场逆光剪影。

[四 · 画面 look 前缀块（生图层·给服化道·轨 A）]

    本融合精华在运动/剪辑层；画面 look 用真人写实电影质感即可（与项目"真人写实·高级都市丽人"兼容）。需要把"凌厉活力"也烧进参考图时，用：
    ```
    Keishi Otomo x Edgar Wright fusion look, photoreal cinematic live-action with kinetic flair, sharp crisp filmic texture, dynamic intimate handheld energy mixed with symmetrical poster-like framing, high-end stylish urban caper mood, neon-night and warm-daylight dual palette, slightly heightened saturation and contrast, witty playful yet emotionally warm tone
    avoid cartoon, avoid anime, avoid 3d render, avoid plastic skin, avoid text overlays, avoid watermark
    ```
    > ⚠️ 画面 look（轨 A·生图）与运镜剪辑（轨 B·本 skill §三）分属两轨：这段 look 只决定生图质感，运镜/剪辑/节奏仍照 §三按情节配方做（运镜不在 look 里）。画面 look 只取其"凌厉活力质感"，温情戏不必叠。

[五 · 落地到 production（导演怎么把它写进交付）]

    1. **production「叙事模式」列**：动作/卡点段标 `Rhythm`（赖特卡点）或 `LongTake`（大友长镜）；温情段标 `Stillness`。
    2. **分镜动作链 [C0N] 标卡点**：关键 beat 按事件顺序写清 `[C0N · 命中/落地/漂移 · 卡点]`（不写秒级时间戳），让后期有明确踩拍锚。
    3. **变速标注**：大友 speed ramp 处用 `[V0N]` 写"慢动作强调 X，随即恢复常速"。
    4. **「后期参考·节奏卡点」薄章节**：写 BPM 区间 + 音乐类型 + 卡点位置 + 声效卡点元素（引擎/秒针/金属音）——给后期剪辑师。
    5. **赖特剂量自检**：每段问一句"这段该给赖特几颗●？"——文戏给 ○ 别卡点，飙车/换装给 ●●●● 拉满。
    6. **production 只写画面与运动**：不写音乐、不写 BPM（那些在后期参考章节）。

[六 · 与现有 skill 的关系（别重复造轮子）]

    - `action-choreography-skill`：动作词汇 / 身体力学 / 环境交互**基础库**——本 skill 是它的"**导演风格层**"（怎么把动作拍得像大友×赖特）。设计具体动作仍查 action-choreography。
    - `storyboard-skill`：分镜师 @图N 关键帧渲染手册——本 skill 指定**何时**用 whip/snap/long-take/speed ramp 作为导演运镜意图（写进 production·i2v 实现），@图N 关键帧怎么渲染查 storyboard。
    - `long-take-skill`：大友长镜动作流与之呼应（一镜到底的动作流 = 长镜的一种用法）。
    - `cinematography-skill/styles §B`：画面 look 前缀（轨 A·生图）；§C 光影效果（登场逆光轮廓光等）。
    - `sound-design-skill`：节奏卡点的音乐 / 声效落到**后期参考**，不进 production 画面/运动。
    - `performance-skill`：文戏温情段的微表情 / 沉默 / 视线设计（大友内核层）。

[七 · 一句话记忆]
    **大友给骨与魂（真实重量的华丽动作 + 走心），赖特给皮与韵（踩拍的剪辑 + 时髦幽默），剂量按情节配（飙车换装拉满、文戏撤掉），暧昧线加一味王家卫/是枝。**
