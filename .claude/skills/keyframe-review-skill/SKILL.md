# 关键帧 @图N / 身份级底 Go/No-Go 审图清单（用户手工流水线）

**定位**：本 skill 是**用户**在手工流水线中使用的审图工具。分镜师产出精修关键帧渲染卡、用户用 Nano Banana Pro 等出**精修关键帧（@图N·三道洗后的首帧）**，以及服化道产出身份级底提示词、用户出**人物/场景身份级底图**——这两类图的"用户审图 Go/No-Go"节点都由此 skill 支撑。

**不是 director 审核**：director 审核的是 production（review-skill §1）、服化道身份级底（§2）、分镜师关键帧渲染卡（§3）的**文字**；本 skill 审核的是用户**生成出来的图**。两者互补。

**专业版说明**：专业版 = 极速版 + 分镜师增强，共用同一条 i2v 视频主干。手工流水线是"服化道出身份级底 → 分镜师出关键帧渲染卡 → 用户逐张出精修关键帧（@图N·三道洗后）→ 审图 Go → 喂导演 production 当 i2v 首帧"。**本清单审的就是这批精修关键帧（@图N）+ 服化道人物/场景身份级底**。关键帧 Go 后是**喂导演 i2v 当首帧上传**——不是给 CG/动画团队作静帧蓝本。

## §0 审图顺序 · 身份级底（信息版）→ 三道洗 → 精修关键帧（出图顺序纪律）

关键帧按"先在服化道身份级底上出信息版锁内容、核对 Go 后再三道洗（质感→光影→氛围）出精修帧"出图（见 storyboard-skill 出图顺序纪律），审图也按这个顺序：
- **信息版底（服化道身份级底·大平光·可读性最高）**：只核**内容**——构图、景别、机位、人物 identity、道具/场景结构、占比朝向。内容没锁死**不要往下洗**（否则一洗、AI 看不清就乱改结构，白审）。**这就是核对 Go 闸**。
- **三道洗（核对 Go 后·一道一道审·顺序=质感→光影→氛围）**：
  - **① 质感**：材质 PBR——菲涅尔/clearcoat/粗糙度差异/AO/高光滚降/微纹理/SSS（不是只看"金属感"形容词）。
  - **② 光影**：主光方向/色温、明暗对比、边缘光、体积光、单光源不打架。
  - **③ 氛围（合成层）**：调色 + 大气(雾/体积光) + 镜头光学(光晕/辉光/色散/暗角) + 胶粒 + 粒子——是否点到为止（别堆成廉价海报）。
- 三道洗后即**精修关键帧 @图N**——目标是 identity 稳、构图对、渲染到位，**可直接喂导演 production 当 i2v 首帧上传**。
- 若洗的过程发现**结构/identity 被吞掉或重绘** → 判 No-Go，**回信息版底重出**，不在洗图层硬修。

下面 §1-§3 清单按顺序套用：信息版底重点过 §1.1/§1.2/§1.4（identity/构图/道具），三道洗重点过 §1.3/§1.5/§2（光影/氛围/场景专项）+ §0.5 制片人校正。

**§0 附 · 漏载检测门（强检测·防 skill 没被触发）**
硬映射表（CLAUDE.md 场景分析）在入口防"该载没载"；这道在出口兜底——**不信"载没载"，检产出里有没有该效果的痕迹**：
- **材质镜**（机甲/金属/硬表面…按映射该载 material-pbr）：卡「质感」字段搜不到物理词（菲涅尔/clearcoat/粗糙度差异/AO/高光滚降/微纹理）、只有"金属感/质感好"这类形容词 → **判漏载 No-Go·回炉重写**。
- **布光镜**（低长调/硬光/体积光…按映射该载 cinematic-lighting）：「光影」字段搜不到"先定影调→主光方向/受光压暗区→边缘光/体积光"这套、只有"打光好看/有电影感" → **判漏载 No-Go·回炉**。
- 场景明显命中映射、卡头却无 `📦 加载：<skill>` 声明 → 同样判漏载。
> 产出"异常干净"（该有的物理痕迹没有）≠ 没问题，多半是门禁没触发——这是 luban「活体检查」的落地：查产出、不信状态。

## §0.5 制片人校正回路 · 看图加减效果（核心环节）

> **为什么有这一节**：关键帧提示词是 AI（制片人）"闭眼"写的——方法论对、但**针对某个模型/某张图的剂量没法凭空校准**。校准只能靠**真图回传**。所以关键帧流程不止"用户自审"，还有一个**制片人看图分析**的回路：用户出完图发回来，制片人对照方法论分析"该加什么、该减什么"，给出可执行的改词清单。**方法论给强起点，真图给校准。**

**触发**：用户把生成的关键帧（信息版底或三道洗后）发回给制片人，说"帮我看看 / 还差点意思 / 怎么调"。

**制片人分析流程（对照方法论，不空谈）**：
1. **先认这是哪一版**：信息版底（核内容）还是三道洗后（核质感/光影/氛围）。错版的问题不在这版改（见 §0）。
2. **对照意图**：调出该镜的关键帧渲染卡（画面瞬间/构图/光影/风格前缀），看真图与意图的差距。
3. **对照方法论逐维诊断 + 出加减清单**：
   - **材质**（查 `material-pbr-skill`）：边缘菲涅尔够不够？高光滚降软硬？粗糙度有没有面板间差异？是不是"太干净=AI味"？→ 加/减具体物理词。
   - **光影**（查 `cinematic-lighting-skill`）：影调对不对（低长调/高反差）？主光方向/受光压暗区？补光是 soft fill 还是 weak fill 的问题？边缘光是 rim 还是 soft edge？体积光够不够/过头？→ 加/减具体布光词。
   - **氛围**：高反差/体积雾/火花——是不是堆过头了（廉价海报感/特效素材包感）？→ **减**比加更常见，点到为止。
   - **构图/identity**（若是信息版）：占比/朝向/分层/角色一致性偏没偏 → 回信息版改。
4. **产出"加减清单"**（给 storyboard-artist 改词用）：
   ```
   ## <镜号> 校正清单（基于回传图）
   - 加：[具体效果词 + 一句为什么]（如：边缘加 Fresnel 反光——机甲轮廓发死，立体感不够）
   - 减：[具体效果词 + 为什么]（如：体积雾减半——糊了主体，廉价感）
   - 改：[某词换某词]（如：高光滚降由硬改软——现在塑料数码味重）
   - 重抽基准：信息版底 / 三道洗后 · 只调 delta · 其余保持
   ```
5. **storyboard-artist 据清单改提示词 → 用户重出 → 再回传 → 循环到对。**

> 纪律：每条加减都要给**物理/叙事理由**（呼应"每个效果有理由、点到为止"），不堆词、不空泛说"更高级一点"。这正是制片人替没有产品经理的用户多想一步的价值。

## §1 通用审图清单（每张 KF 都过）

### 1.1 角色一致性（identity）

对照 `assets/character-prompts.md` 的角色主图和出图提示词中的角色描述：

- [ ] **面部特征**：五官比例、眼睛颜色、发色发型、肤色与主图一致？
- [ ] **服装**：主要服装（外套/便服等）款式、颜色、材质一致？
- [ ] **体型**：身高、肩宽、比例符合角色年龄/性别设定？
- [ ] **标志性特征**（如有）：特殊标记位置、疤痕、纹身、配饰等？
- [ ] **年龄段**：儿童/青年/中年/老年区分准确？

**致命问题**（直接 No-Go）：
- 角色面部与主图偏差明显（别人的脸）
- 年龄段错（把中年画成青年等）

### 1.2 构图 · 景别 · 机位

对照出图提示词（信息版）中的构图描述：

- [ ] **景别**：中景/近景/特写/大全景与提示词一致？
- [ ] **机位角度**：低角度仰拍 / 正面 / 俯视等与提示词一致？
- [ ] **画幅**：与项目 bible 锁定的画幅一致（16:9 / 2.39:1 / 9:16 等）· 分辨率达标（2K+）？
- [ ] **角色相对位置**：与提示词的**自然语言相对位置**一致（"坛阵那头""中央偏右"）？**不按画面占比%/坐标核**（铁律④·走位交 AI 在窄幅内自行落位）
- [ ] **角色朝向**：后背朝向观众 / 侧脸 3/4 / 正面 等与提示词一致？

### 1.3 光影（光源逻辑 · 三道洗「光影」道）

对照三道洗「光影」道的描述（主光方向/色温/对比/边缘光）：

- [ ] **主光源位置**：从左/右/顶/底/逆光 方向射入·与提示词一致？
- [ ] **光色色温**：冷蓝 5500K / 暖橙 3200K / 等·与提示词一致？
- [ ] **对比度**：高对比（低长调）/ 中对比 / 低对比（高调）·与提示词一致？
- [ ] **阴影方向**：主光源方向的阴影投向是否物理正确？
- [ ] **辅光 / 边缘光（如有）**：辅光（指示灯 / 屏幕自发光）亮度不盖过主光？需要时边缘光/体积光是否到位？
- [ ] **光位逻辑自洽**：用几盏光由项目风格/bible 决定——**单光源是 Deakins 等写实风的专项要求、不是通用铁律**；多光位（三光位/组合光）在多数动画/CG/高调风里合法。关键是**光位有逻辑来源、不穿帮**（见 cinematic-lighting-skill）。

**常见翻车**：
- 光位无逻辑来源（左右脸都高光、光从左来右脸却无暗部）——区别于"有意的多光位布光"
- 光色与提示词不符（提示词冷蓝但出图偏暖）
- 阴影方向违背物理

### 1.4 道具 · 环境

对照出图提示词中的道具和环境描述：

- [ ] **关键道具位置**：操作台 / 关键设备 / 屏幕界面 等在正确画面位置？
- [ ] **关键道具状态**：屏幕暗屏 / 亮屏 / 指示灯颜色 等与提示词一致？
- [ ] **环境动态元素**：指示灯 1Hz vs 3Hz 无法从静态图判断·检查指示灯颜色/状态位
- [ ] **场景布局**：本段主要场景结构与 scene-prompts 设定图一致？

### 1.5 前景 / 氛围粒子（如适用）

对照三道洗「氛围」道的前景/氛围描述（非所有 KF 都有）：

- [ ] **前景遮挡物**：管线 / 舱壁 / 肩部剪影 等·是否有·位置正确？
- [ ] **氛围粒子**：细尘埃 / 液泡 / 星尘 / 火星溅射·类型与场景匹配？
- [ ] **粒子密度**：极简美学场景（情绪峰值）不应有过多粒子·平构图场景应该有足够粒子
- [ ] **分层关键词生效**：前景是否明显虚化/散景（不是和主体一样清晰）？

### 1.6 跨镜一致性（多 KF 同段时）

对照已锁定的上一张 KF（通常是 KF1 作为 Style Anchor）：

- [ ] **场景延续**：同一场景内·墙面/地板/道具位置是否一致？
- [ ] **光影延续**：主光源色温/位置是否保持（即使焦点切换）？
- [ ] **角色服装延续**：同一时间线内角色服装/状态是否一致？
- [ ] **色调延续**：整体冷蓝底色 / 暖色能量元素的色彩基调统一？
- [ ] **机位一致性**：如提示词声明"严格保持机位"·角度/焦段/景别应该保持？

### 1.7 AI 常见画崩（Nano Banana Pro 通病）

- [ ] **手部解剖**：5 指正确？没有多指 / 少指 / 手指畸形 / 错位？手/腕关节比例正常？
- [ ] **脚部解剖**：5 趾正确（如裸足出镜）？
- [ ] **面部左右对称**：眼睛大小、眉毛位置、嘴角对称（除非提示词要求非对称表情）？
- [ ] **眼睛**：瞳孔清晰 / 眼白不呆滞 / 反光正常？特别关注特殊要求（如特殊设定的角色的异常瞳孔）是否被误画成恐怖效果
- [ ] **文字 / Logo / HUD 漏出**：画面中是否混入可读文字、品牌 Logo、UI overlay（全片禁止）？
- [ ] **肢体穿模**：手臂穿过身体 / 腿部交叉异常？
- [ ] **头发物理**：发型在静态图中是否自然（不是飘起异常）？

**致命问题**（直接 No-Go）：
- 手指数量不对
- 画面混入可读文字 / 品牌 Logo

## §2 按场景类型的专项审图（由项目 bible §6 驱动）

本项目的场景类型由 `assets/cinematography-bible.md` §6 场景映射表定义。对每张 KF，先确认它所属的场景类型，再按下方通用专项维度逐条核对；具体取值（该场景的主色调、光源设定、标志性元素、空间结构等）以 **bible §6 + scene-prompts** 为准。**本清单不绑定任何题材**，下列维度对所有场景类型通用：

- [ ] **主色调一致**：本张 KF 的整体色调与该场景类型在 bible §6 设定的主色调一致？
- [ ] **光源逻辑符合设定**：主光源数量/方向/色温符合该场景类型在 bible §6 的光照设定（光位有逻辑来源·不穿帮；单光源仅 Deakins 等写实风专项要求·非通用铁律）？
- [ ] **空间结构 / 标志性元素一致**：场景的空间布局、标志性物件与 scene-prompts 设定图一致？
- [ ] **大场面三层到位**：若属大场面 / 奇观类场景，前景 + 中景 + 远景三层纵深是否到位？
- [ ] **多人戏站位**：多人同框时站位是否对照 staging-skill 的站位规范？
- [ ] **跨场景色调对比成立**：若本场景设定为与相邻场景形成色调对比，该对比是否成立（不串色）？

> 具体场景类型及其专属审图点随项目 bible §6 而定。某一类型反复翻车时，把该类型的专属检查点累积进 bible §6（场景映射表）。

## §4 Go / No-Go 判定规则

### Go（通过 · 锁定为 KF.png）

同时满足：
- §1 通用清单全部打勾（致命问题零容忍）
- §2 对应场景类型专项清单全部打勾
- §3 注意事项全部打勾

**Go 的实际动作**：
1. 保存图片（命名与 storyboard 卡片/身份级底里的引用一致，如关键帧 `S01-01.png`、身份级底按角色/场景名）
2. 如果本图进入复用库（跨段复用候选）· 同步保存一份到 `assets/keyframes/`
3. 该图可作为后续出图的 delta ref；**精修关键帧 @图N 喂导演 production 当 i2v 首帧上传**（专业版共用 i2v 主干）

### No-Go（不通过 · 调整重抽）

任何 §1/§2/§3 致命问题命中·或累积 3+ 个非致命问题。

**No-Go 的实际动作**：
1. 记录问题清单（哪些 checkbox 失败 / 具体描述）
2. 反馈给 导演 / 分镜师（@图N 关键帧）或服化道（身份级底）→ 调整本图的 Nano Banana 提示词（delta 改写 / 加负面约束 / 换 ref）
3. 用新提示词重抽
4. 回到本 skill 重审

**Nano Banana Pro 重抽技巧**（无需改 storyboard / 设定图提示词文件·用户可自行微调）：
- 手部问题 → 追加 `avoid hand deformation, avoid extra finger count, anatomy correct hands`
- 文字漏出 → 追加 `avoid text, no English, no Chinese, avoid any readable words`
- 多光源 → 追加 `avoid multi-light studio, single light source only`
- identity 漂 → 强化 character ref 的权重 / 重新上传主图
- 单次 seed 换别的 → Nano Banana 多 seed 试（1-2 次如仍失败·回 导演）
