# Roger Deakins 摄影风格

[核心哲学]
    "光不是你加上去的，是场景里本来就有的。"

    Deakins 的一切摄影决策都从一个问题出发：这个场景里，光从哪里来？
    窗户、台灯、屏幕、火焰、天空——光源必须是画面中可见的或可解释的物理存在。
    他几乎从不使用观众无法解释来源的"美化光"。

    这个哲学对 AI 提示词的影响：
    写光线时，永远先写光源（"窗户射入的光"），再写效果（"在地板上投下方形光区"）。
    不写"戏剧性光影"——写"唯一的窗户在左侧，房间右侧沉入阴影"。

[Deakins 五条法则]

    ## 一、单一光源优先

    大部分场景只用一个主光源。辅助光来自自然反射（墙面、地面、天花板的反光），不额外加灯。

    效果：画面简洁、方向感强、阴影自然。
    反面：多光源从多个方向照射 → 阴影混乱 → 假。

    提示词翻译：
    "房间里唯一的光源是右侧的窗户。光线从窗户射入，在左侧墙面上产生微弱的反射补光。房间深处逐渐暗下去。"

    不要写：
    "主光从右侧照来，辅光从左侧补充，轮廓光从背后勾边。"（这是灯光师思维，不是 Deakins 思维）

    ## 二、让阴影做叙事

    Deakins 不怕黑。画面中大面积的阴影不是"曝光不足"，是叙事空间。
    观众看不见的地方 = 观众会想象的地方。阴影制造想象空间。

    《老无所依》中 Chigurh 在暗处等待，画面 70% 是黑的——恐惧来自"看不见"。
    《银翼杀手2049》中 K 走进废弃建筑，巨大的空间只有一束光——孤独来自"空旷的黑暗"。

    提示词翻译：
    "画面大面积暗部，仅 [光源] 照亮 [局部区域]。角色 [面部/身体的哪个部分] 可见，其余隐没在阴影中。"

    ## 三、色彩极度克制

    Deakins 的画面很少有鲜艳颜色。去饱和、低对比、接近单色。
    当整个画面都是灰蓝色调时，一点暖色（烛光、火焰）就变得极其珍贵。

    《1917》：全片泥土色+灰绿，只有火焰和照明弹是暖色——每次暖色出现都是"生命/危险"的信号。
    《银翼杀手2049》：冷蓝灰+橙黄，两种色调交替但从不混合。

    提示词翻译：
    "整体色调 [低饱和的主色调]。画面中唯一的 [对比色] 来自 [具体光源/物体]。"

    ## 四、镜头不炫技

    Deakins 极少使用花哨的运镜。大量固定机位、缓慢推拉、简单跟拍。
    他的镜头"不存在"——观众完全忘记摄影机的存在，只看故事。

    运镜选择：
    - 默认固定机位或极慢推拉
    - 跟拍只在角色移动时使用，速度匹配角色速度
    - 几乎不用手持（除非是《1917》那种特殊设计）
    - 从不用炫技环绕、甩镜、快速变焦
    - 景别切换靠剪辑，不靠单镜头内的运动

    提示词翻译：
    "固定机位，镜头不动。" 或 "镜头极缓地向前推近，速度几乎不可察觉。"
    不要写："镜头快速环绕主体360度。"

    ## 五、环境即角色

    Deakins 的建立镜头不是"交代地点"，是"介绍一个角色"。
    《银翼杀手2049》的废墟拉斯维加斯——橙色雾霾中的空旷废城，这个环境本身就在讲"文明的尸体"。

    每个建立镜头都要回答：这个空间在说什么？
    - 空旷 = 孤独
    - 逼仄 = 压迫
    - 整洁 = 控制
    - 混乱 = 失序
    - 废弃 = 时间的痕迹

    提示词翻译：
    建立镜头不只写"地点是什么"，要写"空间的性格"：
    "极远景，废弃的城市街区。建筑外墙剥落，街道空无一人，路面裂缝中长出枯草。橙色的雾霾笼罩一切，天空和地面的界限模糊。安静到能听见风穿过碎玻璃。"

[Deakins 风格适用场景]
    最强：写实科幻、西部/荒野、监狱/密闭空间、战争/废墟、冷峻剧情片
    可用：都市现实题材、历史片
    不适合：魔幻/奇幻（色彩太克制）、喜剧（氛围太沉）、MV（不够华丽）

[提示词风格示例]

    Deakins 式提示词：
    "固定机位，中景。灰蓝色调的金属走廊，唯一光源是尽头的舱门窗口——一小块冷白光落在地板上。角色A站在光区边缘，面部左半侧被光照亮，右半侧沉入走廊的阴影。他一动不动地看着舱门。引擎的低频嗡鸣是唯一的声音。"

    非 Deakins 的写法（对比）：
    "戏剧性的光影效果，蓝色和橙色的对比光从两侧照亮走廊，镜头缓慢环绕角色A，展示他的决心。史诗感的配乐响起。"
