# 轨 B · 名导招牌镜头库（镜头运镜意图 → 导演 production 的 i2v 运动）

> **双轨定位**：本库是「轨 B·镜头运镜」总库，决定**这场戏的镜头怎么动**（导演写进 production 卡片的运镜列 / 分镜动作链 [C0N]）。**运镜是 i2v 视频里要实现的镜头运动**——导演直接写进 production，由 i2v 生成视频实现，不取静帧旁注给下游团队。配套「轨 A·画面光影色彩」见 `_风格方法论与库.md` §B（导演画面前缀）+ §C（光影效果）——决定怎么生图；轨 A 由分镜师在服化道底上渲染 @图N 当 i2v 首帧/参考。
> **默认耦合**：项目选定某导演/作品 → 服化道/分镜师套他的轨 A 光影（落进 @图N）、**导演套他的轨 B 招牌运镜意图**（落进 production 的 i2v 运动），两轨一起上。本库就是导演把"招牌镜头"落进 production 运镜列/分镜动作链的执行手册。
> **为什么单独建**：招牌运镜（希区柯克变焦、360°环绕、split diopter…）既不在画面前缀里、也不在导演的"通用运镜动词"里——它们是名导的签名句式，必须单列、按情绪触发。
> **主源**：本文件（MD·人读·运镜签名单一事实源）。`style-library.json` 暂未建 `camera_signatures` 镜像，运镜签名以本 MD 为准（不强制双写）。

# §一 · 总则（运镜意图怎么写进 production、怎么由 i2v 实现）

招牌镜头是名导面对特定情绪的签名运镜。专业版里它就是 i2v 视频里要实现的镜头运动，由导演直接写进 production：

> **运镜意图 = 导演 production 卡片的标注**。导演在 production 的「运镜」列里写招牌镜头名（给人看），在分镜动作链/意图描述里写"镜头怎么动、画面随之怎么变"——这段直接作为 i2v 视频的镜头运动驱动，由 i2v 平台生成实现。

| 层 | 写什么 | 给谁看 / 怎么实现 |
|---|---|---|
| production「运镜」列 | 招牌镜头名（如 dolly zoom、360° orbital、split diopter） | 人读·i2v 运动锚 |
| 运镜意图 / 分镜动作链 [C0N] | 镜头怎么动、画面随之怎么变（如"背景向两侧拉伸逼近、主体大小不变"）按事件顺序 | i2v 平台据此生成镜头运动 |
| @图N 关键帧（分镜师） | 服化道底上渲染光影氛围的精修关键帧 | 喂 production 的 i2v 当首帧/参考 |

> 铁律：**运镜意图只描述"镜头怎么动、画面随之怎么变"，画面色彩光影归轨 A**。术语写在 production 运镜列（给人看），运动描述写进分镜动作链正文（i2v 据此生成运动）；@图N 关键帧只承载光影氛围构图，运动由 i2v 实现。

## 结构性镜头的处理（i2v 单条难一气呵成的）
有些招牌镜头单条 i2v 难一气呵成，需要分段 + 创意转场缝合，导演在 production 里标清：
- **超长一镜到底** → 拆成多条 i2v + 创意转场缝合点（遮挡/甩镜/入暗/物件擦镜），见 `long-take-skill`。
- **不可能穿越镜（穿过实体物）** → 拆"穿入"和"穿出"两条 i2v，中间靠遮挡黑场缝合。
- **精确 match-cut（今敏式形状/动作匹配）** → 前后两条 i2v 锁住相同形状/构图位置，靠剪辑点对齐。
- **折叠/旋转重力空间（诺兰）** → 拆成旋转中的几段 i2v，或靠美术与构图暗示。
- **子弹时间** → 用环绕路径的运镜（绕静止主体一周），i2v 不稳时拆成几段机位。
- **复杂多人 cut-on-action 连续调度（黑泽明/张艺谋人海）** → 拆成单/双人 i2v 逐条出，标注剪辑拼接顺序。

# §三 · 按导演的轨 B 运镜签名速查（选了谁·默认套这套镜头）

> 选定某导演 → 导演默认从其"招牌运镜包"里按戏取用（不是全上，是**这位导演面对该情绪时的首选解法**）。配合 §二 触发表落地。

- **希区柯克**：dolly-zoom（眩晕/顿悟）· 主观窥视 POV · 楼梯/高处俯拍 · 悬念缓逼近 · 一抹红色重点物引视线。
- **库布里克**：单点透视对称 track · 缓慢对称推/拉 · Steadicam 长廊贴地低跟（《闪灵》）· 居中庄严。
- **斯皮尔伯格**：缓推面部 + 仰望 wonder 反应（Spielberg face·缓推到定格反应）· 逆光光斑 · 一镜到底场面调度（oner）· 前景遮挡物揭示下一主体 · 低角度仰望英雄/奇观 · 固定机位让动作进出画面 · 流畅古典推轨。
- **斯科塞斯**：snap zoom · whip pan · Steadicam 一镜穿行（入场长镜）· 上帝视角俯拍 · 暴烈快剪。
- **朴赞郁**：360° 环绕 · 垂直俯拍 · 华丽运镜转场 · 对称 graphic frame · 优雅的暴力调度。
- **德帕尔马**：split diopter 前后双焦 · split screen 分屏 · 360° 环绕 · 慢动作长镜。
- **马力克**：magic-hour 手持游移 · 低角仰天 · 人在景中漂浮 · 自然流动不设定。

# §三B · 类型 / 通用招牌镜头（不绑导演·高频通用）

# §四 · 落地到 production（导演怎么把轨 B 写进交付）

1. **production「运镜」列**：直接写招牌镜头名（给人看），如"dolly zoom（眩晕）"、"360° orbital"、"split diopter 双焦"。
2. **运镜意图 / 分镜动作链 [C0N]**：**只写画面怎么动、不写术语黑话**——按 §一/§二 的意图写法，按事件顺序写进 production，作为 i2v 生成的镜头运动驱动。例：运镜列写"dolly zoom"，动作链写"背景向两侧拉伸、纵深急速逼近，主体大小不变"。
3. **i2v 生成**：production 的运镜意图直接由 i2v 平台生成镜头运动；单条难一气呵成的（穿越镜、match-cut、超长一镜）按 §一「结构性镜头的处理」拆成多条 i2v + 缝合点标注。
4. **默认耦合自检**：项目圣经指定了导演风格 → 每个高表现力节拍问一句"这位导演面对这个情绪，招牌解法是什么？"（查 §二/§三），别只用通用运镜动词。
5. **与轨 A 不冲突**：轨 B 只写镜头怎么动（进 production·i2v 实现）；画面色彩光影（轨 A）由分镜师渲染 @图N 当首帧继承，运镜意图里不写风格前缀。

# §六 · 喂片现拆 meta-prompt（轨 B 运镜签名提炼器·开箱即用）

> 用法：用户丢一段参考素材（或它的连续截帧/逐镜时间轴描述）→ 把下面这段贴给 AI + 提供素材 → AI 拆出可**直接入本库**的轨 B 运镜签名。这是轨 A 风格提炼器的镜头版（外部教程只做了轨 A 喂图，本段是我们独有的轨 B 喂片）。
> 抽帧工具：本机 `imageio_ffmpeg` 自带 ffmpeg（`…\imageio_ffmpeg\binaries\ffmpeg-win-x86_64-v7.1.exe`），可 `-vf "fps=1/N,scale=480:-1"` 抽帧成图喂入。

```
你是一位资深电影导演兼剪辑指导。我会提供一段参考素材（或它的连续截帧/逐镜时间轴）。请只做「镜头运镜与剪辑节奏」分析（轨 B）——不要分析画面色彩光影（那是轨 A），专门提炼这段的运镜签名：
- 招牌运镜：用了哪些标志性镜头（dolly zoom 希区柯克变焦 / 360°环绕 / snap zoom / whip pan / 长镜一镜流 / split diopter 前后双焦 / step-print 抽帧 / speed ramp 变速 / 手持游移 / 低机位仰拍…），各服务什么情绪。
- 运镜节奏：景别切换密度、切点逻辑（cut on action？信息耗尽即切？情绪不切？）、是否卡拍/音乐驱动。
- 镜头运动：机位高度、推/拉/摇/移/升降/环绕的具体用法、运动速度。

然后严格用下面格式输出（供我入 _轨B-名导招牌镜头库.md），每个招牌镜头一行：
【运镜签名名】<中文一句话>
【触发→招牌镜头】<情绪/情节> → <招牌镜头名>
【运镜意图描述】<中文·只写"画面怎么动"·不写镜头术语黑话，如 dolly zoom 写成"背景向两侧拉伸逼近、主体大小不变"·画面色彩光影归轨 A 不写>

不写画面色彩光影（轨 A 的事）。术语只在签名名里出现，意图描述里只写镜头怎么动。
```

> 拿到输出 → 追加进 §二（情绪触发表）+ §三（按导演速查）。
