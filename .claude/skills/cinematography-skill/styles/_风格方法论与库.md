# 风格拆解方法论 + 风格库（可拓展）

> 用途：把**任意导演 / 影片 / 美学流派**的视觉签名，拆成固定维度 → 组装成可复现的英文风格前缀块（给文生图）。
> 配合 `art-design-skill/visual-style-presets.md` 的「风格生成器」：用户给一部代表作/一个流派 → 按本方法论 7 维拆解 → 产出前缀 → 存进下方「风格库」复用。
> **可拓展**：库里没有的风格，照 §A 模板拆一遍、追加到 §B 即可。
> **主源声明**：本文件（MD）为**主源**（人读·可编辑）；`style-library.json` 为机读**镜像**。两份应一致，**以本文件为准**；新增/改风格先改这里，再同步 JSON（不强制双写，避免漂移）。
>
> ## ★ 双轨风格架构（2026-06-13 用户校正·覆盖旧"运镜解耦"声明）
> 一部作品**至少由两套风格决定**，分管两件不同的事——**两轨默认耦合，不再解耦**：
>
> | 轨 | 管什么 | 决定用户 | 内容 | 落到 | 库在哪 |
> |---|---|---|---|---|---|
> | **轨 A · 画面光影色彩** | 怎么**生图**（参考图） | 文生图 | 机位质感/构图/光影/色彩/胶片质感 | 服化道·风格前缀块（烧进参考图） | 本文件 §B（导演画面前缀）+ §C（光影效果叠加） |
> | **轨 B · 镜头运镜** | **镜头怎么动**（运镜意图） | i2v 视频里实现的镜头运动 | 招牌镜头/运镜/剪辑节奏 | 导演·写进 production 运镜列/分镜动作链 [C0N]（i2v 生成实现） | `_轨B-名导招牌镜头库.md`（招牌镜头总库）+ 本库每条的「⑦运动/节奏」维 |
>
> **默认耦合铁律**：项目选定某导演/作品 → **两轨一起套**（既用他的轨 A 光影、也用他的轨 B 招牌镜头）。例：选希区柯克＝服化道套他的高反差阴影光影（轨 A）+ 导演套他的 dolly-zoom/主观窥视调度（轨 B）。
> **混搭为可选 override**：高级用法可拆开（A 导演的光影 + B 导演的镜头），但这是**显式指定的 override，不是默认**。旧版"运镜解耦·默认不套"作废——那会把轨 B 整条砍掉、导致名导招牌镜头永远不出现。
> **§A 第⑦维即轨 B 种子**：本库每条导演的「⑦运动/节奏」就是该导演的轨 B 运镜签名摘要；深度招牌镜头（运镜意图描述）见 `_轨B-名导招牌镜头库.md`。

# §A · 拆解方法论（7 维框架）

任何风格都拆这 7 维，逐维填好再组装：

| # | 维度 | 拆什么（关键词方向） |
|---|------|------|
| ① | **摄影机 / 镜头** | 机型质感、焦段倾向（广角/标准/长焦）、画幅（变形宽银幕/4:3/2.39）、镜头特性（球面/变形/柔焦/光晕） |
| ② | **构图法则** | 对称/中心/三分/对角/前景框架/留白、人与环境比例、机位高度 |
| ③ | **光影方案** | 光源逻辑（单源/自然/实用光）、对比度（高/低）、明暗分布、阴影质感（硬/柔）、高调/低调 |
| ④ | **色彩 / 调色** | 调色板、饱和度、色温、grading（teal-orange / 去饱和 / 单色 / 糖果色 / 霓虹） |
| ⑤ | **质感 / 介质** | 胶片颗粒/数字、画幅比、锐利/柔、年代感、笔触（油画/水彩/赛璐璐） |
| ⑥ | **氛围 / 母题** | 签名元素（雾/水/烟/雨/霓虹/铬合金…）、空间感、情绪基调 |
| ⑦ | **运动 / 节奏**（运镜层） | 运镜习惯（长镜头/手持/对称固定/快速）、剪辑节奏、天气/动势 |

**组装规则**：①-⑥维 → 英文短语串成一句风格前缀块（**轨 A·生图**），开头点名风格出处（"Stanley Kubrick 2001 style…"/"Atompunk retro-futurism…"），再堆关键视觉词。生图 avoid 按需另配（text/logo/watermark/手指等）。

**★ 轨别归属（双轨架构）**：
- **①-⑥维 → 轨 A（生图）**：组成风格前缀块，归服化道，烧进参考图。
- **⑦维 → 轨 B（运镜）**：是该导演的**招牌运镜签名**，**不进生图前缀**；由导演按 `_轨B-名导招牌镜头库.md` 落进 **production 的运镜列/分镜动作链 [C0N]**（运镜/剪辑节奏），作为 i2v 视频里要实现的镜头运动。选定导演时默认两轨一起套。

**如何扩展**：拿到新导演/流派 → 看 1-2 部代表作截图 → 逐维填表 → 写成前缀 → 追加到 §B（标注出处便于复用）。

# §A-2 · 喂图现拆 meta-prompt（轨 A 风格生成器·开箱即用）

> 用法：用户丢 1-N 张参考图（某影片/导演/美学）→ 把下面这段贴给多模态 AI（Gemini/GPT-4o 等）+ 上传参考图 → AI 按 7 维拆出可**直接入库**的轨 A 风格前缀块。比"人读 §A 手册自己拆"更快、更稳。
> （此法吸收自外部风格复刻教程并升级——原教程只到轨 A 关键词，这里直接对齐我们的入库格式 + 7 维 + 生图 avoid。）

```
你是一位拥有20年经验的电影摄影指导(DP)兼美术指导。我会上传 1-N 张参考图（同一部影片/导演/美学风格）。请只做「画面风格」分析——不要描述具体人物或剧情，去找这一组图的共性视觉签名，按以下 7 维逐维提炼：
① 摄影机/镜头：机型质感·焦段倾向(广角/标准/长焦)·画幅·镜头特性(球面/变形/柔焦/光晕)
② 构图：对称/中心/三分/前景框架/留白·人景比例·机位高度
③ 光影：光源逻辑(单源/自然/实用光)·对比度·明暗分布·阴影质感(硬/柔)·高低调（若有体积光/逆光轮廓/百叶窗影/焦散等明确点出）
④ 色彩/调色：调色板·饱和·色温·grading(teal-orange/去饱和/单色/霓虹…)
⑤ 质感/介质：胶片颗粒或数字·锐/柔·年代感·笔触
⑥ 氛围/母题：签名元素(雾/水/烟/雨/霓虹…)·空间感·情绪基调
⑦ 运动/节奏（仅记录·供轨B参考·不进本次前缀）：若图能看出运镜倾向，一句话记下

然后严格用下面三行格式输出（供我直接入风格库，不要任何多余解释、不要复杂长句、只要可复现的视觉关键词）：
【风格名】<中文一句话定位>
【prompt_prefix】<英文·10-18个关键短语·开头点风格出处，如 "Wong Kar-wai style, ...">
【avoid】avoid text, avoid logo, avoid watermark<按图按需追加，如 avoid cartoon / avoid 3d render>
```

> 拿到输出 → 照 §B 条目格式追加进风格库（7 维要点 + prompt_prefix + avoid）。命中光影现象的，顺手在 §C 挂对应效果。

# §C · 光影 / 光学效果包（单层 · 可叠加层）

> **与 §B 的区别**：§B 是「完整风格包」（7 维一整套，定整片基调，一次只选一个当基底）；本节是「**单层光影/光学效果**」——它**不定整片风格**，而是**叠加在任意基底风格之后**，给某一条镜头/某一场景加一道具体的光影戏法。
> **怎么叠**：在服化道的风格前缀块里，把基底风格前缀写在前，把这里的效果短语**追加在后**。可叠 1-2 个，别堆太多（互斥的光影会打架）。
> **归属不变**：这些仍是「风格前缀」，由**服化道**写进身份级底提示词、**分镜师**写进 @图N 关键帧提示词（两处取同一条·生图阶段烧进画面）。
> **实战示例**：「角色在豪华别墅露天泳池游泳」这条镜头 → 基底用项目主风格（如真人写实/王家卫霓虹），**叠加 `水下丁达尔光柱`** 效果短语 → 服化道出的泳池参考图就会有阳光穿透水面的光柱、水面焦散光纹、漂浮光斑，质感立刻高级。

# §D · 在 demo / 项目里怎么用
- **服化道生图（基底风格）**：把 §B 任一前缀块当「风格前缀块」，放在中文场景/角色描述最前（同 visual-style-presets 用法）。
- **叠加 §C 光影效果层**：在基底风格前缀**之后**追加 §C 的效果短语（1-2 个），给某条镜头加一道具体光影戏法。组装顺序：`[§B 基底风格前缀] + [§C 效果短语] + [中文内容描述]`。例：真人写实基底 + `underwater sun shafts… caustic light patterns…` → 泳池游泳参考图自带水下光柱。
- **导演主动提示 → 用户拍板**：导演按 §C「三、触发关联表」扫场景线索，命中即在 production「场景与光影」字段标 `💡 建议光影效果：XXX`，主 Agent 通知时复述一句；**用户决定叠不叠**，服化道/分镜师据此在身份级底/ @图N 前缀追加效果短语。
- **同一内容 × 多导演风格**：锁死中文内容，只换 §B 前缀块 → 一个画面在库布里克/塔可夫斯基/黑泽明/原子朋克之间切换（控制力展示）。
- **扩展**：新导演/流派照 §A 拆 7 维 → 追加到 §B；新光影效果照 §C 格式（定位 + 英文短语）追加到 §C。这份就是系统的「导演/风格 + 光影效果」单一事实源。
