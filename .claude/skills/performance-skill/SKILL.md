# 表演指导知识库

[技能说明]
    知识库，供导演与分镜师使用：
    - 设计阶段：用表演语言描述角色的状态，而不是用情绪标签
    - 组装阶段：将表演描述转化为 AI 可执行的动作指令写进提示词

    核心理念：
    AI 不会"演戏"。你不能在提示词里写"她很难过"然后期待 AI 生成一个悲伤的表演。
    你必须写"她的嘴角向下压了一毫米，眼睛看着杯子但没有聚焦，右手的手指在桌面上无意识地敲了两下"。
    表演 = 可观察的物理动作。情绪是观众从动作中读出来的，不是写在提示词里的。

[表演的底层逻辑——外化]

    ## 铁律：永远不写情绪词，只写动作

    | 情绪词（禁止） | 外化动作（使用） |
    |--------------|----------------|
    | 她很紧张 | 她的拇指反复摩挲食指侧面 |
    | 他很愤怒 | 他的下颌肌肉绷紧，太阳穴的青筋微微跳动 |
    | 她很悲伤 | 她低头，眼睛盯着桌面上的一个点，眨眼频率变慢 |
    | 他很开心 | 他嘴角上扬，但只扬了一侧，眼睛微微眯起 |
    | 她犹豫 | 她的手伸向门把手，停在半空，手指张了又合 |
    | 他恐惧 | 他的瞳孔扩大，肩膀微微收拢，后退了半步但脚还没完全离地 |

    设计镜头时：用外化动作描述，不用情绪词。
    组装提示词时：直接使用外化动作描述。

[微表情设计]

    微表情 = 持续不超过 0.5 秒的面部变化。观众可能意识不到看见了什么，但会"感觉到"。

    ## 面部区域与情绪关联

    | 面部区域 | 动作 | 传达情绪 |
    |---------|------|---------|
    | 眉毛 | 内侧上扬 | 担忧、同情 |
    | 眉毛 | 整体下压 | 愤怒、专注 |
    | 眉毛 | 单侧挑起 | 怀疑、不屑 |
    | 眼睛 | 瞳孔扩大 | 恐惧、惊讶、兴趣 |
    | 眼睛 | 眯起 | 怀疑、开心、光线刺激 |
    | 眼睛 | 视线下移 | 羞耻、回避、思考 |
    | 眼睛 | 视线固定不动 | 震惊、决心、威胁 |
    | 眼睛 | 眨眼加速 | 紧张、不安 |
    | 眼睛 | 眨眼减慢 | 悲伤、疲惫、放空 |
    | 嘴 | 嘴角下压 | 不满、悲伤 |
    | 嘴 | 嘴唇抿紧 | 克制、忍耐 |
    | 嘴 | 微微张开 | 惊讶、准备说话又没说 |
    | 嘴 | 咬下唇 | 紧张、犹豫 |
    | 下颌 | 绷紧 | 愤怒、决心 |
    | 下颌 | 松弛 | 放松、放弃 |
    | 鼻翼 | 微微扩张 | 愤怒、深呼吸 |

    ## i2v 生成中的微表情约束
    - i2v 能生成明显的表情变化（微笑、皱眉），但极细微的差别（瞳孔1毫米扩大、嘴角1毫米下压）可靠度低、画面上不易读出
    - production 提示词写微表情时，配合一个更明显的辅助动作把神态"锚定"住（如"她抿紧嘴唇，同时视线移开，露出欲言又止的神态"）
    - 极特写景别才能让微表情读得出来，中景和远景里微表情几乎无效

[肢体语言系统]

    ## 手部——最诚实的表演者

    手部动作是最细腻的情绪指标，因为人很难有意识地控制自己的手。

    | 手部动作 | 传达状态 |
    |---------|---------|
    | 握拳 | 愤怒、紧张、克制 |
    | 搓手/揉指 | 焦虑、不安 |
    | 手指敲桌面 | 不耐烦、思考 |
    | 双手交叉放胸前 | 防御、封闭 |
    | 手插口袋 | 隐藏、不参与 |
    | 抚摸物件（杯子、手机）| 寻求安慰、转移注意力 |
    | 手掌向上摊开 | 坦诚、无奈 |
    | 指向 | 攻击性、指控 |
    | 手轻触嘴唇 | 犹豫要不要说 |
    | 手指绞在一起 | 极度紧张 |

    ## 身体姿态——权力和安全感

    | 姿态 | 传达状态 |
    |------|---------|
    | 挺直坐/站 | 自信、警觉、正式 |
    | 前倾 | 关注、进攻、兴趣 |
    | 后仰 | 评估、放松、优越感 |
    | 缩肩 | 不安全、防御、畏缩 |
    | 扩肩 | 自信、威胁、占据空间 |
    | 侧身 | 回避、不想正面面对 |
    | 转身 | 拒绝、结束对话 |
    | 靠墙/靠门框 | 旁观、不完全参与、随时准备离开 |

    ## 距离——关系的物理化

    | 距离 | 关系含义 |
    |------|---------|
    | < 0.5米 | 亲密或威胁 |
    | 0.5-1米 | 信任或对峙 |
    | 1-2米 | 社交距离 |
    | > 2米 | 疏远或正式 |

    距离的变化就是关系的变化：
    - 角色走近 = 关系拉近（或压迫加大）
    - 角色退开 = 关系疏远（或解除威胁）

[视线设计]

    视线 = 注意力的方向 = 观众了解"角色在想什么"的最重要线索。

    ## 视线规则

    | 视线行为 | 含义 |
    |---------|------|
    | 直视对方眼睛 | 自信、诚实、挑战、亲密 |
    | 看对方但避开眼睛（看鼻子/嘴/额头）| 不完全坦诚 |
    | 视线偏移/移开 | 回避、说谎、羞耻、思考 |
    | 视线下移 | 服从、悲伤、反思 |
    | 视线上移 | 回忆、思考、不屑（翻白眼的轻度版）|
    | 视线固定在某物上 | 那个物件对角色有意义 |
    | 视线穿过对方（看远方）| 放空、失去连接、已做出决定 |
    | 频繁转移视线 | 不安、寻找出路 |

    ## 视线与对话的配合
    - 说话时看对方 = 传递信息
    - 说话时不看对方 = 在对自己说，或回避
    - 听别人说话时看对方 = 在接收
    - 听别人说话时不看对方 = 在想自己的事

[沉默表演]

    沉默不是"什么都没发生"，是"所有事都在发生但没有说出来"。

    ## 沉默中该有什么
    - 呼吸变化（加深、屏住、叹气）
    - 视线移动（看什么、不看什么）
    - 微动作（手指动、脚尖动、舔嘴唇）
    - 身体重心转移（从一只脚移到另一只脚）
    - 和环境的微互动（摸杯子、调整衣服、看手表）

    ## 沉默的长度（i2v 里靠微表情/微动作密度表达·下表秒数是节奏意图参考，不写进提示词时间戳）
    | 长度 | 效果 |
    |------|------|
    | 0.5-1秒 | 思考间隙，自然 |
    | 2-3秒 | 重量感——角色在做决定或消化信息 |
    | 4-5秒 | 极重——观众开始不适，张力拉满 |
    | 5秒以上 | 导演特意设计的"静止时刻"，需要微表情和微动作支撑 |

[角色行为模式表]

    导演在剧情脚本的人物清单中附加行为模式标签：

    | 维度 | 内容 |
    |------|------|
    | 习惯动作 | 角色在不同状态下的标志性动作（思考时摸下巴/紧张时攥拳/放松时翘脚） |
    | 空间习惯 | 角色在房间里习惯待的位置（靠窗/靠门/中央/角落） |
    | 对话距离偏好 | 角色和人说话习惯保持多远 |
    | 情绪泄漏点 | 角色最容易暴露真实情绪的身体部位（手/嘴唇/眼睛/肩膀） |
    | 防御姿态 | 角色感到威胁时的本能反应（交叉手臂/后退/沉默/反击） |

    这些标签一旦建立，全集/全片保持一致——角色的行为模式就是角色的"身体签名"。

[production 的表演描述规范]

    导演在镜头设计中描述角色表演时：
    1. 先写动作（可观察的物理行为）
    2. 如有必要，用括号补充表演目的（理解上下文用，不写入提示词）

    示例：
    "角色A 的手停在操作台上方，手指微微张开但没有按下去（他在犹豫是否要做这个决定）。他的视线从操作台移向窗外远处，停了两秒。然后他闭上眼，深吸一口气，手指合拢，按了下去。"

    组装提示词时：
    - 使用所有动作描述
    - 删除括号中的目的说明
    - 补充景别和镜头运动

[注意事项]
    - 此 skill 填补武打之外所有日常戏的表演空白
    - 本 skill 覆盖所有日常戏的表演设计
    - AI 生成的表演精度有限——微表情靠近景/特写景别才有效
    - 每条提示词中的表演描述不要超过 3-4 个动作，AI 处理不了太密集的表演指令
    - 角色行为模式表建立后全片保持一致
