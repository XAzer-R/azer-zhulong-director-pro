# 分镜师 @图N 渲染卡产出模板（专业版 · 段级）

输出文件：`outputs/EPNN/<段号>-storyboard.md`（如 `outputs/EP01/S01-storyboard.md`）

**定位**：专业版分镜师**不出 i2v 视频提示词本体**（视频由导演 production 出），只**渲染 @图N 精修关键帧**——每镜一张（或关键镜多张）生图，**回填进导演 production 的素材对应表当 i2v 首帧/参考**。分镜师据导演 production 卡片的画面描述 + 服化道身份级底，**起可读底（大平光锁内容·忠实执行导演的画面描述/构图）→ 核对 Go → 三道洗（质感→光影→氛围）= @图N**，不重写、不回写导演意图。

**粒度**：按段产出。本段对应导演 production 的镜头 S0N（场景一条·内含分镜动作链 [C0N]）；**默认每个导演镜头 S0N 一张 @图N 渲染卡**——取该场景叙事重心的定格关键帧（一个 production 镜头是一段 [C0N] 动作过程，分镜师选喂 i2v 的那一帧）；关键镜可拆多张（见下方多图触发）。

**输入依赖**：
- 导演 production：`outputs/EPNN/<段号>-production.md`（视频提示词卡片 = 景别/机位/运镜/驱动模式/焦点/叙事 + 画面描述/分镜动作链 [C0N]/锁姿态 + 台词内嵌 + 表演走位 + 上传@图）
- 服化道身份级底：`assets/character-prompts.md` / `scene-prompts.md` + `assets/asset-index.md`（@图N）
- 摄影圣经：`assets/cinematography-bible.md`（风格前缀块 + 光源规则 + §6 场景映射）

---

## 产出白名单（硬规则）

storyboard **只能包含**：① 文件头 ② 段内总览 ③ 段级素材对应表 ④ 各剧情点（镜头 @图N 渲染卡）⑤ 段尾衔接 ⑥ 附·分镜师诊断（文末）。

**禁止**：
- 散文式阐述 / 五维打分诊断（诊断进文末「附」区，不夹进交付卡）
- **写 i2v 视频提示词本体**：驱动模式（首帧/首尾帧/续写）、运镜运动、分镜动作链 `[C0N]`、生成单元时长档、Seedance/可灵/即梦、模型选择、线稿——这些都由导演 production 写，分镜师不写、不回写 production
- 重写导演意图（景别/运镜/焦点/叙事/画面描述/构图由导演 production 定，分镜师只渲染 @图N + 三道洗）

## 每个剧情点

> **★卡片＝可读底 + 三道洗 = @图N（渲染顺序纪律·见 storyboard-skill）**：渲染卡显式分「可读底」（先出·大平光·锁内容·在服化道身份级底上按 production 卡片画面描述/构图忠实执行）与「三道洗」（核对 Go 后·一道一道叠：质感→光影→氛围）。先大平光起可读底、核对构图/identity 锁死，Go 了再顺序洗，洗完即 @图N。"内容稳了再一层层提升感觉"，避免 AI 在暗部高光里看不清乱改结构。

```markdown
## S01 <场景/镜头标题>（对应 production 镜头 S01）

### 镜头 S01 · @图N 渲染卡
**📦 加载**：[本镜命中硬映射表的 skill·如 material-pbr / cinematic-lighting；无则填"无"——供 keyframe-review 漏载检测门对账]

**【可读底 · 先出·大平光锁内容·在服化道身份级底上忠实执行 production 卡片】**
- **镜次·景别·机位**：[取自导演 production] 中景 · 正面平视
- **画面瞬间**：[取自 production 卡片「画面描述」——这一镜定格喂 i2v 的关键瞬间·角色此刻的动作/表情/姿态/走位的静态截面]
- **构图**：[取自 production 卡片「构图」] 占比 [角色约 X%] · 位置 [画面中央偏右] · 朝向 [侧面朝左] · 分层 [前景:… / 中景:主体 / 远景:…]
- **风格前缀**：[项目视觉 DNA·轨A·取自 bible/服化道风格前缀块——生图必写·与服化道参考图同一条·烧进底图]
- **上传素材**：人物 @图N <角色> / 场景 @图N <场景> / 道具 @图N <道具>（继承服化道身份级底）· **分开上传·不合成**
- **→【核对 Go】**：大平光出底，核对构图/identity/姿态对不对（见 keyframe-review-skill），Go 了再洗。

**【三道洗 · 核对 Go 后·一道一道叠·每道扫一眼防漂 = @图N】**（底子错了回可读底重起，绝不在洗图层硬改）
- **① 洗质感**（`material-pbr-skill`）：[本镜表面物理——金属菲涅尔/面板粗糙度差异/做旧/SSS/胶片颗粒。**光影氛围级质感归分镜师洗·服化道只出身份级底不焊渲染质感**；无质感重点镜可略]
- **② 洗光影**（`cinematic-lighting-skill`）：[**承接 production「影调/光影意图」**落地：主光方向·色温 / 对比(高中低) / 补光(soft fill 还是 weak fill) / 边缘光(rim 还是 soft edge) / 体积光；承接 bible §4 光源规则 + §8 色彩锚点。真人写实路线导演已设计布光·此处轻调]
- **③ 洗氛围（＝合成层 compositing）**（`cinematic-lighting-skill` 氛围块 + `_风格方法论与库.md §C` 光学效果包）：[调色 + 大气(雾/体积光) + 镜头光学(光晕 flare/辉光 bloom/色散/暗角) + 胶粒 + 粒子·**点到为止**·无需求可略·不做多层合成/运动模糊/后期景深]
- **avoid**：[出图层面负面约束，如 no readable text, no HUD overlay, anatomy correct hands, single light source]

**回填**
- **回填去向**：[本镜 @图N 回填进导演 production 哪个素材槽·喂 i2v 当首帧还是参考（驱动模式由 production 已定：首帧/首尾帧/参考）。镜头运动由 production 写·分镜师不写]

（每个导演镜头 S0N 一张卡；镜头之间以 `---` 分隔）
```
> 写每个字段都守**写物理不写形容词**（见 CLAUDE.md 写词纪律）：光影写主光方向/色温/对比，质感写菲涅尔/粗糙度，不写"高级感/电影感"空词。

# 自审摘要格式（subagent 返回消息中呈报 · 不产出独立文件）
```
## 自审摘要
- 业务审核：X.XX/10（PASS / FAIL · 最低单项 X 分于 S0N）
- 镜头覆盖率：全覆盖 / S0N 缺 N 镜
- @图N 合规：每镜有可读底 + 三道洗(质感→光影→氛围)·风格前缀已写·参考图分开上传·未写 i2v 视频提示词本体/未回写 production / 违规于 S0N
- 渲染顺序：先可读底核对 Go·再三道洗 / 违规于 S0N
- 回填去向：每镜已标喂导演 i2v 首帧/参考 / 漏标于 S0N
- 多图判断：关键镜 [列出] 已多图 / 误拆普通镜于 S0N
```
**判定**：PASS = 镜头全覆盖 + 每镜有合规 @图N 渲染卡（可读底 + 三道洗）+ 风格前缀已写 + 参考图分开上传 + 未写 i2v 视频提示词本体/未回写 production + 已标回填去向。FAIL → 自我修改至 PASS（最多 2 轮）。
