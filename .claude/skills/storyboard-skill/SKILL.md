# 分镜师 @图N 关键帧渲染 + 逐层洗图手册（专业版 · 执行层）

> **专业版说明（= 极速版 + 分镜师增强层·共用同一条视频主干）**：专业版不是两套并列系统，是极速版加了一道分镜师渲染层。导演一次成型出 **production（视频提示词 `<段号>-production.md`·提示词卡片：景别/运镜/驱动模式 + 分镜动作链 [C0N] + 台词内嵌 + 上传@图）**，结构与极速版完全一致、是用户在用的产出、神圣不可动。分镜师不翻译意图、不回写 production，而是**@图N 渲染流水线**——据导演 production 卡片的画面描述 + 服化道身份级底，**渲染该镜的精修关键帧**：**① 起可读底（大平光·锁内容）→ 核对 Go → ② 三道洗（质感→光影→氛围）= @图N**，回填进导演 production 的素材对应表，**喂导演 i2v 当首帧/参考**。**两入口**：per-shot 渲染 @图N + 回洗服化道身份级底补漏。
> **分镜师渲染的是关键帧（@图N），喂导演 i2v 当首帧/参考**：视频由导演 production 出，分镜师不出视频提示词、不取代 production，只把渲染好的 @图N 回填进 production 的素材对应表当 i2v 首帧/参考。
> **@图N 是生图**：写风格前缀（轨A·取自 bible/服化道风格前缀块·烧进底图）、写 avoid（出图层面负面约束）。镜头运动、驱动模式、分镜动作链是导演 production 的事，分镜师不写——只据 production 卡片的画面描述定格渲染那一帧关键帧。
>
> ⚠ **卡片最终格式以模板为准**：见 `storyboard-skill/templates/storyboard-template.md`——每镜一张 @图N 渲染卡（可读底：景别机位 + 画面瞬间 + 构图 + 上传素材 + 风格前缀 ‖ 三道洗：质感 → 光影 → 氛围 ‖ avoid + 回填去向）。本手册提供关键帧渲染 / 三道洗 / 构图 / 多图判断等**方法论**；落地格式按模板。

[技能说明]
    分镜师据导演 production（已含景别/机位/运镜/驱动模式/焦点/叙事/走位 + **画面描述/分镜动作链/锁姿态/上传@图**）渲染关键帧。每个**镜头**渲染**一张** @图N 精修关键帧（关键镜可多张）。流程 = ① 在服化道身份级底上起**可读底**（按 production 卡片的画面描述·大平光锁内容·忠实执行不重设计）→ ② **核对 Go**（构图/identity/姿态）→ ③ **三道洗**：质感（material-pbr）→ 光影（cinematic-lighting）→ 氛围（雾/粒子/调色）= @图N。导演 production 已定的画面描述/构图/景别/运镜/焦点/叙事**直接取用不重写**；分镜师只做关键帧渲染 + 三道洗 + 写 avoid + 标回填去向。渲染好的 @图N 回填进导演 production 的素材对应表，喂 i2v 当首帧/参考。

    **参考图使用原则**：场景图、人物图、道具图**各自独立上传不合成**（合成进生图工具会压缩掉画质和 identity）。@图N 取自服化道 `asset-index.md`，服化道未完成时用占位待回填。

[@图N 渲染 + 洗图流程]（每个**镜头一张精修关键帧** · 完整卡片格式与产出白名单以 `templates/storyboard-template.md` 为单一权威，本节只给执行要点）
    **A · 可读底（先·锁内容·大平光·在服化道身份级底上起）**
    1. **画面瞬间**：取导演 production 卡片里这一镜的「画面描述」（导演已定格）·忠实定格成关键帧；导演没写全时按 [画面瞬间选取] 补——写此刻角色的姿态/表情/走位/手部的静态截面，不写"他走过去然后……"。
    2. **构图**：取 production 卡片「构图」（占比/位置/朝向/前中远景分层）·忠实落图；导演没给够时按 [构图原则] 补。
    3. **风格前缀**：取自 bible/服化道风格前缀块统一登记的那一条（轨A·烧进底图）——**@图N 是生图，必须写**。
    4. **上传素材**：人物 @图N / 场景 @图N / 道具 @图N（继承服化道身份级底），**分开上传·不合成**。
    5. **大平光起可读底 → 核对 Go**：在服化道身份级底上先大平光起可读底、核对构图/identity/姿态（见 `keyframe-review-skill`），Go 了再洗。
    **B · 三道洗（后·一道一道叠·每道扫一眼防漂）**
    6. **第一道·洗质感**：材质 PBR（见 `material-pbr-skill`）。
    7. **第二道·洗光影**：戏剧布光（见 `cinematic-lighting-skill`）·落地导演影调意图（真人写实路线导演已设计布光·这里轻调）。
    8. **第三道·洗氛围（＝合成层）**：调色 + 大气（雾/体积光）+ 镜头光学（光晕 flare/辉光 bloom/色散/暗角）+ 胶粒 + 粒子（工具箱：`cinematic-lighting-skill` 氛围块 + `_风格方法论与库.md §C` 光学效果包）·点到为止。不做多层合成/运动模糊/后期景深（单张静态图不适用）。**洗完即 @图N 精修关键帧。**
    **C · 旁注**
    9. **avoid**：出图层面负面约束（见 [avoid 负面约束]）。
    10. **回填去向**：标明本镜 @图N 回填进导演 production 哪个素材槽、喂 i2v 当首帧还是参考（导演 production 已定驱动模式：首帧/首尾帧/参考）。**镜头运动/驱动模式由导演 production 写·分镜师不写·只标关键帧喂哪。**

[渲染顺序纪律 · 可读底 → 三道洗（硬规则）]
    @图N 最终在文生图工具渲染，**AI 在暗部/高光里看不清就会"脑补"——凭空加东西、改结构、重绘**。所以分镜师**先稳后美·分步渲染**：
    1. **可读底（先·锁内容·在服化道身份级底上起）**：大平光、可读性最高——人物/道具/构图/identity 全看得清。按**导演 production 卡片的画面描述/构图/锁姿态**起这张底（导演已定内容·分镜师忠实执行不重设计），把"画什么、谁在哪、什么姿态"在图上定死。
    2. **【核对 Go】**：可读底出来**先核对再洗**（构图/identity/姿态对不对·见 `keyframe-review-skill`）——**底没锁对绝不往上叠**（否则越洗越糊、回炉更亏）。
    3. **三道顺序洗（一道一道叠·每道洗完扫一眼防漂）**：
       - **第一道·洗质感**（`material-pbr-skill`）：金属/皮肤/布料/做旧的表面物理（清漆菲涅尔/粗糙度/AO/SSS/胶片颗粒）。
       - **第二道·洗光影**（`cinematic-lighting-skill`）：主光方向/色温/对比/边缘光/体积光。风格化路线落地导演影调意图；真人写实路线导演已设计布光、这里轻调。
       - **第三道·洗氛围（＝合成层 compositing·单张静态图相关的合成内容都归这）**（工具箱：`cinematic-lighting-skill` 氛围块 + `_风格方法论与库.md §C` 光影/光学效果包）：**调色**（grade/去饱和/teal-orange）+ **大气**（体积雾/体积光-丁达尔/霾）+ **镜头光学**（镜头光晕 flare/辉光泛光 bloom/色散/暗角 vignette）+ **胶粒**（film grain）+ **粒子**（火花/尘埃）·**点到为止**。
         > 不做（标准合成里对单张静态 AI 图不适用的）：多层合成/light wrap（单张图无 render 图层可合）、运动模糊（静帧）、景深作后期（已在构图/焦点定·不在此重做）。
    4. **铁律**：底子错了/换整套风格要**回可读底重起**，绝不在洗图层硬改（否则影调吞信息、AI 乱猜、结构被重绘，陷入抽卡循环）。
    5. **第二入口·回洗服化道身份级底补漏**：服化道只出身份级底（identity/造型/结构/材质身份＝"它是什么"·不焊光影氛围质感）。分镜师拿到身份级底先看渲染有没有到位，按三道洗给它补强——这就自然触发分步渲染（服化道做"它是什么"、分镜师做"它怎么被渲染"）。
    > **顺序铁证**：质感 → 光影 → 氛围（材质先于光影＝光打在已定材质上才对·氛围最后叠）。**高级感是控制出来的，不是堆词堆出来的——每个效果都要有物理逻辑和叙事理由，点到为止。**
    > **对照 CG 标准管线（为什么是这个顺序·不是拍脑袋）**：可读底 → 质感 → 光影 → 氛围 ≈ **布局 layout → 着色 shading → 布光 lighting → 合成 compositing**——工业渲染管线的因果顺序（材质决定表面如何响应光 → 光打上去 → 合成层罩在最上）。角色映射：**服化道＝建模**（身份级底/资产）· **导演＝布局+出口**（production：构图/机位/驱动 + 视频提示词）· **分镜师＝着色+布光+合成**（三道洗·渲染 @图N 喂 i2v）。术语对终端用户保留白话（质感/光影/氛围），CG 名仅作理解锚。
    > **谁的活在谁那层（边界·身份级 vs 光影氛围级）**：服化道＝轨A风格DNA + 身份级底（identity/造型/结构/材质身份＝"它是什么"·不焊光影/氛围/质感渲染）；导演＝production 出口（画面描述/构图/锁姿态/驱动模式·写进 production·出 i2v）；分镜师＝起可读底（执行 production 卡片）+ 三道洗（质感→光影→氛围）= @图N，回填 production 喂 i2v + 回洗服化道补漏。**光影氛围级的质感/光影/氛围全归分镜师洗。**

[画面瞬间选取 · 要点]
    导演 production 里一个镜头往往是一段动作过程（分镜动作链 [C0N]）。分镜师渲染 @图N 的工作是**选定格帧**——选喂 i2v 的那一帧关键帧：
    - **单图镜**：选这一镜**叙事重心**所在的那一帧（情绪核心 / 关键动作 / 台词落点的画面）。
    - 把"过程描述"转成"静态截面"：写此刻角色的姿态、表情、走位、手部，而非"他走过去然后……"。
    - **台词镜**：定格在台词最有张力的那一刻的口型/神态（台词本身是导演 production 的内容，@图N 记录"说这句时的画面"）。
    - 一帧讲不清的复杂动作 → 触发多图（见 [一镜一图 · 多图触发]）。

[一镜一图 · 多图触发]
    - **默认一镜一图**：取这一镜叙事最关键的瞬间，定格成一张 @图N 关键帧。
    - **关键镜可多图**，仅限以下情形，每张标 `-a/-b` 并写理由：
        - **表演转折**（情绪/态度在镜内反转）
        - **复杂动作分解**（一个动作需多帧才说清·如 起势→高潮→收势）
        - **情绪高点**（重场戏的关键定格值得多角度/多帧）
    - 普通镜**不许滥拆多图**。误拆 = 自审扣分。

[构图原则]
    **原则 1 · 占比定主次（硬）**：用角色/主体在画幅中的占比定义景别与注意力焦点——特写主体占 60%+ 强调面部、全景主体作小剪影强调环境大尺度、中景占 30-40% 强调上半身姿态。
    **原则 2 · 位置与朝向给叙事（硬）**：主体在画面的位置（中央/偏左/偏右/三分点）和朝向（正面/侧面/背面/四分之三面）承载叙事——朝向画面外的留白方向暗示去向/期待，正反打中同一角色始终在画面同一侧（180° 轴线）。
    **原则 3 · 前中远景分层（硬）**：除极近特写外，每张 @图N 写明前景/中景/远景三层——前景给遮挡或氛围（设备边缘/栏杆/粒子）、中景是主体、远景给空间深度。分层是关键帧电影感的核心，缺层 = 画面扁平。
    **原则 4 · 抽象动作→视觉元素（硬）**：背对/望向/凝视/回眸 → 翻译为 身体朝向 + 头部方向 + 视线所及物体的具体描述。导演 production 通常已给焦点，分镜师验证并落到构图即可。
    | 想要的效果 | ✅ 推荐写法（构图语言） |
    |---|---|
    | 特写面部 | 主体占 60%+·详细面部细节·浅景深背景虚化 |
    | 中近景上半身 | 主体占 30-40%·肩章/领口/颈部线条·中景层 |
    | 全景 | 主体作小剪影·环境大尺度元素铺满·远景层主导 |
    | 俯拍 | 头顶/肩膀/背部/地面透视占据画面 |
    | 仰拍 | 下巴/颈部/服装下缘/背景上仰 |
    | OTS 过肩 | 前景肩膀+后脑勺虚焦占 25% 作框架·焦点主体在另一侧 |
    | 倒影/镜面 | 画面中一面反射面·只画倒影中的姿态表情·不画本体 |

[光影原则]
    **先承接导演 production「影调/光影意图」**（元信息里的叙事决策：低长调？高反差？谁在光里谁在暗里？冷暖代表什么）——这是导演定的、分镜师不重写；再用 `cinematic-lighting-skill` 把它**落地成生图参数**（主光方向/色温/对比/补光术语/边缘光/体积光）。导演定意图、分镜师第二道洗光影时落地，和运镜分工一致。
    bible 给全片光源恒量，分镜师在不够时补充落到这一帧：
    - **主光源**：方向（左前/右后/顶光/底光）+ 色温（如 5600K 冷白 / 3200K 暖橙）+ 软硬（硬光锐影 / 柔光散影）。
    - **对比**：高（强反差·硬调）/ 中 / 低（柔和·平光）。
    - **辅光 / 氛围光**：承接 bible 光源规则补轮廓光/环境反射光。
    - **一致性**：同段/跨段同一场景光线方向、色温保持一致（写入文末诊断的跨镜一致性提醒）。

[风格前缀 · 硬规则]
    **@图N 是生图，必须写风格前缀**（与导演 production 视频提示词不写风格前缀相反·风格前缀归参考图/底图）。
    - 取自 `assets/cinematography-bible.md` 的「风格前缀块」/服化道参考图统一登记的那一条，**原样引用同一条**，不自由发挥、不每镜各写一套。
    - 风格前缀块只定义全片**身份级**视觉 DNA（机型/材质身份/胶片/画幅/颗粒等"它是什么"），保证所有 @图N 身份级风格统一、喂 i2v 时首帧一致；**调色/色温/对比/戏剧光影/大气氛围不进前缀**，属分镜师三道洗（光影/氛围）逐镜渲染、靠同一 bible 基线保持全片一致（身份级↔光影氛围级分界·见 art-design-skill）。
    - 服化道未配置时用占位 `[风格前缀·待 bible 回填]`，并在文末诊断标注待回填。

[avoid 负面约束 · 硬规则]
    **@图N 是生图，必写 avoid**（出图层面负面约束）。常用项：
    - 文字/界面污染：`no readable text, no UI overlay, no HUD, no watermark, no subtitle`
    - 解剖正确：`anatomy correct hands, correct finger count, no extra limbs`
    - 光影一致：`single light source`（与本镜光影设定匹配时）
    - 风格防漂：`no style drift, consistent character identity`
    按本镜实际需要取用，不堆砌无关项。

[抽象概念 → 物理翻译]
    AI 生图看不懂抽象概念，按"导演意图 → 物理动作/微表情 → 提示词"翻译，把情绪核心放句首给最具体物理描写：
    ```
    （压抑的计算）   → 眼睛不动·瞳孔微缩·手指轻点桌面一次 → "瞳孔微缩，右手食指轻点桌面一次后静止"
    （恐惧被理性压制）→ 咽喉微动·手指收紧后松开·呼吸幅度极小 → "喉结微微滚动，手指收紧后缓缓松开"
    ```
    - **括注 = 情绪密码**：镜头表/分镜动作链中 `（...）` 括注定义这个时刻"关于什么"，意图优先级高于同时刻其他动作，必须读懂并译为物理表现。
    - **一句一核心**：每张 @图N 只画一个情绪核心，承载情绪重量的姿态/微表情放句首最具体处，其余从属或省略。
    - **不加噪声**：不添加导演 production 里没有的动作/元素（噪声稀释情绪核心、分散 AI 注意力、提高出错率）。

[污染词扫描 · 硬规则]
    禁用事件名/抽象概念（打游戏、驾驶、战斗、瞄准、望向、注视、意识、记忆等）→ 改具体动作/姿态/物体。AI 看到某词就脑补整套刻板印象，即使被否定也不例外（写"不戴帽子"仍把人放进对应场景）。
    | ❌ 污染词 | AI 脑补陷阱 | ✅ 替代写法（具体视觉元素） |
    |---|---|---|
    | 意识 / 记忆 等抽象概念 | 生成发光大脑、抽象画面 | 描述具体物理表现（瞳孔收缩、手指无意识抽搐） |
    | 望向 / 注视 / 凝视 / 看向 | 强行出正脸 | 身体朝向 + 视线所及物体的具体描述 |
    | 背对 + 望向（叠加） | 给妥协侧身 | 拆成两条物理描述（身体背对 + 对应方向出现该物体） |
    | （题材专属事件名/生物名/设定名） | 生成刻板造型 | 用具体物理特征描述（外形/材质/几何结构/光线），按项目追加 |
    新发现污染词在文末诊断记录，审核时决定是否追加到 bible 负面约束。
