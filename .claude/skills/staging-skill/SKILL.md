# 多角色调度知识库

[技能说明]
    知识库，供导演与分镜师使用：设计多角色的空间关系、站位和视线——导演写进 production 的走位/分镜动作链，分镜师在 @图N 关键帧中精确描述每个角色的位置和状态。

    核心问题：
    AI 生成多角色场景时，角色越多越难控制——位置漂移、角色融合、动作混乱。
    3 人以上同框必须有明确的调度设计，否则生成结果一定是乱的。

[多角色调度的底层逻辑]

    画面中同时出现多个角色时，观众只能关注一个。
    调度的本质 = 在每个瞬间告诉观众"现在看谁"。

    实现手段：
    1. 空间位置——谁在前景谁在背景
    2. 动作差异——在动的人比静止的人吸引注意力
    3. 光线引导——亮的人比暗的人吸引注意力
    4. 视线汇聚——其他角色都在看的那个人 = 焦点
    5. 景别选择——近景中的角色比远景中的角色更受关注

[站位设计模板]

    ## 二人对话（基准）
    ```
    A <-> B
    ```
    正反打或双人中景，最简单的调度。

    ## 三人——三角站位
    ```
        A
       / \
      B   C
    ```
    最稳定的三人构图。A 在顶点 = A 是焦点/决策者。
    变体：等腰三角（三人平等）、锐角三角（A 远离 BC = A 被孤立/对立）。
    适用：讨论、对峙、一对二的谈判。

    ## 三人——一字排列
    ```
    A — B — C
    ```
    三人面向同一方向或面向镜头。
    B 在中间 = B 是视觉中心。
    适用：共同面对某个事物（屏幕、窗外景象）、仪式、并肩。

    ## 四人——菱形/方形
    ```
      A
    B   C
      D
    ```
    A 和 D 是对角线上的主要交流者，B 和 C 是旁观者/辅助者。
    适用：会议、审讯（A 审 D，BC 旁听）。

    ## 四人以上——层次分组
    超过 4 人时，不要试图让每个人都有独立存在感。
    将角色分为：
    - 焦点组（1-2 人）：前景，有动作和台词
    - 反应组（1-2 人）：中景，有反应表情
    - 背景组（其余）：后景，存在但不吸引注意力

    AI 提示词中只详细描述焦点组，反应组简要提及，背景组一句话带过。

[视线网络设计]

    多角色场景中，视线关系是最重要的调度工具。

    ## 视线汇聚（所有人看一个人）
    ```
    B -> A <- C
         ^
         D
    ```
    效果：A 是绝对焦点，权力/信息中心。
    适用：演讲、审判、宣布决定。
    提示词写法："所有人的视线集中在 A 身上。"

    ## 视线对抗（两组人互看）
    ```
    A -> <- B
    C -> <- D
    ```
    效果：两个阵营对立。
    适用：谈判、对峙、两队交锋前。
    提示词写法："A 和 C 面向右侧注视 B 和 D，B 和 D 面向左侧回视。"

    ## 视线分散（各看各的）
    ```
    A ->
    B v
    C <-
    ```
    效果：没有焦点，混乱/各怀心思/尴尬。
    适用：争吵后的沉默、各自思考、信任瓦解。

    ## 视线传递（接力看）
    ```
    A -> B -> C -> D
    ```
    效果：信息或反应在角色之间传递。
    适用：消息传来时的连锁反应。
    在提示词中按时间顺序描述："A 先抬头看向 B，B 转头看向 C，C 的表情凝固。"

[注意力引导——谁是焦点]

    在每个时刻，画面中必须有且只有一个焦点角色。
    其他角色要"让"出注意力。

    ## "让"注意力的方式

    | 方式 | 效果 | 提示词示例 |
    |------|------|-----------|
    | 静止 | 动的人吸引注意力 | "B 和 C 保持静止，A 站起身" |
    | 虚焦 | 清晰的人吸引注意力 | "前景 B 虚焦，焦点在后方的 A" |
    | 暗光 | 亮的人吸引注意力 | "A 被顶灯照亮，B 和 C 在阴影中" |
    | 背对 | 正面的人吸引注意力 | "B 背对镜头，A 正面面向镜头" |
    | 低姿态 | 高位的人吸引注意力 | "B 和 C 坐着，A 站着俯视" |

    ## 焦点切换
    当焦点从 A 转移到 B 时，需要一个"交接动作"：
    - A 的视线转向 B（最常用）
    - A 说了 B 的名字
    - 镜头从 A 推向 B
    - A 停止动作，B 开始动作

    提示词中不要同时让两个角色做大动作——AI 会混乱。
    一个时刻一个焦点，焦点切换要有明确的交接。

[AI 生成中的多角色控制策略]

    ## 角色数量与可靠度

    | 同框人数 | 可靠度 | 建议 |
    |---------|-------|------|
    | 2 人 | 高 | 自由发挥 |
    | 3 人 | 中高 | 明确站位，焦点角色详细描述 |
    | 4 人 | 中 | 焦点组+背景组分层描述 |
    | 5+ 人 | 低 | 焦点组详细，其余"模糊存在" |

    ## 提示词策略

    ### 3 人场景
    详细描述每个人的位置、朝向和动作。
    示例：
    "画面中三人呈三角站位。角色A（画面左侧，面朝右）双臂交叉在胸前。
    角色B（画面右侧，面朝左）靠在墙上。
    角色C（画面中央偏后，面朝镜头）坐在椅子上，双手放在扶手上。
    角色A 和角色B 的视线都指向角色C。"

    ### 4+ 人场景
    焦点组详细 + 其余模糊。
    示例：
    "前景：角色A 站在台前，双手撑在台面上（焦点角色，详细描述动作和表情）。
    中景：角色B 和角色C 分立两侧，面向角色A（反应组，简要描述朝向）。
    背景：其余人站在各自岗位上，注视着角色A（背景组，一句带过）。"

    ### 群演/多人背景
    不逐个描述，用整体描述：
    "空间内各操作台前坐满了人——有低头操作终端的、有交头接耳的、有盯着投影的。"

    ## 避免事项
    - 不要在一条提示词中让 3 个以上角色同时做不同的大动作
    - 不要在中景或远景中要求 AI 展现角色的微表情（看不清）
    - 不要给背景角色太多描述——AI 会把注意力分散到背景上
    - 不要让角色站在几乎相同的位置——AI 可能把两人"融合"

[导演 production 的多角色标注]

    当剧情点涉及 3 人以上时，production 的镜头设计中应标注：

    **调度设计**：
    - 站位：[三角/一字/菱形/层次分组]
    - 焦点：[此刻谁是焦点]
    - 视线网络：[谁看谁]
    - 焦点切换：[如果焦点在这段中转移，交接动作是什么]

    示例：
    "调度：三角站位，角色A 在顶点面朝角色B 和角色C。
    焦点：角色A（他在说话）。
    视线：角色B 看角色A，角色C 低头看桌面（她在想别的事）。
    焦点切换：角色A 说完后沉默，视线转向角色C——焦点交接到角色C，她缓缓抬头。"

[注意事项]
    - 多角色场景的核心原则：每个时刻只有一个焦点
    - AI 生成中角色越多越难控制——能用 2 人讲的故事不要用 4 人
    - 5 人以上同框建议用远景/全景建立一次空间关系，然后切到 2-3 人的近景组合
    - 焦点切换必须有交接动作，不能突然跳
    - 背景角色"存在"就够了，不需要详细描述
