# 创意转场方法论

[技能说明]
    知识库，供导演（含分镜）使用：
    - 设计阶段：为每对相邻镜头/剧情点主动设计转场创意，写入镜头表备注
    - 组装阶段：将转场创意落地为前一条结尾 + 后一条开头的精确提示词

[为什么需要创意转场]

    AI 视频生成（Seedance / Kling）的现实约束：
    - 单条生成 4-15 秒，成片需要多条拼接
    - **尾帧对不齐**：延长续写的尾帧常有运动模糊，下一条接不上
    - **首帧惯性断裂**：首帧锚定时上条运动惯性在新条中消失，观众感知"顿了一下"
    - 帧级对齐在 AI 生成流程中不可靠——这不是技术会进步就解决的问题，而是生成模型的本质特性

    创意转场的三层价值：
    1. **技术层**：不依赖帧对齐，从根源解决剪辑点问题
    2. **叙事层**：每次转场都可以完成场景切换、时间跳转、角色替换、情绪转折
    3. **视觉层**：观众感受"一气呵成"，视觉冲击力远超硬切

    核心理念：
    转场不是"技术补丁"，而是**创作工具**。好的转场本身就是叙事的一部分。

[遮挡转场 · 最可靠的创意手段]

    原理：前一条结尾安排某物完全遮挡镜头，画面被 100% 遮挡的那一帧切到下一条。
    观众视觉被遮挡物自然中断，大脑"眨眼"，对接缝感知最低。

    为什么遮挡最可靠：
    - 不需要任何帧对齐——遮挡帧本身就是黑/模糊/纯色，两条可以完全独立生成
    - 遮挡物的运动方向天然引导视线，切换后观众注意力已经被重新定位
    - 适用于所有类型的片段衔接：同场景、跨场景、时间跳转、角色替换

    经典案例：
    | 影片 | 手法 | 叙事功能 |
    |------|------|---------|
    | 《功夫》 | 成年周星驰 → 女主后脑遮挡 + 镜头横移 → 揭示童年周星驰 | 时间跳转（成年→童年） |
    | 《1917》 | 士兵穿过烟雾/废墟 → 出来后是新战场 | 空间转换 + 时间压缩 |
    | 《鸟人》 | 角色走过走廊拐角 → 拐角后是不同时段的同一走廊 | 时间跳跃（白天→夜晚） |
    | 《地心引力》 | 太空碎片撞击后画面全白 → 白光退去进入新空间 | 危机转换 + 空间跳转 |

    ## 遮挡物创意库

    | 遮挡类型 | 具体手法 | 适用情境 | 叙事潜力 |
    |---------|---------|---------|---------|
    | **角色身体** | 人物从镜头前走过/转身背影填满画面 | 跟拍、人群、走廊 | 角色替换、视角切换 |
    | **手/物体** | 手掌遮镜头、举起物品挡住画面 | 主观视角、特写 | 情绪转折（握拳→松开是新世界） |
    | **门/舱门** | 门关闭→重新打开是新空间 | 室内空间转换 | 场景切换的最自然方式 |
    | **建筑结构** | 柱子/墙角/隔板遮挡+镜头横移 | 横移跟拍 | 同一横移中切换场景/时间 |
    | **黑暗/阴影** | 走进黑暗区域/灯灭 | 光线变化的场景 | 情绪沉降、悬念 |
    | **烟雾/粒子** | 蒸汽/烟雾/尘埃/光斑漫过镜头 | 任意有粒子源的场景（雾/烟/尘/水汽） | 用粒子流盖住剪辑点 |
    | **快速甩镜** | 急速横摇产生运动模糊 | 快节奏、惊吓、转头 | 情绪加速、视角急转 |
    | **光线过曝** | 强光直射镜头→全白 | 开门、窗户、爆炸 | 希望、顿悟、场景跳转 |
    | **后脑/肩膀** | 摄影机推向角色后脑/肩膀 → 移开后是新画面 | 对话、回忆、情感 | 《功夫》式时间跳转 |

    ## 遮挡转场提示词写法

    **前一条结尾**（安排遮挡入画）：
    ```
    ...角色A转身，他的后脑和肩膀逐渐填满整个画面。
    ```

    **后一条开头**（从遮挡后揭示新画面）：
    ```
    镜头从角色A肩膀后方缓缓移开，露出[新场景/新时空的画面]。
    ```

    关键规则：
    - 遮挡必须做到至少 2-3 帧 100% 被遮挡，后期在此处切
    - 遮挡物运动方向和镜头运动方向协调（同向最自然）
    - 遮挡前后画面亮度尽量接近（大亮度差加 1-2 帧交叉溶解）

[经典电影转场创意库]

    除遮挡外，以下经典转场手法同样适用于 AI 视频制作：

    ## 匹配剪辑（Match Cut）
    前后两个画面在构图、形状或动作上高度相似，视觉惯性带动场景切换。
    - **形状匹配**：圆形物→另一圆形物、眼睛→孔洞/镜头、弧面→另一弧线
    - **动作匹配**：伸手触控→手掌按在舱壁、转身→旋转、脱离对接→分裂
    - **色彩匹配**：橙色灯光→橙色夕阳、蓝色水面→蓝色天空

    AI 视频实现：前一条视频的结束构图和后一条视频的起始构图设计为匹配图形，两条独立生成后硬切即可。

    案例：《2001太空漫游》骨头抛向天空 → 匹配切为太空站。

    ## 推进/后退揭示（Push-in / Pull-out Reveal）
    镜头极速推向细节（如眼睛、按钮、数据屏纹理）→ 从新场景的同类细节拉出。
    - 推入通讯界面微距纹理 → 拉出时已是另一个空间的同类界面
    - 推入角色瞳孔 → 拉出时角色在不同环境

    AI 视频实现：前一条以极端特写结束，后一条以极端特写开始，中间靠画面相似度衔接。

    ## 视线引导转场
    角色看向画面外某个方向 → 下一条从该方向展开新画面。
    - 角色抬头望天 → 下一条是天空/星空/远景空镜
    - 角色低头看手 → 下一条是手中物品的特写

    利用观众的视线跟随习惯，转场感知极低。

    ## 声音先行（J-Cut 逻辑）
    虽然驱动提示词不直接控制声音，但可以设计"听到声音后的反应"作为转场触发：
    - 角色竖耳/转头（反应先于视觉切换）→ 下一条揭示声音来源
    - 导演在镜头表中标注"声音先行"意图，后期音频跨越剪辑点

    ## 动势贯穿（Momentum Carry）
    一个运动动作跨越剪辑点，观众被运动本身吸引而忽略场景变化。
    - 镜头跟着飞行的物体（数据终端、工具、漂浮碎片）→ 物体落地时已是新场景
    - 角色快步行走，镜头跟拍 → 走过门框后空间已变

    与遮挡可组合使用：动势 + 建筑遮挡 = 最自然的空间转换。

[辅助拼接手段 · 段内使用]

    以下两种方法用于遮挡段内部的驱动条衔接，不作为跨镜头/跨剧情点的主要转场方案。

    ## 延长续写
    在上一条生成结果基础上直接延长，光线和角色位置天然连续。
    - 适用：同一遮挡段内的连续动作（角色一个动作拆成两条 clip 时·无缝缝合三招见 `seedance-kling-capabilities §3.5 片段间动作衔接`：保留重叠动作/剪辑点放动作中途/视觉暂留）
    - 限制：连续延长不超过 3 次（质量衰减）；尾帧运动模糊可能导致下次延长起点不清晰
    - 定位：遮挡段内部的"胶水"，不是跨段转场方案

    ## 首帧锚定
    截取上一条稳定帧作为下一条首帧，两条视觉锚点对齐。
    - 适用：同一空间内需要重新控制画面的位置（如换角度拍摄）
    - 限制：运动惯性在新条中断裂；截帧必须是"稳定帧"（无运动模糊）
    - 定位：遮挡段内部的"重置点"，不是跨段转场方案

    使用建议：优先用创意转场解决跨镜头/跨剧情点衔接，延长续写和首帧锚定只在单个镜头内部的多 clip 拼接时考虑。

[导演职责 · 镜头表中的转场设计]

    导演在剧情脚本的镜头表中，必须为每对相邻镜头思考转场：

    标注格式（写在镜头备注中）：
    ```
    P0X-03 → P0X-04 转场：遮挡（角色转身背影填满画面）→ 揭示走廊/通道全景
    P0X-05 → P0X-06 转场：匹配剪辑（圆形物特写 → 另一圆形弧线·形状匹配）
    P0X-06 → P0Y-01 转场：推入某物微距 → 拉出为更大空间/界面全貌
    ```

    设计原则：
    1. **每个镜头间都想一想**——不是都要用创意转场，简单场景硬切也可以，但要有意识地做决策
    2. **遮挡是默认首选**——不确定用什么时，先想遮挡，因为最不容易出错
    3. **转场服务叙事**——选择转场方式时优先考虑叙事价值（时间跳转？情绪转折？空间切换？），其次才是视觉效果
    4. **跨剧情点转场更重要**——P01→P02 的转场比 P01 内部镜头间的转场需要更多创意
    5. **标注具体创意**——不要只写"遮挡转场"，要写清楚遮挡物是什么、运动方向、揭示什么

[提示词中的转场执行]

    导演在视频提示词中落地转场创意：

    执行规则：
    1. **前一条驱动结尾**必须包含转场动作的前半段（遮挡物入画、推入特写、动作起势等）
    2. **后一条驱动开头**必须包含转场动作的后半段（遮挡物移开揭示、从特写拉出、动作完成等）
    3. 两条可以完全独立生成——转场创意的核心就是不依赖帧对齐
    4. 后期在遮挡帧/匹配帧处做硬切或 1-2 帧交叉溶解

    若设计阶段未标注转场创意，组装时主动补充：
    - 扫描前后镜头内容，寻找自然遮挡物（人物动线、道具、建筑结构、光线变化）
    - 找不到自然遮挡时，考虑匹配剪辑或视线引导
    - 实在没有好的创意时用硬切，但在备注中说明原因

[Seedance/Kling 能力边界]

    单条生成时长建议：
    | 时长 | 画面一致性 | 建议 |
    |------|-----------|------|
    | 4-8 秒 | 高 | 安全区，优先 |
    | 8-10 秒 | 中高 | 简单运镜可用 |
    | 10-12 秒 | 中 | 谨慎，避免复杂运镜 |
    | 12-15 秒 | 中低 | 风险区，可能漂移 |

    建议单条 8-10 秒，多条 + 创意转场拼接成长段落。

[注意事项]
    - 创意转场是工具不是目的——转场创意要服务于故事节奏，不要为炫技而转场
    - 简单场景硬切无罪——不是每个剪辑点都需要花式转场
    - 天然转场素材举例（按题材替换）：门/帘/帷幕开合、蒸汽/烟雾排放、尘埃/光斑、狭小空间的光影变化、水面/镜面反射——这些都是现成的遮挡/匹配素材
    - 后期是最后一道保险——再好的转场设计也可能需要微调接缝
