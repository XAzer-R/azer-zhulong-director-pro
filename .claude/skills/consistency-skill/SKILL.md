# 跨镜一致性方法论 · Consistency Engineering

## 核心命题

AI 视频生成的头号敌人不是"画面不好看"，而是"同一个人看起来不像同一个人"。多集项目不解决一致性，观众第 3 集就会出戏。

本 skill 不发明技术，而是把**业界已验证的一致性手段**整合为制片流程中的强制动作。

---

## 一、一致性的五个维度

每个镜头产出前，必须通过以下五维度检查：

| 维度 | 对象 | 失控表现 | 锚定手段 |
|------|------|----------|----------|
| **角色** | 脸、身材、发型、肤色、瞳色 | 换脸、身高忽高忽低 | 参考图 + @引用 + 三视图锚定 |
| **服化** | 服装版型、配色、质地、饰品、武器 | 同场戏换衣、纽扣数变化 | 服装色卡 + 关键细节清单 + 参考图 |
| **道具** | 关键道具的造型、材质、铭文 | 道具外形每集不同、设备换型 | 道具设定表 + @引用 + 多角度图 |
| **场景** | 空间布局、光源位置、装饰细节 | 同一房间家具搬家、窗户消失 | 场景宫格图 + 布局平面图 + 光位记录 |
| **时序** | 同场戏内动作连续性、伤痕、服装残损 | 上一镜干净下一镜染血（或反之） | 场内状态表（state table） |

## 二、三级锚定体系

### Level 1：参考图锚定（源头）

所有主要角色、关键道具、固定场景在 art-designer 阶段**必须产出参考图提示词**，并由用户在文生图工具生成参考图后入库。

**参考图的质量标准**：
- **角色**：一张图包含 `面部特写 + 全身三视图（正/侧/背） + 白色背景`，禁止抠图不干净、光影过强
- **道具**：`多角度图（至少 3 个视角） + 材质特写 + 比例尺`（放一只手或常见物体作尺度参照）
- **场景**：`宫格图（3×3 起） + 布局平面图（可手绘） + 关键光位标注`

**入库规则**：
```
assets/character-prompts.md  → 所有角色设定提示词 + 图号（@图N）
assets/scene-prompts.md      → 所有场景 + 道具提示词 + 图号
```

### Level 2：@引用传递（分镜层）

导演 在提示词卡片中**必须用 @引用语法**关联 Level 1 的素材：

```
良例：角色为{{@图1}}。场景为{{@图2}}。角色A背部直挺，右手食指缓慢从操作台抬起后放下。
劣例：一个穿外套的男人在室内中…
```

**硬规则**：
- 在 `character-prompts.md` / `scene-prompts.md` 中存在提示词 → **强制 @引用**
- 群演、一次性配角 → 不进对应表，文字直接描述
- 新增主要角色/场景 → art-designer 阶段补图，再进对应表

### Level 3：段间 handoff（段与段之间）

跨段视觉连续性靠**段尾交接包**传递：导演在 production 末尾写"段尾交接包"，下段只读该章节承接。

**handoff 级别（速查）**：L1 强锚定（同场景跨段·严格一致·强制）/ L2 软锚定（跨场景但情绪连续·色调光位匹配·推荐）/ L3 硬切（叙事跳转/时间跳跃/蒙太奇·不需连续·交后期）。

> 详细实现、信息来源、示例见下文 **§十一.2 段间 handoff 规范**（单一权威·勿重复维护）。

## 三、种子（Seed）控制规范

Nano Banana Pro 等生图工具支持种子控制。用于**同一角色/场景重复生成时的稳定性**。

**种子分配规则**：
- 每个主要角色分配一个**主种子**（primary seed），所有该角色的单人镜头优先使用
- 每个固定场景分配一个**场景种子**
- 多角色镜头使用**场景种子**，角色由 @引用锚定
- 特效/战斗场景使用**场景种子 + 时间戳后缀**，容许变异

**种子登记表**（写入 `assets/seeds.md`，首次使用时创建）：

```markdown
| 类型 | 对象 | 种子 | 首次使用 | 备注 |
|------|------|------|----------|------|
| 角色 | 角色A | 8472391 | EP01-S05 | 主种子 |
| 场景 | 室内指挥室 | 1028374 | EP01-S03 | 固定场景 |
| 道具 | 主载具外观 | 5519283 | EP02-S12 | 主载具主种子 |
```

**不要**在每个镜头随机种子——那等于放弃一致性。

## 四、场内状态表（State Table）

同一场戏内的连续性问题（染血、服装残损、伤痕、手持道具）靠**状态表**管理。

导演 在编写多镜头场戏前，先画一张状态表：

```markdown
## EP01 · 室内指挥室对峙 · 状态表

| 镜号 | 角色A状态 | 角色B状态 | 关键道具 |
|------|---------|-------------|---------|
| S12 | 外套整洁 | 站立，面无表情 | 操作台完好 |
| S13 | 外套整洁 | 身体微倾，瞳孔收缩 | 操作台完好 |
| S14 | 右颊划伤 | 后退一步 | 操作台裂纹 |
| S15 | 右颊划伤 + 衣领扯开 | 倒地 | 操作台裂纹 |
```

**硬规则**：一旦状态变化（血、伤、衣破），**后续所有镜头必须继承**，直到场景结束或明确清洗动作。

## 五、跨集一致性交接

多集项目在每集开始前必须执行"**跨集接续检查**"：

1. **上集末状态读取**：读取上一集末段 `outputs/<上集>/<末段号>-production.md` 段尾交接包，提取角色/场景末状态
2. **本集首状态对齐**：本集首张提示词卡片的角色状态必须与上集末状态匹配，除非剧本明确跳时间
3. **道具延续**：跨集出现的道具（如主载具、关键物品）使用**同一 @图号 + 同一种子**
4. **场景复用**：跨集复用的场景（如主载具内部、指挥室）**不得重新生成参考图**，必须复用 `scene-prompts.md` 原条目

违反以上任一项 → director 审核阶段 FAIL。

## 六、常见一致性陷阱与规避

| 陷阱 | 典型表现 | 规避 |
|------|---------|------|
| **群演脸** | 同一群演在相邻镜头脸变了 | 群演用"去个性化"描述（戴头盔/背影/远景），避免特写 |
| **手部** | AI 普遍画不好手，多指/缺指 | 握物/操作镜头避免特写手，或用参考图明确指法 |
| **文字/铭文** | 载具编号、徽章文字反复变 | 文字出现时用**图形符号代替字母**，或后期贴图 |
| **比例漂移** | 同一主载具尺寸在不同镜头不一致 | 与参照物同框（人、标准箱体），禁止纯空镜比例 |
| **光位变异** | 同场戏光源方向乱跳 | 场景参考图标注光位，分镜提示词每条复述主光方向 |

## 七、审核清单（director 使用）

审核任何分镜提示词时，逐条检查：

- [ ] 所有在素材表中的角色/场景/道具都使用了 @引用？
- [ ] 主要角色与场景是否使用了登记种子？
- [ ] 跨镜连续动作是否标注 handoff？
- [ ] 同场戏内状态（伤/血/服装残损）是否与状态表一致？
- [ ] 跨集接续是否通过上集末状态检查？
- [ ] 有无对手部/文字/比例的特写规避？

任一未满足 → FAIL，返回 导演 修改。

## 十一、工业化一致性双柱

专业版工作流（导演 production → 服化道身份级底 → 分镜师 @图N 精修关键帧 → 喂导演 production 的 i2v）下，一致性管控围绕两个核心机制。

### 11.1 参考图复用规范（Reference Image Reuse）

**背景**：多集项目中，同一角色/场景会在多个段反复出现。参考图由 art-designer 在服化道阶段生成一次，后续跨段/跨集复用。

**复用规则**：
- 所有参考图统一管理在 `assets/` 目录（character-prompts.md / scene-prompts.md + split 文件）
- 导演通过 `asset-index.md` 查询本段涉及的 @图编号，直接引用
- **跨集复用**：同一角色/场景在不同集出现时，**必须引用同一 @图编号**·不得重新生成
- **变体处理**：角色外观变化（如受伤、换装）由 art-designer 生成变体参考图，分配新 @图编号
- **场景多角度**：同一场景的不同角度使用后缀（@图N-A / @图N-B），首次使用时由 art-designer 补充

**参考图分开上传原则**：
- 人物设定图、场景图、道具图各自独立上传到 AI 视频生成工具
- **禁止合成**（将人物和场景合成为一张图上传）——合成会同时降低场景和人物的 identity 精度
- 每张提示词卡片的上传清单必须标注"分开上传"

---

### 11.2 段间 handoff 规范（Cross-segment Handoff）

**背景**：段落之间（S01 → S02 → S03...）的连接由后期剪辑承担，但视觉上必须有"承接感"——段尾画面和下段首镜在角色位置/光影/情绪上必须**连续**。

**三种 handoff 级别**：

| Level | 描述 | 实现 |
|---|---|---|
| **L1 强锚定**（同场景跨段）| 段尾和下段首镜视觉状态严格一致 | 导演在下段首张提示词卡片中明确承接上段尾帧状态（角色位置/朝向/姿态/环境） |
| **L2 软锚定**（跨场景但情绪连续）| 段尾和下段首镜在色调/光位/角色朝向保持匹配 | production 段尾画面标注 + 导演在下段首镜提示词中保持色调/光位匹配 |
| **L3 硬切**（叙事跳转）| 段尾和首镜视觉不需连续 | production 明确"硬切 · 下段独立起帧" |

**规则**：
- production 段尾画面字段里**明确标注** handoff 级别（L1 / L2 / L3）
- 导演按级别执行提示词承接

**信息来源**：
- 下段 导演 **只读上段 production 的"段尾交接包"章节**（约 10-15 行）获取 handoff 信息
- **不通读上段 production 的提示词卡片细节**（对本段无用）
- 交接包含：Handoff 级别 / 尾帧状态 / 跨段可复用素材
- 上段 导演 在段末产出时**必写交接包章节**（见 `director-skill/templates/director-analysis-template.md` 的"段尾交接包（给下段）"）

**示例（production）**：
```markdown
**段末尾画面**：角色A走出指挥室·画面定格在她背影+门半开状态。
**→ 下一段（EP01-S05）· handoff L2**（下段起帧角色A在走廊·色调/光位保持冷蓝单光源匹配）
```

## 十二、一致性审核清单（review-skill §1 执行）

基于一致性双柱，审核 production 文件时的核对：

| 核对项 | 触发 | 失败判定 |
|---|---|---|
| 参考图复用正确性 | 跨段/跨集出现的角色/场景是否引用同一 @图编号 | 扣分 |
| 参考图分开上传 | 上传清单是否标注"分开上传"·有无合成上传 | FAIL |
| handoff 级别标注 | production 缺 L1/L2/L3 标注 | 回流 director |
| handoff 执行一致 | 声明 L1 但下段首镜提示词未承接尾帧状态 | FAIL |
| @引用完整性 | 素材表中的角色/场景/道具是否全部使用 @引用 | 扣分 |
