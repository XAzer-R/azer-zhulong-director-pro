## 硬规则

1. 一旦某列状态变化（出血、衣破、伤痕、道具损毁），**后续所有行同一列必须继承**
2. 变化只能朝"更糟"走，除非剧本有明确清洗/换装/治疗动作
3. 光位一经确立，全场不变（除非明确切换时辰或关灯等事件）
4. 提示词编写时，每条必须复述该镜号在表中的状态
