# 服化道设计技能（专业版）

[技能说明]
    美术设计技能，将导演提供的人物清单和场景清单转化为可直接用于文生图工具生成参考图的详细提示词。

    **专业版关键职责**：服化道出的是**身份级大平光、高可读的底**——identity / 造型 / 结构 / 材质身份，即"它**是什么**"。这张底干净、平光、信息可读，**供下游分镜师在其上三道洗渲染（质感→光影→氛围）→ 精修成关键帧 @图N → 喂导演 production 视频提示词的 i2v**。所以**身份级"风格前缀块"由服化道写入每张参考图提示词的顶部**，把身份级风格 DNA 烧进底（皮衣就是皮的、赛博服装就是赛博的、机甲就是那套结构设计）；**光影 / 氛围级风格不在这层焊死**——那是分镜师三道洗时在底上渲染的。分界 = 「它**是什么**（身份级·服化道进底）」vs「它**怎么被渲染**（光影氛围级·分镜师洗）」。

    **链路全景（重构后·权威）**：导演一次成型出 `<段号>-production.md` 视频提示词（引用 @图N）→ 服化道出身份级干净底 → 分镜师在底上三道洗渲染、精修出关键帧 @图N → @图N 回喂导演 production 的 i2v。服化道是这条链上的**身份级底层**，不是终点；终点是分镜师精修的 @图N 进 i2v。

    人物提示词出图格式：一张图，左半边面部特写，右半边全身正面/侧面/背面设定图，白色背景。
    场景提示词出图格式：一张宫格图，每格一个场景（≤9→3x3 / 10-12→3x4 / 13-16→4x4，不满格留空）。

[风格前缀块 · 硬规则]
    每张人物/场景参考图提示词的**顶部**必须带"风格前缀块"，由两部分组成：

    1. **风格前缀（身份级）**（英文）：当前项目配置的视觉风格压缩前缀——**只取身份级那部分**（题材/质感身份/画幅/世界观风格 DNA，即决定"它是什么"的风格），戏剧光影 / 氛围调色 / 渲染情绪**不进这层**（留给分镜师三道洗）。来源：
       - 命中预设 → 取 `visual-style-presets.md` 对应预设的**压缩前缀**（人物用人物版、场景用场景版）
       - 未命中预设 → 走风格生成器（见 visual-style-presets.md 末"风格生成器"），现写一个新风格条目后取其前缀
       - 风格信息同步登记于 `assets/cinematography-bible.md`
    2. **生图 avoid**（英文）：图像生成专属负面约束。基线：
       ```
       avoid text overlays, avoid HUD elements, avoid watermark, avoid extra fingers, avoid deformed hands, avoid distorted face
       ```
       按角色/场景特性补充（如有视觉禁忌追加）。

    3. **光影/氛围级风格不在这层（移交分镜师·身份级↔光影氛围级分界）**：戏剧布光 / 体积雾 / 丁达尔 / 火花 / 情绪调色 / 电影级渲染情绪这类**光影氛围级风格归分镜师三道洗（质感→光影→氛围）**——服化道**只出身份级干净底**（大平光 + 结构 + 身份级风格 DNA），不叠戏剧光影 / 氛围效果。导演 production「场景与光影」里标的 `💡 建议光影效果：XXX` 由**分镜师**在三道洗时落地（取 `cinematography-skill/styles/_风格方法论与库.md §C` 效果短语），**不在服化道底上烧**。

    **注意**：这里写**生图 avoid**（服务于服化道身份级底这类生图）。专业版的链路是：服化道出身份级干净底 → 分镜师在底上三道洗渲染、精修出关键帧 @图N → @图N 喂导演 `<段号>-production.md` 的 i2v。**导演的 production 视频提示词不写风格前缀、不写 avoid**（风格由参考图承载，i2v 从 @图N 继承）。

[参照]
    - `assets/cinematography-bible.md`：场景/角色色彩必须符合全剧配色恒量
    - **三轨分工（专业版·身份级↔光影氛围级分界）**：服化道**只负责轨 A 的身份级部分**（机型/质感身份/胶片/画幅风格 DNA → 身份级风格前缀块·烧进底）；**轨 A 的光影氛围渲染（戏剧光/色彩氛围/情绪调色/电影级质感）归分镜师三道洗**，在服化道底上渲染；**轨 B·镜头运镜归导演**（写进 production·不进底前缀）。选定导演时服化道套其身份级风格 DNA、分镜师套其光影氛围渲染、导演套其招牌镜头运动。
    - `visual-style-presets.md`：风格前缀块来源（含风格生成器）；轨 A 现拆见 `cinematography-skill/styles/_风格方法论与库.md` §A-2「喂图现拆 meta-prompt」（服化道只取其中身份级维度）
    - **文生图提示词写法手册**：`gemini-image-prompt-guide.md`（Gemini / Nano Banana Pro 等文生图工具的提示词写法）；**身份级底范例**：`examples/character-prompt-examples.md`（人物）/ `examples/scene-prompt-examples.md`（场景）——照着写、对齐格式
    - 角色外观从剧本/项目设定中提取
    - production 段内"色彩锚点"标注：本段各剧情点的具体色彩意图（服化道仅作身份级参考，氛围落地由分镜师渲染）

[执行流程]

    第一步：读取上游产物
        - 读取本集各段 production（`outputs/<集号>/*-production.md`）中的人物清单和场景清单
        - 读取已有的 `assets/character-prompts.md` / `assets/scene-prompts.md`（如存在）
        - 按清单"素材状态"列，只为"新增"/"变体"项设计；"复用"项跳过
        - 确认当前项目的风格前缀块（命中预设 or 已生成的新风格）

    第二步：设计人物造型提示词
        为每个人物编写设定提示词，**顶部写风格前缀块（人物版前缀 + 生图 avoid）**，正文包含：角色整体定位、面部细节、体型、服装、配饰、鞋子、整体气质。
        出图布局：一张图，左半边面部特写，右半边全身三视图，白色干净背景，角色设定图风格。

    第三步：设计场景环境提示词
        将所有场景以宫格格式编写为一张整图，**顶部写风格前缀块（场景版身份级前缀 + 生图 avoid）**。每格一个场景（主视角），包含：地点类型与空间布局、时间、关键道具、空间纵深、结构。**只出大平光 + 高可读结构**——戏剧光影/氛围（情绪布光/体积雾/调色）**不在这里焊，留给分镜师三道洗在底上渲染**。所有格子身份级风格统一（风格 DNA 一致）、结构逻辑自洽。

    第三步-B：多角度场景图补充（按需）
        **为什么**：参考图分开上传，下游分镜师在场景底上渲染、出关键帧 @图N 依赖场景底传达空间信息。不同景别/机位需要不同视角的场景底。
        **识别规则**：扫描本集所有段 production，标记同一场景出现不同景别/视角、改变视角的机位、高频反复使用的场景为"多角度需求"。
        **角度规划**：为每个标记场景补充 1-3 个角度变体的独立提示词（非宫格），编号 @图N（主视角）/ @图N-A / @图N-B / @图N-C。每个角度变体基于主视角相同设定，调整视角/距离/构图，保持光影/色调/道具一致。

        **全景定位法则（场景变体硬规则）**：@图N（主视角）必须是该场景的**全景定位图（establishing master）**——选最能交代整体空间的最宽机位（如室内取"从入口望向纵深主体、一帧见全屋"），一帧锁住布局/陈设/立柱间距/光位/比例。所有 -A/-B/-C 变体都是这张全景的**"向内推近 / 改机位 / 反打"派生，不是另起炉灶重描**。
        - **出图顺序**：① 先出全景定位、审过、**锁 seed**；② 出各变体时**把全景定位图作为参考图喂入**再改景别/角度（含反打），保证同一空间不漂移。
        - 变体提示词正文显式声明"同一座 X、承接全景的布局/陈设/光位"，只写"改了什么机位/景别"，不重新发明空间。
        - 反例（禁止）：每个角度各写一段互不相干的独立空间描述 → AI 把同一场景画成几个不同的房间。

    第四步：输出
        - 人物提示词 → 追加到 `assets/character-prompts.md`
        - 场景提示词 → 追加到 `assets/scene-prompts.md`
        - 多角度场景图（如有）→ 追加到对应场景 split 文件 `assets/scenes/@图N_*.md`
        - 同步更新 `assets/asset-index.md` + 创建/更新 split 文件
        - **每张提示词顶部均带风格前缀块**

[角色设计要点（通用方法论）]
    - **identity DNA**：每个角色提炼一组不可变的视觉锚点（五官结构、发型、体型、标志性服饰/道具），跨集跨镜保持一致——这是后续视频不换脸的根基
    - **三视图布局**：左面部特写 + 右全身正/侧/背，白底，设定图风格
    - **外观关键词从剧本/项目设定提取**：年龄、性别、职业气质、服装功能性、配饰、使用痕迹（磨损/老化等讲述时间的细节）
    - **变体处理**：同一角色换装/老化/受伤 → 标"变体"，提示词中注明与原版的关联和差异，复用 identity DNA 的不变部分
    - **表情/姿态留给镜头**：身份级底保持中性大平光，具体表演由导演 production 的表演走位 + 分镜师在底上渲染/精修 @图N 承载
    - **非人/面部不可动角色（上一条的例外）**：机器人、面具人、玩偶、无五官角色——脸演不了，"表情留给镜头"不适用。改为给一个**可切换情绪载体**（LED 表情屏 / 可换面板 / 体态），每种情绪出一张**独立表情变体底**（标"变体"挂在该角色 @图N 下，如 @图N-惧 / @图N-思 / @图N-喜），分镜师/导演按情绪绑定对应变体；载体须注明**静帧显示、无动态过渡**。情绪靠运镜 + 体态 + 当前表情底承载。

[场景类型设计参考（通用）]
    用中性场景类型，按项目剧本实际填写光影/色彩/关键元素：
    | 场景类型 | 光影基调 | 色彩方向 | 关键视觉元素 |
    |---------|---------|---------|------------|
    | 室内-生活空间 | 自然光+实用光源 | 按项目调性 | 家具·个人物品·窗 |
    | 室内-功能空间 | 单光源·深影 | 冷调为主 | 设备·面板·指示灯 |
    | 室外-城市 | 环境光污染 | 冷暖混合 | 建筑·车流·广告 |
    | 太空-舱内 | 人造单光源 | 冷蓝+深黑 | 舱壁·终端·舷窗 |
    | 太空-外景 | 天体反射光 | 深黑+点光 | 行星·星场·结构 |
    | 界面-通讯 | 屏幕光·噪点 | 冷蓝+静电 | 通讯窗口·延迟标识 |
    （以上为参考骨架；具体光影/色温/配色以 cinematography-bible 为准）

[提示词写法原则]
    - **语言：正文用中文叙事，只有风格词用英文**——画面/人物/场景的正常描述用**完整中文段落**，不要关键词堆叠；**只有顶部"风格前缀块"（机型/胶片/调色师/画幅等风格词）+ 生图 avoid 用英文**。中英混排：英文风格前缀块在最顶，下面接中文叙事描述。
    - 具体化：所有描述具体到可视化程度
    - 摄影术语自然融入
    - 情绪通过视觉细节传达，不抽象描述
    - 风格统一：遵循当前项目配置的视觉风格（风格前缀块 + cinematography-bible），不擅自混入其它风格
    - **对照 CG 标准管线**：服化道＝**建模**（资产/形象·定"长什么样"·干净造型）；布局(构图/机位)是导演、着色/布光/合成(质感/光影/氛围)是分镜师。
    - **有垫图/参照图就只写身份 delta（硬规则·母版通用·所有带参照图资产适用）**：当某资产有参照图/垫图（如某带参照图的角色/机甲/场景）→ 提示词**只写这个资产独有的身份 delta**（区别于参照的造型/做旧/标志特征），**不堆通用渲染物理词**（clearcoat/Fresnel/AO/HDR tonemapping 那套——参照图已承载，堆了是冗余、还违"叙事优先于关键词堆叠"）。变体（同一资产换态）**只写与基底的 delta·不重画几何**。

[注意事项]
    - 人物提示词必须明确"左半边面部特写 + 右半边三视图"的布局要求
    - 场景提示词要含足够环境细节以确保可信度与一致性
    - 变体设计需注明与原版的关联和差异
    - **每张提示词顶部带风格前缀块**（风格前缀 + 生图 avoid）
    - 项目若有专属视觉禁忌（特定题材黑名单），在生图 avoid 与 cinematography-bible 中体现
