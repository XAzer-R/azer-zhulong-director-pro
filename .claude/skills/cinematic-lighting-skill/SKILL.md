# 电影级布光与影调方法论（@图N 关键帧生图层）

[技能定位]
    供**分镜师**第二道洗（光影）+ 第三道洗（氛围）使用（三道洗顺序：质感→光影→氛围）。**服化道场景只出中性平光（不焊戏剧光影/氛围）**，光影氛围归分镜师洗。@图N 关键帧是**生图**——光影决定一张关键帧"有没有戏"，渲好的 @图N 喂导演 production 的 i2v 当首帧/参考。配合 `material-pbr-skill`（材质负责"像不像真的"，光影负责"有没有戏"）。

[核心理念（铁律）]
    - **不是提示词里加"电影感曝光"这五个字就有电影感**。电影感来自**明暗的秩序**和**叙事意图**，不是形容词。
    - **影调是前期设计，不是后期滤镜**："滤镜是最后贴上去的，但影调是拍摄之前就已经设计好的。" 渲 @图N 关键帧时就要把光影**设计**进去，不是指望调色补救。
    - **高级感是控制出来的，不是堆叠出来的**。氛围不是"加得越多越好"，而是"**让每一个效果都有理由**"。点到为止。
    - **光是用来讲故事的**：电影级布光"不单只是照明的作用"——它表达故事的情绪与思想（哪里亮、哪里暗、光从哪来，都是叙事决策）。

[第一块 · 影调（先定基调）]
    **影调** = 画面从最暗到最亮各级明暗层次的分布关系 + 这种明暗关系形成的整体视觉倾向。

    **影调九宫格**（横轴反差：短/中/长 · 纵轴亮度：高/中/低）：
    | | 短调（反差小） | 中调 | 长调（反差大） |
    |---|---|---|---|
    | **高调**（偏亮） | 高短调 | 高中调 | 高长调 |
    | **中调** | 中短调 | 中中调 | 中长调 |
    | **低调**（偏暗） | 低短调 | 低中调 | **低长调** |

    **★ 低长调（最出电影质感·重点）**：以暗部为主要画面基底，**同时保留完整调域跨度**。画面整体低亮度倾向，但通过**局部高光 + 深黑位 + 暗部细节 + 中间调层次**形成**强烈而受控**的明暗组织。
    - 不是单纯的黑——黑位干净但**暗部有细节**；高光集中、背景压暗但不死黑；主体被局部光"切"出来；明暗跨度宽。
    - **影史参照**：《七宗罪》（暗部主导但有手电光/窗光/荧光灯把人物线索从黑里切出来）、《银翼杀手2049》（大面积低亮度 + 精准高光 + 体积光）、《沉默的羔羊》（脸部局部光、背景沉入暗部、心理压力强）、蝙蝠侠×小丑审讯室、《小丑》（病态城市低调·暗部很深但轮廓/脸/墙仍有层次）。
    - 一句话：**DC 比漫威更压抑、更有质感，差别就在影调的运用。**

[第二块 · 人物布光（把人从暗里"切"出来）]
    以"硬侧顶光打人物"为范式（适合压迫/危险/粗粝/愤怒的人物）：

    **① 主光：硬侧顶光（hard side-top light，如来自右上方）**
    - **受光区**：额头上方与额头皱纹、鼻梁、（红）鼻头、近光侧脸颊、耳朵、部分胡须。
    - **压暗区**：眼窝、背光侧脸、胡须深处、脖子与衣领、身体正面。
    - 效果：强化皮肤纹理/皱纹/胡须/脏旧质感 → 人物显得粗粝、愤怒、危险，压迫感"一步步逼近"。

    **② 补光：弱（区分两个易混术语·术语说明）**
    - `soft front fill`（柔和正面补光）：柔光补亮，**保留很轻微的阴影**，强调"柔"。
    - `weak frontal fill`（弱正面补光）：更弱，**只为"不要死黑"**，只保留最低限度的暗部细节。
    - 选择：要"表情清楚、情绪不恐怖"用 soft front fill；要"暗部压住、只留一点细节"用 weak frontal fill。

    **③ 边缘光/轮廓光（区分两个易混术语）**
    - `rim light`（商业轮廓光）：精致、强、干净——商业人像那种。
    - `soft edge highlight`（电影自然边缘光）：主导光从侧后切入时**自然形成**的边缘高光，**脏、硬、粗糙**——电影质感要的是这种，不是精致澎湃感。
    - 作用：把人物从昏暗背景里**分离**出来（沿白发/肩/手臂/磨损皮衣边缘）。

[第三块 · 三光位拆解（任何一张图都能拆成这三层）]
    - **主光**：来自某方向的强方向性硬光。特点：方向明确、光质硬、有明显光束；**不是均匀照亮，而是只"切"到脸/手/桌面/关键物**。
    - **辅光**：极弱环境补光。作用：画面更神秘、视觉重心更集中、让主光光束更有存在感。大面积保留黑位，不做均匀照亮。
    - **背景光/体积光**：高位侧逆光等。有烟雾/尘埃时，**光线本身成为画面的一部分**。

[第四块 · 体积光（让光被看见）]
    `off-frame high side-back light`（画面外的高位侧逆光）从后方/高处斜射，**穿过空气里的灰尘和薄雾，形成可见的体积光束（volumetric beams）**。
    - 作用：建立空间纵深、把前景人物从背景里分离、让"空气不空"。
    - 叙事用法（法庭案例）：左后冷蓝灰光打背景观众区（理性/距离/质度），右上暖白金光打人物轮廓（人性/温度）——**用色温对比讲故事**；中心对称构图表达"公平/秩序"；主光位置让"真正做判决的人处在光与暗的交界"。

[第五块 · 氛围三件套（让世界"活"过来）]
    **材质决定像不像真的，氛围决定世界是不是活的。** 三个词，每个都要有理由：
    1. **High Contrast（高反差/大光比）**：亮处更亮、暗处更暗、明暗关系更明确。主体亮 + 背景压暗 → 视线集中 → 压迫感；一束光切开黑暗 → 戏剧性。
    2. **Volumetric Smoke / Fog（体积烟雾·丁达尔效应）**：让光有路径、让空间有厚度。空气不空了，光更有存在感，远处更有层次，画面不那么"数码死硬"。
    3. **Sparks（火花）**：增添工业感、危险感、动态感、能量释放感。
    > **红线**：点到为止。堆过头 → 廉价海报感 / 游戏技能特效感 / 爆炸特效素材包感。

[第五块补 · 色调 → 情绪映射 + 色卡提取（调色层）]
    **颜色是有情绪的·色调本身就是情绪控制**。调色不是"调好看"，是**用主导色温/色相讲情绪**——和"用光讲故事"同源，只是落在色彩维度。影调定明暗秩序，色调定情绪基调，两者叠出画面的"戏"。

    **色调 → 情绪 映射表**（选基调时反查·非穷举·按剧情情绪挑）：
    | 主导色调 | 情绪 | 典型用途 | 提示词锚（中/英） |
    |---|---|---|---|
    | 冷蓝 / 青灰 | 孤独·疏离·理性·冷峻 | 都市夜·审讯·科技·回忆抽离 | 冷蓝青调，暗部偏青 / cool teal-blue grade, cyan shadows |
    | 暖橙 / 琥珀 | 回忆·温情·黄昏·怀旧 | 闪回·团聚·夕阳·温馨对话 | 暖橙琥珀调，金色高光 / warm amber grade, golden highlights |
    | 青橙对比（teal & orange）| 商业大片·张力·人景分离 | 动作·主流叙事·人物从环境跳出 | 暗部青、肤色暖橙 / teal shadows + warm orange skin |
    | 青绿 / 病态绿 | 不安·末日·腐败·诡异 | 灾难·惊悚·反派空间·中毒 | 病态青绿调，低饱和 / sickly green grade, desaturated |
    | 高饱和暖红 / 品红 | 危险·欲望·愤怒·警示 | 冲突峰值·情欲·霓虹 | 浓烈红品调，高饱和 / saturated crimson-magenta |
    | 低饱和灰调（去色）| 压抑·麻木·绝望·纪实 | 创伤·贫困·冷硬现实 | 低饱和灰调，近黑白 / desaturated muted grade |
    | 高调暖白 / 过曝柔光 | 纯净·梦境·天堂·入口 | 梦境·回忆入口·和解 | 高调暖白，轻微过曝柔光 / high-key warm overexposed glow |
    > 用法：调色服务剧情情绪，不是套滤镜。一个场景定一个主导色调当基调，重场戏可用**色温对比**讲故事（冷光区=理性/距离、暖光区=人性/温度，呼应第四块体积光的法庭案例）。全片底色温恒量记入 `cinematography-bible.md §4`，段内色彩锚点在导演 production「色彩锚点」字段标。

    **色卡提取 workflow（复刻某帧的色调）**：
    1. **截参考帧**：截一张你认可色调的电影/广告/照片帧。
    2. **AI 出色卡**：把该帧喂 AI，让它提取**主色板**（5-7 个 HEX + 各自占比 + 用途标：主导/高光/暗部/点缀）。
    3. **套色调**：把色板当**全能参考**喂生图（@图N 关键帧渲染时叠在风格前缀后），或写进提示词"整体色调匹配以下色板：[HEX 列表]，[暖/冷] 主导"。
    4. **统一全片**：同一特辑各镜套同一色板 = 视觉黏合剂（即使画风/场景不同，统一 LUT/色调也能剪在一起不割裂）。
    > ⚠️ 目测估的 HEX 是近似值，最终以生图实际出色为准；多镜统一靠同一份色板，不靠逐镜口述。

[第六块 · 可直接复制的提示词模板（中英对照）]
    **A · 低长调（高端男性香水广告·示范基调）**
    ```
    男性香水高端广告画面，低长调影调，深色极简背景，瓶身位于画面中央，边缘有精致轮廓光，玻璃瓶身出现穿镜面高光，液体呈深琥珀色透明层次，金属瓶盖有冷硬反射，暗部保留细节。
    ```

    **B · 硬侧顶光打人物（粗粝/危险/愤怒）**
    ```
    人物脸部由右上方硬质侧顶光局部切亮，额头皱纹、鼻梁、鼻头和画面右侧脸颊出现强烈高光；眼窝、画面左侧脸、胡须深处和脖子保留深阴影；形成强烈明暗对比，突出粗粝、愤怒、危险的表情。
    ```
    `The character's face is partially carved by a hard side-top light from the upper right, creating strong highlights on the forehead wrinkles, nose bridge, nose, and screen-right cheek, while eye sockets, screen-left face, deep beard, and neck remain in deep shadow — strong light-shadow contrast emphasizing a rough, angry, dangerous expression.`

    **C · 边缘光把人物从暗背景分离**
    ```
    右上方硬光在人物凌乱白发、右肩、手臂和磨损皮衣边缘形成粗粝边缘高光，使人物从昏暗背景中分离出来。
    ```
    `the upper-right hard light creates rough edge highlights on the messy gray hair, right shoulder, arm, and worn leather edges, separating the character from the dark background.`

    **D · 高位侧逆光体积光（空间氛围）**
    ```
    画面外的高位侧逆光从后方斜射下来，穿过空气中的灰尘和薄雾，形成明显体积光束。
    ```
    `off-frame high side-back light streaming down from behind, cutting through dust and haze to create visible volumetric beams.`

    **E · 三光位整合（强方向硬侧光 + 极弱环境补光 + 逆光轮廓 + 体积光）**
    ```
    右侧后方一道强烈方向性光线斜射进空间，局部照亮人物脸部、手部和关键物，形成强烈明暗对比；
    脸部被狭窄侧向硬光局部照亮，眼窝和下半张脸保留深阴影；
    极弱环境补光，暗部大面积保留黑位，不做均匀照亮；
    右后方逆光在肩膀、耳朵和背景物体边缘形成细窄轮廓光，使主体从黑暗中分离；
    空气中有细微灰尘和薄雾，使光束可见，形成明显体积光和空间纵深。
    ```

[落到 @图N 关键帧（分镜师怎么用）]
    - @图N 关键帧「光影」字段：先定**影调**（低长调？高反差？）→ 再写**主光方向/光质/受光压暗区** → 按需叠**补光（soft/weak fill 选准）/ 边缘光（rim/soft edge 选准）/ 体积光 / 氛围三件套**。
    - **用光讲故事**：重场戏的光位要服务叙事（谁在光里、谁在暗里、色温冷暖代表什么）——这正是导演 production「影调/光影意图」在画面上的落点。
    - **配合生图顺序**：光影是三道洗的第二道，**先在信息版底用大平光锁好构图/identity，内容稳定后再叠布光**（见 storyboard-skill 生图顺序纪律）。换整套光影风格要回信息版底重做，不在洗图层硬改。
    - `avoid`：`avoid flat even lighting, avoid clipped highlights, avoid muddy black with no detail, avoid over-stylized filter look`。

[与其他 skill 的关系]
    - `material-pbr-skill`：材质（像不像真的）打底，本 skill（有没有戏）做戏剧性——两者合出电影级机甲/角色。
    - `cinematography-skill`：含镜头语言（景别/构图/运镜意图）**和一套打光方案/主光九分类**——与本 skill 在光影上有重叠。分工：**分镜师写「光影」字段以本 skill 为落地主源，cinematography 的打光表作术语/灵感参考库**（与 storyboard-skill 的裁决一致）。bible §4 光源规则（全片光源恒量）是本 skill 在项目级的落点。
    - `art-design-skill`：风格前缀块归属与登记；本 skill 是其"布光/影调层"的深化。
