# 动作编排知识库

[技能说明]
    知识库，供导演（含分镜）使用：
    - 设计阶段：用专业动作术语描述角色运动，设计动作节奏曲线和环境交互编排
    - 组装阶段：将动作编排转化为 i2v 可执行的运动描述、按事件顺序写进 production 的分镜动作链 [C0N]，并按身体力学约束校验合理性

    核心理念：
    动作编排不是"跳、跑、翻、爬"的笼统描述。每个跑酷动作都有专业名称和精确的身体力学，
    每段动作序列都有节奏曲线（加速-减速-凝固-爆发），每个建筑元素都对应特定的可用动作。
    一段连续动作在 production 里写成按事件顺序的分镜动作链 [C0N]，由 i2v 生成视频实现——怎么把动作 beat 排成动作链、每个 beat 怎么描述运动，就是动作编排的镜头语言。
    导演既要知道角色"能做什么"，也要知道"怎么写进 production 让 i2v 拍出来"。

    与其他 skill 的关系：
    - 对抗性武打/格斗不在本 skill 范围（如需在动作链按物理动作直接描述）
    - performance-skill 覆盖非武打场景的表演（微表情、肢体语言、沉默戏）
    - long-take-skill 覆盖创意转场/遮挡缝合方法论
    - **本 skill 覆盖非对抗性动作序列**——跑酷、追逐、逃脱、攀爬、特技、坠落
    - 边界：本 skill 覆盖一个人跑/跳/翻/爬等非对抗动作；武打格斗不在范围
    - 可组合使用：动作序列中的表演（performance）+ 动作编排（本 skill）+ 遮挡缝合（long-take）

    ## 地面移动

    | 动作 | 英文 | 视觉特征 |
    |------|------|---------|
    | 跑酷步伐 | Stride | 连续跳跃式奔跑，每步精确瞄准落脚点，像攻击性的定点冲刺 |
    | 受身落地 | Depth Drop / Precision Landing | 前脚掌落地，膝髋深屈吸收冲击，重心极低，无声着地 |
    | 肩滚翻 | PK Roll / Shoulder Roll | 从一侧肩膀到对侧髋部的对角线滚翻，分散向前/向下的冲击力 |
    | 四足移动 | QM / Quadrupedal Movement | 手脚交替的低姿爬行，用于低矮障碍下方穿越或动作间过渡 |
    | 猫式平衡 | Cat Balance / Rail Walk | 在窄面（栏杆、窗台）上缓慢精确移动，双臂展开平衡 |

    ## 跳跃与精准着地

    | 动作 | 英文 | 视觉特征 |
    |------|------|---------|
    | 定点跳 | Precision Jump | 双脚起跳到精确落点（窗台/栏杆），脚趾扣住边缘，膝盖吸震，零多余动量 |
    | 跑步定点跳 | Running Precision | 冲刺起跳到精确落点，双脚同时落地锁定 |
    | 跨越跳 | Gap Jump | 全速跨越间隙（楼间/平台间），身体在空中完全伸展，双腿前收准备着地 |
    | 鹤立落地 | Crane Landing | 单脚落在精确点（栏杆顶端），另一条腿向后伸展平衡，如鸟栖枝 |
    | 猫扑 | Cat Leap / Arm Jump | 跳向墙面，双脚先触墙吸震，双手同时抓住顶缘，身体以紧凑蹲姿悬挂在墙面 |
    | 跑步猫扑 | Running Cat Leap | 冲刺后猫扑，覆盖更大距离，墙面冲击更爆发 |
    | 踢墙跳 | Tic-Tac / Wall Kick | 单脚蹬墙改变运动方向——身体斜向接近墙面，单脚踩踏，弹开转向 |
    | 双踢墙跳 | Double Tic-Tac | 连续两次蹬墙：在相邻或对面墙之间之字形上升/横移 |

[动作组合与流线设计]

    ## 流线原则

    1. **动量连续**：每个动作的出力喂入下一个动作的入力，暂停 = 断流
    2. **最少过渡步**：障碍之间的衔接步数压到零——能跳就不跑
    3. **环境决定技术**：建筑结构决定用什么动作，不是反过来
    4. **角色性格决定风格**：同一段路线，不同角色的动作选择不同（见 [环境叙事] 节）

    ## 自然链接规则（什么动作接什么）

    | 结束状态 | 自然接续 |
    |---------|---------|
    | 翻越落地（前向动量）| Stride → 下一个翻越 / 跑步定点跳 / 冲刺 |
    | 下落落地（下向动量）| PK Roll → Stride / QM 过渡 / 弹起翻越 |
    | PK Roll 出（前向+地面）| 冲刺 / QM / 弹起翻越 / 跑步猫扑 |
    | 猫扑悬挂（静止墙面）| 攀上 / 猫扑到猫扑 / 踢墙跳离墙 / 下落 |
    | 摆荡释放（空中弧线）| 定点落地 / 下一杆抓握 / 猫扑 / PK Roll |
    | 跑墙峰值（垂直动量耗尽）| 抓缘攀上 / 墙上后空翻弹离 / 蹬离定点跳 |
    | 定点落地（零动量）| 原地定点跳 / 原地翻越 / 下落 / 静止停顿 |
    | 空翻落地（旋转收束）| Stride 跑出 / Roll / 下一个空翻 / 翻越 |

[环境交互模式]

    ## 建筑元素 → 可用动作映射

    ### 低墙（腰到胸高 · 0.7-1.2m）
    速度翻 / 猴子翻 / 冲刺翻 / 懒人翻 / 安全翻 / 猴冲混合翻 / 猫式翻越 /
    回身翻 / 反转翻 / 盗贼翻 / 弹跳翻 / 双猴翻（长墙）/ 三猴翻（超长墙）

    ### 高墙（头顶以上 · >2m）
    垂直跑墙（2-3 步上墙抓缘）/ 猫扑（跳到悬挂）/ 攀上（悬挂到翻上）/
    踢墙跳（蹬墙改向）/ 墙上后空翻（跑墙峰值弹出后翻）/ 墙上旋转

    ### 楼间间隙 / 平台间隙
    跨越跳（全速飞跃）/ 定点跳（短距精准）/ 跑步定点跳（长距精准）/
    猫扑（远端太高无法落顶时抓缘）/ 摆荡释放（如有横杆跨越）/
    PK Roll（大落差着地时必须滚翻卸力）

    ### 栏杆 / 管道 / 横杆
    摆荡释放 / 穿杆 / 翻杆 / 引体翻上 / 摆振上 / 栅栏翻 /
    栏杆定点 / 猫式平衡 / 栏杆滑行

    ### 楼梯 / 斜面
    Stride（跳跃式跳级下行）/ 下落（从平台跳下）/ PK Roll（底部卸力）/
    栏杆滑行 / 速度翻（翻过扶手）/ 懒人翻（斜角过扶手）

    ### 垂直墙面
    垂直跑墙 / 水平跑墙 / 踢墙跳 / 双踢墙跳 / 墙上后空翻 /
    墙上旋转 / 猫扑 / 猫式翻越

    ### 窄巷（两墙对面）
    双踢墙跳（之字上升）/ 猫扑墙到墙 / 烟囱攀爬（背靠一墙脚蹬另一墙）

[哥特/废土建筑跑酷机会]

    本节为项目特化——废土哥特世界观下的建筑元素与跑酷动作对应关系。

    ## 哥特建筑元素

    | 建筑元素 | 跑酷功能 | 叙事/视觉价值 |
    |---------|---------|-------------|
    | 飞扶壁 | 天然桥梁/高空走道，连接建筑间的高处通道 | 建立垂直感；角色剪影映衬天空；极致暴露=极致张力 |
    | 尖塔/小尖顶 | 垂直攀登目标；顶部窄面平衡 | "旗杆时刻"——角色到达顶点鸟瞰全局 |
    | 石像鬼/怪兽雕塑 | 抓握点、摆荡点、短暂栖身处 | 角色蹲在石像鬼上——与怪兽雕塑同姿态的主题映射 |
    | 尖拱 | 拱顶作为平衡梁；拱下方作为摆荡杆；拱开口作为跳跃框架 | 天然画框——角色从拱中跳向/离镜头 |
    | 玫瑰窗 | 破碎穿越的奇观时刻（彩色玻璃碎散）| 壮观的破坏性入场——彩色光碎片飞散 |
    | 肋穹顶（室内）| 头顶横越路线——沿穹顶肋条如猴子杆移动 | 极端仰拍（仰望天花板上的角色）制造视觉迷失 |
    | 钟塔 | 垂直追逐/逃脱路线：内部有梯、绳、钟机构 | 钟在打斗中响起 = 关键叙事节拍的声音标点 |
    | 回廊/柱廊 | 节奏性柱间距创造连续翻越序列；掩体间战术移动 | 重复几何创造与剪辑节奏匹配的视觉韵律 |

    ## 废墟建筑元素

    | 建筑元素 | 跑酷功能 | 叙事/视觉价值 |
    |---------|---------|-------------|
    | 裸露钢筋 | 即兴抓握杆和摆荡杆；窄面平衡 | 工业衰败美学；锈色对比灰色混凝土；视觉危险信号 |
    | 坍塌墙面 | 半高墙作为翻越障碍；墙洞作为穿越通道；崩塌风险=动态障碍 | 环境不稳定=张力。角色通过后墙体崩落=惊险一瞬 |

    | 悬挂碎片 | 摆荡元素（悬垂管道、电缆）；闪避障碍 | 动态环境——角色经过时物件晃动、碰撞、坠落 |

    | 建筑元素 | 跑酷功能 | 叙事/视觉价值 |
    |---------|---------|-------------|
    | 水平管道 | 栏杆滑行、平衡梁、头顶摆荡杆 | 管道在全景中创造几何图案 |
    | 垂直管道 | 攀爬柱；消防杆式下降 | 垂直移动多样性——不只是爬墙 |
    | 蒸汽喷口 | 计时障碍（在喷射间隙通过）；遮挡缝合的天然烟雾 | 蒸汽填满画面 = 完美的 i2v 片段遮挡缝合点 |
    | 吊臂/起重臂 | 极高处水平穿越；缆绳滑降 | 参考《Casino Royale》建筑工地吊臂追逐 |
    | 铁链 | 摆荡元素；攀爬辅助；缠绕障碍 | 动态音效——链条碰撞声传达重量和危险 |
    | 栈道/格栅走道 | 高处窄通道；透视地板制造眩晕 | 透过金属格栅看到远处地面 = 内脏级高度传达 |

[动作节奏设计]

    ## Speed Ramp 理论（变速设计）

    Speed ramp = 在同一镜头内交替使用慢动作和正常/快速播放，由 i2v 生成时实现。写进 production 时用 `[V0N]` 标变速点（velocity·区别于分镜动作链 C0N）标"哪几个 beat 慢放成奇观瞬间、哪些位移 beat 走常速带过"，按事件顺序写、**不写秒级时间戳/帧率**。

    **何时减速**：
    | 时机 | 原因 | 示例 |
    |------|------|------|
    | 冲击瞬间 | 让观众看清撞击/着地的物理细节 | 拳头接触面部的一帧 |
    | 决策点 | 角色选择方向/策略的瞬间 | 三条岔路前的一秒犹豫 |
    | 峰值危险 | 碰撞/坠落/爆炸前的最后一秒 | 子弹从身侧掠过 |
    | 技术展示 | 展现精准身体力学的动作 | 深渊跨越的最高点身体舒展 |
    | 情感转折点 | 被背叛的认知/盟友的出现 | 转头看见意外的人 |

    **何时加速**：
    | 时机 | 原因 | 示例 |
    |------|------|------|
    | 过渡移动 | 跑动/穿越开阔地带不需要细看 | 障碍之间的冲刺 |
    | 重复动作 | 连续打击只需展示第一下 | 连续三拳只慢放第一拳 |
    | 动量积累 | 用加速制造冲向高潮的推力 | 起跳前三步加速 |
    | 混乱渲染 | 用速度压过观众的信息处理能力 | 爆炸碎片四散 |

    **Speed Ramp 在 production 中的标注**（用 `[V0N]` 标变速点·按事件顺序·不写秒级/帧率）：
    ```
    [V01 常速] 加速三步蹬地
    [V02 慢动作·奇观瞬间] 起跳腾空峰值：身体脱离楼沿、披风展开如翅（动量最大的空中瞬间慢放）
    [V03 常速] 落地，不停顿继续跑
    ```

    ## 呼吸技术（Breath / Decompression）

    高速序列中插入的微暂停——让观众喘息、消化、重新定位。

    **实现方式**：
    - 0.5-2 秒的反应镜头（角色表情的短暂特写）
    - 大冲击前的静止瞬间（"尖叫前的吸气"）
    - 切到旁观者或环境细节的简短插入镜头
    - 快速剪辑序列中的单帧慢动作
    - 远景重新建立空间关系

    **节奏比喻**：动作序列像海浪——有波峰（高速动作）也有波谷（呼吸暂停），
    但每一波的峰值都比上一波更高。

    **导演脚本中的标注**：
    ```
    S07 → S08：节奏断裂（从 FPV 高速追踪骤停为远景静止 · 暴风眼设计）
    ```

    ## 升级模式（Escalation Pattern）

    动作序列必须在时间轴上持续升级——危险、复杂度、筹码逐步加码。

    **五条升级轴**：
    1. 环境危险递增：地面 → 楼顶 → 吊臂 → 真空跨越
    2. 个人筹码递增：为任务 → 为生存
    3. 身体代价递增：生龙活虎 → 负伤挣扎
    4. 选项收窄：多条逃路 → 被逼入死角
    5. 对手能力递增：小兵 → 精锐 → BOSS

    **常见错误**：每一拍都是同样的强度——没有升级感意味着没有方向感。

    **波浪结构**：每个子序列有自己的 蓄力-高潮-呼吸 小弧线，
    但每一波的高潮峰值都超过上一波。

    ## 三的法则（Rule of Three）

    动作序列中给角色三件事要完成：

    | 次序 | 效果 | 观众感受 |
    |------|------|---------|
    | 第一次 | 相对顺利，建立方法和信心 | "原来如此" |
    | 第二次 | 出错，引入复杂度和怀疑 | "糟了" |
    | 第三次 | 需要创造性即兴和最大筹码 | "太绝了" |

    案例：《美国队长2》——三艘航母需要重编程。第一艘顺利，第二艘极难，第三艘要英雄以命相搏。

    ## 影响帧设计——哪些瞬间值得慢动作

    **值得慢放**：
    - 序列中的首次重大撞击（建立暴力的物理真实感）
    - 优势翻转的那一击
    - 终结一击 / 致命一击
    - 出乎意料的技巧或创意
    - 制造新障碍的环境破坏
    - 身体喜剧节拍（跌倒、擦过）

    **不值得慢放**：
    - 连击中的每一拳（慢放第一拳，压缩其余）
    - 标准位移（移动本身不是重点时）
    - 速度本身是卖点的时刻（角色的压倒性速度感需要正常/加速来传达）
    - 重复动作（只慢放第一次）

[FPV 追拍方法论]

    ## 镜头与主体的位置关系

    | 位置 | 效果 | 适用 |
    |------|------|------|
    | 背后追踪 | "你是追猎者"——最常见的追逐位置 | 标准跑酷追踪 |
    | 上方俯瞰 | "上帝视角/监控感"——揭示路线和前方障碍 | 建立空间地理 |
    | 侧面并行 | "跑步伙伴"——强调奔跑姿态和速度 | 角色跑姿展示 |
    | 前方反向 | "你在被追"——展示角色面部表情 | 恐惧/决心/疲惫 |
    | 不可能角度 | 穿过间隙/从腿下/从窗洞穿越 | 超现实沉浸感 |

    ## 距离与情绪

    | 距离 | 情绪效果 |
    |------|---------|
    | 超近（0.5-1m）| 恐慌、密闭恐惧、无处可逃——伸手可触 |
    | 近（1-3m）| 紧张、投入、个人关切——标准动作追逐距离 |
    | 中（3-8m）| 语境与投入兼顾——展示主体在环境中的位置 |
    | 远（8-15m）| 规模感、脆弱感、孤独——主体在世界中渺小 |
    | 极远（15m+）| 监控、徒劳——世界广袤而冷漠 |

    ## 速度匹配 vs 速度差

    | 策略 | 效果 |
    |------|------|
    | 速度匹配 | 主体固定在画面中，世界移动——稳定持续的张力 |
    | 镜头追近（加速）| 追猎者在靠近——不可避免感——威胁升级 |
    | 镜头落后（减速）| 主体拉开距离——速度优势——逃脱或胜利感 |
    | 镜头飞过（超速）| 超越主体——揭示前方景象——视角从追随变为引领 |

    ## Chest Mount vs FPV Drone vs 机械臂

    | 方式 | 优势 | 限制 | 最佳用途 |
    |------|------|------|---------|
    | Chest Mount（胸前绑定）| 真实人体运动（呼吸、晃动、身体倾斜）；最强沉浸感 | 受限于人体能去的地方；运动速度受限 | 第一人称 POV、密闭空间、角色认同 |
    | FPV 无人机 | "不可能镜头"路径；速度从悬停到 180km/h；流畅超人运动 | 需要高技术飞手；碰撞风险 | 追逐序列、空间揭示、建筑间穿越 |
    | 机械臂/索道 | 最精确可重复的运动轨迹 | 受限于物理轨道/索道基础设施 | 编排精确的场景、可控环境 |

    **混合方案**：专业制作（如《Skyfall》集市追逐）整合所有三种，
    用隐藏剪辑点在 FPV/机械臂/稳定器/身体绑定之间无缝切换。

    ## FPV 一镜到底的 i2v 实现

    i2v（Seedance/Kling）单条无法真正生成超长一镜到底，"一镜到底"靠多条 i2v + 遮挡缝合表达连贯感。实现策略：
    1. 将这段一镜到底的运动拆为若干条 i2v，每条覆盖 FPV 路径上的一段
    2. 相邻 i2v 之间保持镜头位置/朝向的连续递进，让观众感知为连续移动
    3. 每条 i2v 的结尾安排物理遮挡物完全覆盖画面，下一条从遮挡物后方揭示新画面，后期在遮挡帧处硬切作缝合点
    4. 遮挡物必须是场景中的自然物体（建筑楼角、角色披风、柱子、蒸汽）
    5. 每条 i2v 的景别、机位高度、主体在画面中的位置都在 production 里标注清楚，并由分镜师渲染 @图N 锚首帧构图

    Chest Mount 视角在 production 提示词中的实现：
    ```
    FPV drone tracking shot, continuous unbroken shot, chest-level POV,
    character's back partially visible in lower frame (cape hem, hair tips, shoulder blades), foreground motion-blur
    ```

[身体力学约束]

    导演设计动作时必须遵守的物理约束——违反会导致观众出戏。

    ## 跳跃距离

    | 跳跃类型 | 普通人 | 训练者 | 精英/极限 |
    |---------|-------|-------|---------|
    | 原地立定跳远 | 1.5-2.0m | 2.5-3.0m | 3.4m（世界纪录） |
    | 助跑跳远 | 3-4m | 5-7m | 8.95m（田径纪录） |
    | 跑酷定点跳 | 1.0-1.5m | 2.0-2.5m | 2.76m |
    | 翻越距离 | 1.0-1.5m | 2.0-2.5m | 2.57m |

    - 最佳起跳角度：20-30°（非理论值 45°）——水平速度比起跳角度更重要
    - 高差优势：从高处向低处跳增加水平距离（3m 高差可增加 2-4m 水平距离）

    ## 跑墙物理

    - 最大高度增益：约 1.5 倍站立垂直跳跃高度，世界纪录 3.99m
    - 墙面接触时间：0.5-1.5 秒（2-3 步）
    - 接近角度：30-60°（非垂直接近）
    - 接近速度：训练者 4-6 m/s（14-22 km/h）
    - 关键：跑者**先离地再接触墙面**，水平动量通过向下蹬踏转化为向上动量

    ## 着地力学

    | 落差高度 | 主要技术 | 相比硬着地减力 |
    |---------|---------|-------------|
    | 0.6-1.0m | 精准着地（前脚掌 + 屈膝）| 约 38% |
    | 1.0-1.8m | 精准着地或过渡为滚翻 | 视技术而定 |
    | 1.8-2.7m | 肩滚翻（必须）| 约 43%，冲击速率降 63% |
    | 2.7-3.0m+ | 滚翻必须；仅限专业练习者 | 关键生存技术 |

    - 经验丰富的男性跑酷者报告安全最大着地高度约 3.05m（10 英尺）
    - 更重的人和爆发力较弱的人在更低高度就需要滚翻

    ## 负重影响

    - 每增加 5kg 装备：跳跃距离减少约 5-10%，着地冲击力等比增加
    - 全副装甲增加 6-8% 呼吸限制（35kg 负重时升至 15%）
    - 重心前移、姿态改变、平衡能力下降
    - **角色叙事价值**：重装角色应使用蛮力型移动（撞穿、翻越），
      轻装角色使用流畅型跑酷——这正是《Casino Royale》的对比策略：
      Mollaka（轻盈流畅）vs Bond（沉重破坏）

    ## 移动速度

    | 移动类型 | 速度范围 |
    |---------|---------|
    | 普通人冲刺 | 6.3 m/s（~23 km/h）|
    | 运动员冲刺 | 8-10 m/s（29-36 km/h）|
    | 含障碍的跑酷移动 | 4-7 m/s（14-25 km/h）|
    | 跑墙接近速度 | 2-6 m/s（7-22 km/h）|

    关键约束：障碍环境中的跑酷移动比平地冲刺慢 30-50%（每个障碍都需要减速-技术执行-再加速）。

    ## 体力衰减与银幕时间

    影视中的时间流速与现实不同。一段 10 分钟的银幕追逐可能压缩了 2 分钟或 20 分钟的故事时间。
    体力衰减不按时钟推进，而是按**叙事节拍**触发——每次重大冲击/失误/消耗都是一个退化触发点。

    ### 四阶段衰减模型

    | 阶段 | 触发条件 | 动作质量变化 | 影视参考 |
    |------|---------|------------|---------|
    | 巅峰 | 追逐开场 | 流畅、高效、标志性风格完整展现。动作干净，呼吸均匀，选择最优路线 | Casino Royale：Mollaka 开场的芭蕾式跑酷 |
    | 裂痕 | 经历 2-3 个重大障碍或首次险情后 | 落地略重，可闻喘息，微停顿变长。仍能完成高难度动作，但不再完美 | Bourne Ultimatum：穿窗跳跃后的短暂恢复停顿 |
    | 退化 | 受伤/重大挫折/长时间高强度后 | 踉跄、选择更简单路线、偏重未伤侧、翻越从猴翻降级为安全翻。开始犯错——手滑、踩偏、翻滚不干净 | MI Fallout：摩托车坠毁后的跛行冲刺 |
    | 意志力 | 最后一搏，"全部或全无" | 绝望、粗糙、可能完全放弃技术直接硬爬/硬跳。动作从美感退化为求生本能 | Casino Royale：Bond 最终放弃跑酷直接橄榄球式冲撞进大使馆 |

    ### 导演编排要点

    - **阶段转换本身就是戏剧时刻**——角色第一次踉跄 = 观众意识到"他快撑不住了"
    - **可以短暂回升**：肾上腺素爆发让角色从"退化"短暂回到"裂痕"，但随后跌得更深
    - **阶段跨度随追逐总长度自适应**：2 分钟的追逐可能只展现"巅峰→裂痕"；15 分钟的追逐走完全部四阶段
    - **不同角色衰减速度不同**——这本身就是角色塑造（Casino Royale：Mollaka 始终在巅峰，Bond 从裂痕打到意志力，但 Bond 赢了——意志力>技术）
    - **追赶者的衰减也要编排**——如果只有被追者在累而追赶者永远精力充沛，悬念会失真

    ### 银幕时间换算参考

    以下不是硬规则，而是经典动作片的统计规律：

    | 追逐银幕时长 | 典型阶段分布 | 参考片段 |
    |------------|------------|---------|
    | 1-3 分钟 | 巅峰 → 裂痕（或巅峰全程） | Baby Driver 开场追车 |
    | 3-6 分钟 | 巅峰 → 裂痕 → 退化 | Bourne Ultimatum 丹吉尔屋顶追逐 |
    | 6-10 分钟 | 四阶段完整 | Casino Royale 工地追逐（~10min） |
    | 10 分钟+ | 四阶段 + 多次回升-再跌落 | MI Fallout 巴黎→伦敦追逐链（~15min） |

[动作剪辑理论]

    ## 动作中剪辑（Cut-on-Action）

    在运动进行中剪辑——观众的眼睛追踪运动而非剪辑点。
    通常在动作进行到 1/3 时切换角度——前 1/3 在旧角度完成，后 2/3 在新角度展现。

    **对 i2v 的意义**：在角色运动中段拼接两条 i2v 是最宽容的接合点，
    因为运动本身掩盖了两条 i2v 之间角色外观或环境的细微不一致。

    ## 冲击剪辑（Impact Cut）

    在碰撞/打击/爆炸的精确瞬间切换角度——冲击的最大视觉能量完全吸引观众注意力。
    新角度展示冲击后果（面部弹开、物体碎裂），读作因果而非摄影机变化。

    ## 构成性剪辑（Constructive Editing）

    从**从未连续发生过的片段**中构建连贯的动作序列。
    这是所有 i2v 动作制作的基础原理——每条 i2v 独立生成，
    通过剪辑组装成"连续"动作。

    库列肖夫的创造性地理：证明了可以用不同位置的镜头组合出观众认为统一的空间。
    i2v 天然就是构成性剪辑——每条片段都是独立"拍摄"，连贯性来自剪辑组装，而非单次拍摄的连续性。

    ## 180° 规则

    追逐/打斗中的假想轴线——镜头停留在同一侧保持银幕方向一致。
    追逐中被追者始终一个方向，追击者始终另一个方向。

    **何时打破**：
    - 叙事性迷失：故意让观众失去方向感（Bourne 系列）
    - 力量翻转：优势逆转的瞬间——银幕方向逆转=心理逆转
    - 方向变化：被追者掉头时必须越轴

    **平滑越轴**：插入轴线上的中性镜头 / 镜头内可见的物理越轴 / 远景重建空间

    ## 环境叙事

    **角色如何与障碍互动揭示性格**：
    | 风格 | 特征 | 暗示 |
    |------|------|------|
    | 高效/军事型 | 直线路径、精准翻越、零花活 | 受过训练、纪律严明 |
    | 创意/即兴型 | 非常规路线、跑墙、空翻 | 适应力强、自信 |
    | 恐慌/绝望型 | 踉跄、勉强够到、碰撞障碍 | 恐惧、筋疲力尽 |
    | 掠食者型 | 占据高处、战术路线、耐心选路 | 智慧、控制欲 |
    | 零代价型 | 全程零表情变化、动作流畅如水 | 超人/非人、能力远超环境挑战 |

    **破坏之路设计**：
    1. 序列开始时建立完整环境（美景镜头）
    2. 首次破坏是附带的（偏弹打中柱子，裂缝出现）
    3. 中段升级——结构元素开始失效，制造新障碍和新路线
    4. 高潮时环境已面目全非——迫使角色适应全新地形

[动作序列的 i2v 片段分割]

    专业版把一段连续动作拆成一组 i2v 片段，每条由导演写进 production 的分镜动作链 [C0N]。怎么切片段、怎么排，决定动作戏读起来是否流畅。

    ## 片段分割策略

    - 每段动作序列拆成若干条 i2v，**每条包含一个主要动作节拍**——单次翻越、单次跳跃、单次落地
    - 优先把"奇观瞬间"单独成段或慢放：身体伸展最大的空中段、冲击/着地的接触段、动量凝固的峰值段
    - 在自然切换点切片段：冲击瞬间、方向变化、遮挡时刻——这些点前后接续最宽容
    - 一个动作节拍如果信息量大（起跳→腾空→着地），可在一条 i2v 的动作链里按事件顺序写 2-3 个 [C0N] beat

    ## production/i2v 提示词策略（SAEC 框架）

    每条 i2v 的 production 提示词适用 SAEC 锚定主体与运动：

    1. **S - Subject**：第一句锚定主体——先描述背景会导致 i2v 模型丢失角色焦点
    2. **A - Action**：使用强动作动词描述**这一段的运动**——不写"a man running"，写"a man sprints with muscle tension"
    3. **E - Environment**：简洁描述环境关键特征
    4. **C - Cinematics**：景别 + 机位角度 + 镜头运动 + 光影 + 速度（运动模糊暗示速度）

    - 提示词控制在 **80-100 词**以内——过长导致模型注意力分散
    - 分段描述运动：动作链按事件顺序（"先…然后…同时…"），不写秒级时间戳
    - 先由分镜师渲染 @图N 关键帧锁定角色姿态/光照/构图当 i2v 首帧，i2v 模型只在其上添加运动

    ## 遮挡缝合节奏

    每 2-3 条 i2v 设计一个全画面遮挡时刻：
    - 蒸汽喷口 / 柱子经过 / 爆炸 / 身体横穿近景
    - 这是一致性要求最低的"缝"，前后两条 i2v 可独立生成
    - 利用遮挡帧切换镜头角度、角色朝向或环境状态

    ## 空间地理维护

    - 每 4-5 条动作 i2v 插入一条"重建"远景片段——重新锚定空间关系
    - 使用一致的环境标记（同一根断柱、同一个蒸汽喷口）跨片段锚定地理
    - 分镜师生成 2-3 张不同角度的 @图N 场景参考用于维护整组 i2v 的空间一致性

    ## 动作描述规范

    1. 使用本 skill 的专业术语，不用笼统描述
       - ✗ "她跳过了间隙"
       - ✓ "她执行跨越跳（Gap Jump），身体在四米深渊上方完全伸展，双腿前收精准着地"

    2. 每个片段只描述一个主要动作节拍，辅以环境碎片细节
       - 主要动作：角色做什么（一个动作）
       - 环境反馈：环境怎么回应（碎石、粉尘、震动）
       - 镜头碎片：近景锚点（披风、发尾、碎屑掠过画面边缘）

    3. Speed ramp 段使用 [V01][V02][V03] 标注速度切换点（变速点·区别于分镜 C0N）

    4. 提示词总长控制在 80-100 词——AI 模型注意力在长提示词中碎片化

    ## 物理约束校验

    导演在写提示词时对照 [身体力学约束] 校验：
    - 跳跃距离是否在合理范围内？
    - 落差高度是否需要 PK Roll？
    - 跑墙高度/时间是否可信？
    - 角色负重是否影响动作选择？

    如发现导演设计超出物理约束，标注 `⚠ 物理约束：[说明]` 并建议替代方案。

    ## 遮挡缝合点与动作的协调

    FPV 一镜到底段中，缝合点的遮挡物必须来自动作本身或场景中的自然物体：
    - 建筑楼角（角色转弯时楼角掠过画面）
    - 角色身体部位（披风展开 body wipe / 手臂挡镜头）
    - 场景结构（飞扶壁石柱 / 烟囱 / 门框）
    - 环境效果（蒸汽 / 爆炸烟尘 / 碎石扬尘）

    每个缝合点必须在提示词的**结尾**明确描述遮挡物入画，
    下一个片段的**开头**明确描述遮挡物移开揭示新画面。

[注意事项]
    - 本 skill 覆盖非对抗性动作序列——跑酷、追逐、逃脱、攀爬、特技、坠落
    - 对抗性武打/格斗不在本 skill 范围
    - performance-skill 覆盖文戏表演，三者形成三角互补
    - long-take-skill 的遮挡缝合方法论与本 skill 的 FPV 追拍方法论可组合使用
    - 动作词汇表中的英文术语在提示词中使用（AI 模型更准确理解英文动作描述）
    - 身体力学约束是硬规则——超出约束的设计必须标注为"超人/非人"或提供剧情内解释
    - 废土/哥特建筑元素表是项目特化——其他世界观项目需要替换为对应环境
    - 经典电影参考作为设计灵感，不作为照搬模板
