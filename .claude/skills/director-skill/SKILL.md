# 导演执行技能（专业版 · 含分镜）

> **专业版 = 极速版 + 分镜师增强**。导演这一层**与极速版完全相同**——一次成型出可用视频提示词 production，结构/字段/写法一字不动。专业版唯一的不同在导演**下游**：它引用的 **@图N 参考图**由「服化道身份级大平光底 → 分镜师渲染光影氛围 → 精修关键帧」流水线产出（比极速版的角色三视图质量更高、可控性更强）。**导演不感知 @图N 怎么来的，只管引用它产出视频提示词。导演的视频提示词是用户在用的出口，神圣不可动；服化道/分镜师是服务这个出口的内部精修流水线，绝不取代或删改它。**

[技能说明]
    剧本解构 + 镜头设计 + **直接产出可用的视频提示词 production**。将剧本/梗概/分场大纲转化为：
    1. production（按剧情点分节，每镜一张可复制使用的视频提示词卡片）
    2. 人物清单（用于服化道生成角色参考图）
    3. 场景清单（用于服化道生成场景参考图）
    4. 薄后期参考（环境音/音效/沉默设计/听觉记号——不进视频提示词）

    **核心理念**：导演的价值在于**剧本结构性重构 + 镜头语言决策 + 剪辑思维**，并**一次成型**地把这些落成可执行的视频提示词。不再有"导演讲戏本 → 分镜师翻译"的二次环节——镜头设计（意图层）与提示词组装（执行层）写在同一份 production 里。（专业版的分镜师不做"翻译意图"，只在服化道底上**渲染** @图N 精修关键帧，不回写导演的 production。）

    **★镜头粒度铁律（最高优先级 · 2026-06-11 用户校正 · 覆盖下文一切"每镜 3-4s/逐镜一卡"旧表述）**：
    ① **单场景 = 一条提示词（一次生成）· 时长 ≤15s**——15s 是**上限不是目标**，一个场景内容（**画面动作 ＋ 对白朗读**，见②判据）多长就多长、封顶 15s，**不凑时长**。同一场景（不换地点/时空）内的景别、运镜、焦点变化**全部按事件发生顺序写进同一条提示词的分镜动作链**（`[C01]…[C02]…`·**不写秒级时间戳**，官方：模型对精确秒数支持不稳定、可能致生成异常），**不再切成 4-5s 小卡再拼**。
    ② **超 15s 才拆·用「演时换算法」算时长（不准凭感觉·见 seedance-kling-capabilities §5.2）**：每一拍套主公式 **Σ(开口前铺垫动作) ＋ max(台词朗读, 说话时并行动作)**——台词按**固定 4 字/秒 ＋ 标点加成**算（句末 。！？ 各 +0.4s·逗号 +0.2s·破折号/省略号拖腔 +0.6s），动作按 **beat 表**数（微 1 / 中 2 / 大 3 秒），串/并行按表 3 判（开口前铺垫串行计入·说话时动作并行取 max·说话后反应串行计入）。**⚠️ 产出每一拍前必须把换算式写进 production（如 `10s铺垫 + 8.2s台词 = 18.2s → 拆2`），禁止采信剧本"约Ns"标注（只算画面骨架·系统性低估对白与表演）**。算出一拍 >15s，就在该拍内按"开口前 / 说话中 / 说话后"就近拆、每条 4–15s、首尾帧承接、**不切场景**；算出 <4s 补到 4s 或与邻拍合并。常数为工程初值·实拍后在 seedance §5.2 调参。
    ③ **切场景才另起卡片**：真正换地点 / 换时空 = 新场景 = 新提示词卡片。
    ④ **走位交 AI · 不钉坐标**：给大全景参考图后，AI 自会在画面内找合理落位；提示词只用**自然语言**描述相对位置（"坛阵那头""勺递到脸前""院门口"），**不写画面占比% / 象限 / 坐标钉位**。仅极少数**必须**精确锁位的点才退回逐镜强控制。
    ⑤ **9:16 窄幅兜底**：竖屏画幅窄、人物天然被框在小范围、基本不穿帮，适当的自然语言描述即足以让 AI 定位。
    ⑥ **场景图一张全景兜底 · 不滥切变体**：一个场景**默认只用一张全景参考图**——全景已含景深与细节，AI 生视频时自会从中取景。**不为同一场景切 -A/-B/-C 多角度变体**。仅三种情况才单独出图：① **时间变化导致光影变化**（白日→夜晚 / 换光源）；② **全景里看不清、需要非常细致的特写**（罪证道具、关键表情等——用独立**道具图/特写图**承载，而非场景角度变体）；③ **全景拍不到的面 / 动线需要的角度**——一张全景一般只含约三面，当镜头动线需要第四、第五面时（如从前门进到后堂、从屋内走出需要身后的门或墙），才补出该角度的场景图。
    ⑦ **图片行按类别分行**：上传清单按 `场景：@图…` / `人物：@图…` / `道具：@图…` 分行列出（无该类则省略该行），各自独立、分开上传、不合成。
    ⑧ **台词不挂来源标签**：台词直接内嵌在对应分镜，**不写 `[原著]`**（绝大多数本就是原著·冗余）；仅当为补充创作台词时标 `[补]`。原文照搬、零丢失的硬要求不变。

    导演为每个**场景**规划**镜头表**（标明各时段的景别/运镜/焦点/叙事功能），作为**一条提示词内部的时间轴规划**，再组装成**单条**提示词卡片（而非每镜一卡）。下文"剧情点 P01/P02"仍用于剧情拆解，但**同场景的多个剧情点合并进同一条提示词的时间轴**，不各自成卡。

    **项目特性**：
    - 影视微短剧；每集约 5 分钟、约 6 个场景
    - 视觉风格**由项目初始化配置**（命中预设或现写新风格），记录于 `assets/cinematography-bible.md`，由服化道写入参考图"风格前缀块"——**视频提示词本身不写风格前缀**
    - 对白原则：最大限度保留原文、零丢失；台词内嵌对应分镜**不挂 [原著]**（绝大多数本就是原著·冗余），仅补充创作台词标 [补]（见铁律⑧）
    - 剧本来源：`script/EPNN.md`
    - 场景分段格式：`## SNN · 标题`（场景一→S01，场景二→S02...）

[production 职责边界 · 核心哲学]
    **用户的 review 对象就是 production 本身**——视频提示词卡片即给人看、即生产。结构化的镜头卡片让用户能秒级扫读、直接复制使用。

    production **绝不写**：
    1. **散文式导演阐述**：不用自然语言重新叙述剧本——结构化卡片已承载信息
    2. **方法论诊断/打分**：导演内部思考，不进主交付
    3. **自审报告**：在 subagent 返回消息中汇报，不进文件
    4. **集级设计文档**

    **视频提示词不写（极速版硬规则）**：
    - **风格前缀块**（机型/胶片/调色/画幅）→ 归服化道（生图层），i2v 从参考图继承
    - **模型**：无模型概念（Seedance/可灵底层一致），不写、不提示
    - **线稿**：极速版无线稿
    - **摄影恒量**：全剧机型/焦段/f 值/画幅规则在 `assets/cinematography-bible.md`

    production **写**（结构化）：
    - 镜头表：每镜 景别/运镜/焦点/内容摘要/叙事功能 + 执行列（时长/驱动模式）
    - 提示词卡片：景别/运镜 + 运动描述（动作链与表情并入）+ 上传清单 + 台词
    - 角色表演要点（动作链/朝向/表情/自然语言相对位置·**不钉占比/坐标**·铁律④）、场景与光影、情绪意图/潜台词（各一句）、尾画面
    - 人物清单 / 场景清单（给服化道）

    **前置依赖**：开始前必须读取 `assets/cinematography-bible.md`，确认最新恒量与场景映射。

[可用能力清单]
    读剧本时带着这些能力思考——"这个段落是否适合用某种能力增强表达？"

    ## 长镜头设计（long-take-skill · 默认关闭 · 慎用）
    用多条素材拼接出一镜到底的视觉幻觉（延长续写/首帧锚定/遮挡缝合）。
    **硬规则：默认不用**，一集最多 1-2 次。只在硬触发条件下启用（剧本明确"不可切"/情绪峰值不可断/清晰物理移动路线+需要沉浸/用户指示）。绝对不用：多角色互动、复杂运镜转向、大远景长保持、日常对话段。

    ## 摄影技法（cinematography-skill · 按需加载）
    统一的景别体系、构图、镜头运动情绪语言、打光、景深、色温、镜头特性。**视觉风格随项目配置**，不固定单一风格。

    ## 声音设计（sound-design-skill · 按需加载）
    角色声音标签、场景声音签名、听觉母题——写入薄"后期参考"，不进视频提示词。

    ## 表演指导（performance-skill · 按需加载）
    非动作场景的表演设计——微表情、肢体语言、视线、沉默。永远不写情绪词，只写动作。

    ## 多角色调度（staging-skill · 按需加载）
    3 人以上同框时的站位、视线网络、注意力引导。

    ## 导演风格融合·大友启史 × 埃德加·赖特（otomo-wright-fusion-skill · 时尚怪盗/高燃动作戏加载）
    把大友的"华丽真实动作流+温情内核"与赖特的"节拍剪辑+时髦幽默"融为一套，**按情节类型配方**（飙车/打斗/跑酷/盗窃潜入/文戏温情/时尚换装登场）给运镜+剪辑节奏+声画卡点。核心：**赖特剂量按情节配**（飙车/换装/潜入拉满、文戏撤掉），暧昧/暗恋线加一味王家卫/是枝调味。卡点落地为"动作 beat 设计 + 后期参考节奏锚"（视频提示词不写音乐）。**项目若在 cinematography-bible 指定了此导演风格，动作/高燃/怪盗戏必加载本 skill。**

    使用原则：大部分段落用基础流程即可；特殊能力用在叙事最需要处。全剧色彩恒量在 cinematography-bible，段内色彩锚点在 production 中按剧情点标注。

[执行流程]

    第一步：通读剧本
        - 读取 `script/EPNN.md` 中本段对应的场景内容
        - 理解核心叙事线、人物关系、情感走向；识别转折点和高潮
        - 注意原文对白（最大限度保留原文·零丢失）；补充创作的台词标 [补]，**原著台词不挂标签**（铁律⑧）

    第二步：拆解剧情点
        将场景拆分为剧情点（P01、P02...），每个是完整叙事段落。
        拆分依据——叙事自然断点：情绪转折 / 时空跳转 / 叙事功能转换。
        一个剧情点内可含多组镜头（蒙太奇/连续场景/单镜头）。
        反向检查：相邻段落同一叙事目的→合并；一个段落含两个独立目的→拆分。

    第二步半：剧情点筛选与剪辑规划
        **A · 剧情点筛选（隐含叙事）**：删掉后观众不问"然后呢"、内容可被前后文暗示 → 标 `[隐含叙事·省略]` + 理由。
        **B · 过程性动作标注**：扫描动作链中的过程性位移，标注镜头表中应省略的（详见 [剪辑原则] 原则 3）。

    第三步：确定时长
        **★粒度优先（铁律①）**：先按**场景**切——单场景 = **一条 ≤15s 提示词**（15s 是上限不是目标·内容多长就多长封顶 15s·不凑时长）。下方时长档用于**判断一条提示词内部放几个分镜的参考**（内部规划用·不写进提示词正文），**不再是每镜独立时长**；单场景内容 >15s 才在同场景内拆多条（每条 ≤15s）。
        **段级时长预估**：每集约 300 秒、约 6 场景、每场景平均约 50 秒。单个剧情点 5-20 秒，复杂段 30-40 秒。

        时长选择参考：
            | 时长 | 适用场景 |
            |------|----------|
            | 5s   | 极简情绪点，1-2 镜 |
            | 8s   | 一组连贯动作，2-3 镜 |
            | 10s  | 含镜头切换的叙事，3-4 镜 |
            | 15s  | 完整多场景叙事（蒙太奇），4-5 镜 |
            | 20-40s | 复杂叙事段落，5-12 镜 |

        **镜头密度（电影级 ASL）**：动作/追逐 2-3s · 对话/剧情 4-6s · 沉思/抒情 6-8s · 悬疑/恐怖混合。

        **节拍密度约束**（每镜内，非整段）：每镜内 1 拍 ≈ 2.5 秒屏幕时间。一个物理动作=1 拍；一次镜头运动=1 拍；短台词(≤10字)=1 拍，超过按 2 拍；同时发生合并为 1 拍。

        **头尾安全区**：每条驱动前 0.5s、后 0.5s 为安全区不放关键内容。需在动作中切换时头尾各预留 1-2 秒缓冲。

        **最短时长硬约束**：单条视频片段最短 4s。导演原始设计 <4s 的镜头延长至 4s（自然延展过程，记入卡片备注）。

    第四步：为每个剧情点设计镜头表（含执行列）
        导演的工作是**结构性重构 + 镜头语言决策**。每个剧情点必须输出镜头表，导演定义每个镜头的**完整视觉意图**（景别 + 运镜 + 焦点）+ 执行列（时长 + 驱动模式）。

        **镜头的目的（核心哲学）**：每个镜头存在的唯一理由是**讲故事和表达情绪**。写不出叙事功能的镜头 = 不该拍。

        **叙事驱动的镜头设计（硬规则）**：逐镜按因果链思考，而非查模板：
        1. **这个节拍关于什么？** → 确定情绪意图（用括注写进动作链）
        2. **角色在什么空间/位置关系？** → 确定走位（角色表）
        3. **什么镜头让观众感受到这个情绪？** → 情绪意图自然决定景别+运镜+焦点（三层被同一意图同时塑形）
        4. **为什么在这里切？** → 找不到切的理由就延长或合并

        **★主体优先组织律（每镜卡片硬 checklist · AI 视频模型靠"挑重点"实现·干扰项一多就丢主体）**：
        写每条镜头/动作链前，按此顺序组织，**不许元素平铺**：
        1. **定绝对主体**：这一镜的视觉中心是谁/什么？一镜只能有一个绝对主体。
        2. **锚核心动作**：主体在做的那个**唯一核心动作**（辅助/细节动作都围绕它，不喧宾夺主）。
        3. **界定客体边界**：背景、配角、互动物——全部标"**为主体服务·不抢镜**"（远处行人缓慢移动、背景静止/弱化、客体配合主体），明确写进动作链让模型知道谁是配角。
        4. **镜头调度围绕主体**：景别/运镜/焦点都服务于"让观众看清主体+主体动作"（跟拍同速、主体居中或按三分法置点、禁焦点模糊主体；情绪沉淀/单人镜可用**留白**把主体从空旷里衬出来·见 `cinematography-skill [构图规则] 留白/负空间`）。
        5. **光影色彩烘托不淹没**：光影色调为烘托**主体情绪**服务，绝不让大色块/强光把主体盖过去（淹没主体 = 失败）。
        6. **节奏定性化**：主体动作的快慢用**定性节奏词**写（缓慢/沉稳/快速 + 幅度/力度），治"动作忽快忽慢"——**不写秒级时间戳**（官方：模型对精确秒数支持不稳定，见铁律①/seedance §）。
        > 自检一句：这一镜，观众一眼能不能锁定该看谁？锁不定 = 主体没立住，回炉。

        **三层统一决策**：走位（角色表）、机位（景别+运镜）、焦点——被同一情绪意图同时塑形，不拆开。同一个 OTS，"亲密"用浅景深+缓推，"压迫"用 static+极窄框。

        **动作描述铁律**：
        - 抽象动作词黑名单：望向/注视/凝视/看向/盯着/背对/回眸/俯视/视线对着
        - 正确做法：身体朝向 + 头部方向 + 眼睛焦点物体 + 自然语言相对位置（**不写画面占比%/坐标**·铁律④）
        - 示例：「她望向窗外」→ 朝向：侧面朝右 / 动作链：头部转向窗户方向，窗外天空出现在画面右侧
        - **情绪抽象词保留**（意图字段中用）：他陷入回忆 / 时间仿佛静止
        - 判别法：是"动作"→译为物理描述；是"情绪/心理状态"→放意图字段

        **抽象概念视觉化禁令**（通用）：
        - 不直接视觉化抽象概念（意识、记忆、命运、孤独等）——用物理暗示替代：瞳孔变化、肌肉微抽、手指无意识动作、环境光影变化
        - 内心独白不用画外音文字叠加，用角色物理反应传达
        - 项目若有专属禁忌（特定题材的视觉黑名单），在 cinematography-bible 中补充

        **组装硬规则**：
        - **卡片头**：`#### 镜头 S0N · ≤15s · 驱动模式 · 场景名（单场景·一次生成）`（**无模型**；单场景内容 >15s 拆多条时编 `S0N-a` / `S0N-b`）
        - **图片行（按类别分行 · 铁律⑦）**：`场景：@图N <全景>·分开上传` ／ `人物：@图N <角色A> ; @图N <角色B>·分开上传` ／ `道具：@图N <道具>·分开上传`（无该类则省略该行）。场景**默认一张全景兜底**（铁律⑥）；首尾帧需指定起止帧、或动线需补第四/五面时，在场景行标"起始…→终止…"或另列补面图；服化道未完成时 @图N 用占位。**末尾另起一行 `无字幕，无bgm`**
        - **正文 = 分镜动作链**：`- [C0N · 景别 · 运镜] 动作描述`，物理化、污染词已替换、按需含前景/氛围粒子、**动作快慢用定性节奏/速度词**（缓慢/快速/沉稳 + 幅度/力度·不写秒）；同场景的景别/运镜/焦点变化**按事件发生顺序逐分镜写进同一条·不写秒级时间戳**（官方：模型对精确秒数支持不稳定、可能致生成异常；总时长在生成时选档即可）；**台词内嵌在它发生的那个分镜里**（`@角色："原文"`·**不挂 [原著]**·铁律⑧），原文照搬·零丢失·**不单列"台词"字段**·补充台词标 `[补]`
        - **一条内多固定机位** → 分镜首标 `[C01·机位说明]` / `[C02·机位说明]`（按事件顺序·不写秒）
        - 分镜按事件顺序覆盖全程；**单条 ≤15s**（内容 >15s → 同场景内拆·每条 ≤15s·首尾帧承接·不切场景）；拆出的子条最短 4s
        - **不写（极速版）**：风格前缀块（`Shot on ARRI…` 归服化道）、模型、线稿、摄影机基准、**avoid 负面约束**（不需要）
        - 卡片只保留：卡片头 + 图片行（场景/人物/道具分行 + "无字幕，无bgm"）+ 分镜动作链。整段即可复制粘贴。

        **默认单场景一条（铁律①·覆盖旧"逐镜一卡"）**：同一场景拆成**一条 ≤15s 提示词**，景别/运镜/焦点变化**按事件发生顺序逐分镜（C01/C02…）写进同一条·不写秒级时间戳**（官方：精确秒数模型不稳定），**不再每镜一卡**。只有"内容 >15s"（同场景内拆）或"切场景"（另起卡片）才出现多条。
        **覆盖率自验**：逐 P 对照镜头数 vs 卡片数，每个镜头必须被某卡片覆盖，不遗漏。

[质量标准]
    - 每个场景：镜头表（各时段含驱动列）+ **单条 ≤15s 提示词卡片**（铁律①）+ 角色表演要点（不钉占比）+ 场景光影 + 意图 + 尾画面齐全
    - 动作链时间戳与时长一致，节拍密度不超限
    - 朝向/姿态/表情是可观察的物理描述，不用抽象动作词
    - 景别必须带方向（如"近景·正面"）
    - 提示词**无风格前缀、无模型、无线稿**；视频提示词无 avoid（生图 avoid 归服化道）
    - 每个剧情点有场景类型标签
    - 台词零丢失、与剧本原文一致；**不挂 [原著]**、补充创作台词标 [补]（铁律⑧）
    - 尾画面描述具体收束状态，角色状态表含位置/朝向/姿态/表情

[剪辑原则]（硬规则 · 规划镜头表时遵循）
    **原则 1 · Murch 优先级**：切镜决策优先级 情感 > 故事推进 > 节奏 > 视线承接 > 画面连续性 > 空间连续性。情感/故事需要时可牺牲空间连续性。
    **原则 2 · 信息耗尽即切**：当前镜头视觉信息被消化完 → 切。观众已知接下来发生的就不必拍。
    **原则 3 · 省略无信息位移**：A 到已知 B 的过程若不携带新信息 → 省略（走廊穿行/段内第二次同类动作/"看到→到达"中间过程）。例外：过程在建立氛围（≤5s）/ 展现状态变化 / 时间本身是叙事元素。判据：删掉后观众不问"然后呢"→删。
    **原则 4 · 动作中切**：在动作进行中间切，利用运动遮掩剪辑痕迹。切换点选在动作中间。（一个连续动作拆成两条 clip 时的逐帧无缝缝合技巧——保留重叠动作 / 剪辑点放动作中途 / 视觉暂留 0.1-0.2s——见 `seedance-kling-capabilities §3.5 片段间动作衔接`）
    **原则 5 · 30 度法则**：相邻镜头拍同一主体角度变化 > 30°。
    **原则 6 · 情绪不切原则**：情绪积累未到峰值不切；关键反应未完成不切。
