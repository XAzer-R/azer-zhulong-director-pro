# 导演 production 产出模板（专业版 · 段级）

输出文件：`outputs/EPNN/<段号>-production.md`（如 `outputs/EP01/S01-production.md`）

**定位**：专业版导演**一次成型**产出**可用视频提示词 production**——结构与极速版完全一致（导演的视频提示词出口神圣不可动）。**专业版 = 极速版 + 分镜师增强**：导演照出这份 production.md，唯一差异是它引用的 **@图N 参考图**由「服化道身份级大平光底 → 分镜师渲染光影氛围 → 精修关键帧」流水线产出（比极速版的角色三视图质量更高、可控性更强），喂 i2v 当首帧/参考。**导演不感知 @图N 怎么来的，只引用它**——卡片结构、字段、写法一字不动对齐极速版。

**粒度**：按段产出。段内剧情点 P01/P02/...。每个剧情点含若干**提示词卡片**，每张对应一个镜头。服化道+分镜师完成后回填 @图N。

---

## 产出白名单（硬规则）

production **只能包含**：① 文件头 ② 段内总览 ③ 段级素材对应表 ④ 各剧情点（元信息 + 角色走位 + 镜头表 + 提示词卡片）⑤ 段尾画面/交接包 ⑥ 后期参考（薄）⑦ 人物清单 ⑧ 场景清单。

**禁止**：散文式导演阐述 / 五维打分诊断 / 自审报告 / 集级设计 / **视频提示词里写风格前缀块·模型·线稿·摄影机基准**。

## 文件头
```markdown
# <EP号>-<段号> <段标题>

> 段时长目标：约 X 秒 | 情绪弧：[起点] → [终点]
> 依据：script/EPNN.md + cinematography-bible.md
```
> 风格前缀块/摄影机基准不在此——集中于 `assets/cinematography-bible.md`，由服化道写入参考图（分镜师渲染时继承）。

**卡片硬规则（铁律①④⑦⑧）**：
- **卡片头**：`#### 镜头 S0N · ≤15s · <驱动模式> · <场景名>（单场景·一次生成）`（**无模型**；单场景内容 >15s 拆多条时编 `S0N-a` / `S0N-b`）
- **图片行（按类别分行·铁律⑦）**：`场景：@图N <全景>·分开上传` ／ `人物：@图N <角色A> ; @图N <角色B>·分开上传` ／ `道具：@图N <道具>·分开上传`（无该类则省略该行）。场景**默认一张全景兜底**（铁律⑥）；首尾帧需指定起止帧、或动线需补第四/五面时标"起始…→终止…"或另列补面图；服化道未完成时 @图N 用占位。**末尾另起一行 `无字幕，无bgm`**
- **正文 = 分镜动作链**：`- [C0N · 景别 · 运镜] 动作描述`，物理化、污染词已替换、**动作快慢用定性节奏/速度词**（缓慢/快速/沉稳 + 幅度/力度）；同场景的景别/运镜/焦点变化**按事件发生顺序逐分镜写进同一条·不写秒级时间戳**（官方：模型对精确秒数支持不稳定）；**台词内嵌在它发生的那个分镜里**（`@角色："原文"`·**不挂 [原著]**·铁律⑧），原文照搬·零丢失·**不单列"台词"字段**·补充创作台词标 `[补]`
- **一条内多固定机位** → 分镜首标 `[C01·机位说明]` / `[C02·机位说明]`（按事件顺序·不写秒）
- 分镜按事件顺序覆盖全程；**单条 ≤15s**（内容 >15s → 同场景内拆·每条 ≤15s·首尾帧承接·不切场景）；拆出的子条最短 4s
- **不写（专业版同极速版）**：风格前缀块（`Shot on ARRI…` 归服化道）、模型、线稿、摄影机基准、**avoid 负面约束**（不需要）
- 卡片只保留：卡片头 + 图片行（场景/人物/道具分行 + "无字幕，无bgm"）+ 分镜动作链。整段即可复制粘贴去生视频。

# 自审摘要格式（subagent 返回消息中呈报 · 不产出独立文件）
```
## 自审摘要
- 业务审核：X.XX/10（PASS / FAIL · 最低单项 X 分于 P0Y）
- 镜头覆盖率：全覆盖 / P0X 缺 N 镜
- 台词零丢失：全部内嵌一致 / P0X 缺/改
- 提示词合规：分镜动作链·台词内嵌·无风格前缀·无模型·无线稿·无 avoid / 违规于 P0X
- 段戏剧承担：[1 句话]
```
**判定**：PASS = 剧情点均分 ≥ 8 且无单项低于 6 且镜头全覆盖且台词零丢失且提示词合规。FAIL → 自我修改至 PASS（最多 2 轮）。
